# Recursion

Practical, structured notes for understanding **recursion fundamentals, recursive execution, call-stack behavior, recursion techniques, backtracking, and problem-solving strategies** used in software development and algorithms.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Recursion Fundamentals|Recursive functions, recursive thinking, termination, and common recursion patterns|
|02|Base Case|Termination conditions, stopping recursion, edge cases, and preventing infinite recursion|
|03|Recursive Case|Recursive decomposition, self-calls, progress toward termination, and recursive structure|
|04|Call Stack|Stack frames, function calls, return flow, memory usage, and stack behavior|
|05|Tail Recursion|Tail calls, accumulator patterns, optimization concepts, and recursive implementation|
|06|Backtracking|State exploration, decision trees, undo operations, pruning, and search strategies|
|07|Recursion Problems|Common recursion problems, pattern recognition, edge cases, optimization, and problem-solving|

## Structure

The notes progress from **recursion fundamentals → base case → recursive case → call stack → tail recursion → backtracking → recursion problems**.

The first sections establish how recursion works and how recursive functions are structured around base cases and recursive cases. The call-stack section then explains how recursive calls are stored, executed, and returned through stack frames.

Tail recursion introduces a specialized recursive structure and its optimization concepts. Backtracking then extends recursion into systematic state-space exploration using decisions, undo operations, and pruning.

The final section applies these concepts to practical recursion problems, focusing on recursive thinking, pattern recognition, edge cases, complexity, and optimization.

Each topic is separated into focused notes for easier learning, implementation, revision, and problem solving.

## Focus

> Build a practical recursion knowledge base that makes it easy to understand recursive execution, design correct recursive solutions, manage call-stack behavior, apply backtracking techniques, and solve recursion-based problems efficiently.
