# Greedy

Practical, structured notes for understanding **greedy algorithms, greedy-choice strategies, optimization problems, classic greedy techniques, and problem-solving patterns** used in algorithms.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Greedy Fundamentals|Greedy algorithms, local optimization, decision making, feasibility, and common characteristics|
|02|Greedy Choice|Greedy-choice property, optimal substructure, proof strategies, and choosing locally optimal decisions|
|03|Activity Selection|Interval selection, earliest-finish-time strategy, sorting, and greedy optimization|
|04|Interval Scheduling|Scheduling intervals, compatibility, sorting strategies, and efficient selection|
|05|Fractional Knapsack|Value-to-weight ratios, fractional selection, sorting, and greedy optimization|
|06|Huffman Coding|Frequency-based merging, prefix codes, priority queues, and optimal encoding|
|07|Greedy Problems|Common greedy problems, pattern recognition, proof techniques, edge cases, and optimization|

## Structure

The notes progress from **greedy fundamentals → greedy choice → activity selection → interval scheduling → fractional knapsack → Huffman coding → greedy problems**.

The first sections establish the core idea behind greedy algorithms and explain when locally optimal decisions can lead to a globally optimal solution. Greedy-choice analysis then introduces the properties and reasoning used to justify greedy strategies.

Activity selection and interval scheduling provide classic examples of greedy optimization through ordering and compatibility. Fractional knapsack demonstrates ratio-based greedy selection, while Huffman coding introduces repeated optimal merging using a priority queue.

The final section applies these concepts to practical greedy problems, focusing on pattern recognition, correctness reasoning, edge cases, complexity, and optimization.

Each topic is separated into focused notes for easier learning, implementation, revision, and problem solving.
