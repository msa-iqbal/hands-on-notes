# Dynamic Programming

Practical, structured notes for understanding **dynamic programming fundamentals, state modeling, recurrence relations, optimization techniques, classic DP patterns, and problem-solving strategies** used in algorithms.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|DP Fundamentals|Dynamic programming concepts, states, transitions, recurrence relations, and problem decomposition|
|02|Overlapping Subproblems|Repeated subproblems, redundant computation, state reuse, and identifying DP opportunities|
|03|Optimal Substructure|Optimal substructure, combining optimal subproblem solutions, and recognizing DP structure|
|04|Memoization|Top-down DP, recursion with caching, state storage, and reducing repeated computation|
|05|Tabulation|Bottom-up DP, table construction, iteration order, state transitions, and iterative solutions|
|06|One-Dimensional DP|Single-dimension states, linear transitions, initialization, and common 1D DP patterns|

|10|Longest Increasing Subsequence|Increasing subsequences, DP transitions, optimization, and efficient LIS techniques|
|11|Coin Change|Minimum coins, number of combinations, state transitions, initialization, and optimization|
|12|Dynamic Programming Problems|Common DP problems, pattern recognition, state design, optimization, edge cases, and problem-solving|

## Structure

The notes progress from **DP fundamentals → overlapping subproblems → optimal substructure → memoization → tabulation → one-dimensional DP → two-dimensional DP → knapsack → longest common subsequence → longest increasing subsequence → coin change → dynamic programming problems**.

The first sections establish the two key properties behind dynamic programming and explain how repeated subproblems and optimal substructure enable state-based solutions. Memoization and tabulation then introduce the two primary approaches for implementing DP.

One-dimensional and two-dimensional DP introduce common state structures and transition patterns. The following sections apply these concepts to classic problems such as knapsack, longest common subsequence, longest increasing subsequence, and coin change.

The final section applies these concepts to practical dynamic-programming problems, focusing on state design, transition selection, pattern recognition, edge cases, complexity, and optimization.

Each topic is separated into focused notes for easier learning, implementation, revision, and problem solving.
