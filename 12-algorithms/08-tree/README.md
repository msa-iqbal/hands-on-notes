# Tree

Practical, structured notes for understanding **tree fundamentals, tree structures, traversal techniques, specialized trees, and problem-solving strategies** used in software development and algorithms.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Tree Fundamentals|Tree terminology, nodes, edges, roots, leaves, depth, height, and basic properties|
|02|Binary Tree|Binary-tree structure, node relationships, properties, and common operations|
|03|Tree Traversal|Preorder, inorder, postorder, level-order, and traversal techniques|
|04|Binary Search Tree|BST properties, searching, insertion, deletion, and complexity|
|05|AVL Tree|Self-balancing BSTs, rotations, balancing, insertion, deletion, and complexity|
|06|Red-Black Tree|Balanced BST properties, node coloring, rotations, insertion, and deletion|
|07|Trie|Prefix trees, character-based storage, insertion, search, deletion, and prefix matching|
|08|Segment Tree|Range queries, point updates, tree construction, and efficient range operations|
|09|Fenwick Tree|Binary indexed trees, prefix queries, point updates, and efficient cumulative operations|
|10|Tree Problems|Common tree problems, traversal patterns, recursion, edge cases, optimization, and problem-solving|

## Structure

The notes progress from **tree fundamentals → binary trees → traversal → binary search trees → AVL trees → red-black trees → tries → segment trees → Fenwick trees → tree problems**.

The first sections establish tree terminology and binary-tree structures before introducing traversal techniques. Binary search trees then build on these foundations by organizing values to support efficient searching and modification.

AVL and red-black trees introduce self-balancing search trees and the techniques used to maintain their structure. Trie then covers prefix-based tree structures for string and lookup problems.

Segment trees and Fenwick trees focus on efficient range queries and updates. The final section applies these concepts to practical tree problems, emphasizing traversal patterns, recursion, edge cases, complexity, and optimization.

Each topic is separated into focused notes for easier learning, implementation, revision, and problem solving.
