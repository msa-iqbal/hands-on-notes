# Searching

Practical, structured notes for understanding **searching fundamentals, search algorithms, optimization techniques, and problem-solving strategies** used in software development and algorithms.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Searching Fundamentals|Search concepts, search spaces, conditions, complexity, and algorithm selection|
|02|Linear Search|Sequential searching, implementation, edge cases, and complexity|
|03|Binary Search|Sorted data, search intervals, midpoint calculation, boundary handling, and complexity|
|04|Interpolation Search|Position estimation, uniformly distributed data, implementation, and complexity|
|05|Search on Answer|Binary search on feasible answers, monotonic conditions, bounds, and optimization|
|06|Two-Pointer Search|Two-pointer technique, pointer movement, sorted data, and common search patterns|
|07|Searching Problems|Common searching problems, pattern recognition, edge cases, optimization, and problem-solving|

## Structure

The notes progress from **searching fundamentals → linear search → binary search → interpolation search → search on answer → two-pointer search → searching problems**.

The first sections establish the purpose of searching and introduce linear search as the basic sequential approach. Binary search then introduces efficient searching over ordered data using a shrinking search interval.

Interpolation search extends binary-search concepts by estimating the likely position of a target in uniformly distributed data. Search on answer then applies binary-search techniques to solution spaces where a monotonic feasibility condition exists.

Two-pointer search introduces an efficient technique for working with ordered data and related search problems. The final section applies these concepts to practical searching problems, focusing on algorithm selection, pattern recognition, edge cases, complexity, and optimization.

Each topic is separated into focused notes for easier learning, implementation, revision, and problem solving.
