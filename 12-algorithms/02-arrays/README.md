# Arrays

Practical, structured notes for understanding **array fundamentals, operations, common array techniques, and problem-solving strategies** used in software development and algorithms.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Array Fundamentals|Array structure, indexing, memory layout, dimensions, and basic operations|
|02|Static & Dynamic Arrays|Fixed-size arrays, dynamic arrays, resizing, capacity, and memory management|
|03|Array Traversal|Sequential access, iteration, forward and reverse traversal, and traversal techniques|
|04|Insertion & Deletion|Adding and removing elements, shifting elements, position-based operations, and complexity|
|05|Two Pointers|Two-pointer technique, pointer movement, and common array problem patterns|
|06|Sliding Window|Fixed and variable-size windows, window expansion and contraction, and subarray patterns|
|07|Prefix Sum|Prefix-sum construction, range-sum queries, and efficient subarray calculations|
|08|Array Problems|Common array problems, pattern recognition, optimization, edge cases, and problem-solving|

## Structure

The notes progress from **array fundamentals → static and dynamic arrays → traversal → insertion and deletion → two pointers → sliding window → prefix sum → array problems**.

The first sections establish how arrays are structured, stored, accessed, and modified. The next sections introduce common techniques for efficiently processing array elements and contiguous ranges.

The final section applies these concepts to practical problems, focusing on pattern recognition, complexity, edge cases, and optimization.

Each topic is separated into focused notes for easier learning, implementation, revision, and problem solving.
