# Sorting

Practical, structured notes for understanding **sorting fundamentals, comparison-based and non-comparison sorting algorithms, algorithm implementation, and performance analysis**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Sorting Fundamentals|Sorting concepts, ordering, stability, in-place sorting, and sorting complexity|
|02|Bubble Sort|Adjacent comparisons, swapping, passes, optimization, and complexity|
|03|Selection Sort|Minimum-element selection, swapping, implementation, and complexity|
|04|Insertion Sort|Incremental sorting, element shifting, insertion, and complexity|
|05|Merge Sort|Divide and conquer, splitting, merging, recursion, and complexity|
|06|Quick Sort|Pivot selection, partitioning, recursion, and average and worst-case complexity|
|07|Heap Sort|Heap construction, heapify, extraction, and in-place sorting|
|08|Counting Sort|Frequency counting, key ranges, stable sorting, and complexity|
|09|Radix Sort|Digit-based sorting, multiple passes, stable intermediate sorting, and complexity|
|10|Bucket Sort|Bucket distribution, individual bucket sorting, and complexity|
|11|Sorting Comparison|Algorithm comparison, time and space complexity, stability, in-place behavior, and use cases|

## Structure

The notes progress from **sorting fundamentals → basic comparison-based algorithms → divide-and-conquer and heap-based algorithms → non-comparison algorithms → sorting comparison**.

The first sections introduce sorting concepts and basic algorithms such as bubble sort, selection sort, and insertion sort. Merge sort and quick sort then introduce divide-and-conquer approaches, while heap sort applies heap-based techniques to sorting.

Counting sort, radix sort, and bucket sort cover non-comparison sorting approaches that can be effective under suitable data constraints. The final section compares the algorithms based on complexity, stability, memory usage, and practical characteristics.

Each topic is separated into focused notes for easier learning, implementation, revision, algorithm selection, and problem solving.

## Focus

- Sorting fundamentals
- Comparison-based sorting
- Merge, quick, and heap sort
- Non-comparison sorting
- Sorting algorithm comparison

## Goal

> Build a practical sorting knowledge base that makes it easy to understand, implement, analyze, and compare sorting algorithms and choose suitable approaches for different data and performance requirements.
