# Strings

Practical, structured notes for understanding **string fundamentals, string operations, searching techniques, common patterns, and problem-solving strategies** used in software development and algorithms.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|String Fundamentals|String structure, characters, indexing, encoding, immutability, and basic operations|
|02|String Traversal|Character access, iteration, forward and reverse traversal, and traversal techniques|
|03|String Manipulation|Concatenation, splitting, replacement, transformation, and common string operations|
|04|String Search|Substring search, pattern matching, searching techniques, and search complexity|
|05|Palindrome|Palindrome concepts, checking techniques, two-pointer approaches, and common problems|
|06|Anagrams|Anagram concepts, character frequency, sorting, comparison, and common problems|
|07|String Patterns|Common string patterns, frequency counting, two pointers, sliding window, and pattern recognition|
|08|String Problems|Common string problems, technique selection, edge cases, optimization, and problem-solving|

## Structure

The notes progress from **string fundamentals → traversal → manipulation → searching → palindromes → anagrams → string patterns → string problems**.

The first sections establish how strings are represented, accessed, traversed, and modified. String searching then introduces techniques for locating characters, substrings, and patterns efficiently.

Palindrome and anagram sections focus on common string problem types and the techniques used to solve them. String patterns then combine these ideas with techniques such as frequency counting, two pointers, and sliding windows.

The final section applies these concepts to practical string problems, focusing on pattern recognition, edge cases, complexity, and optimization.

Each topic is separated into focused notes for easier learning, implementation, revision, and problem solving.

## Focus

- String fundamentals

- String searching

## Goal

> Build a practical strings knowledge base that makes it easy to understand and manipulate strings, apply common searching and pattern techniques, recognize recurring problem types, and solve string problems efficiently.
