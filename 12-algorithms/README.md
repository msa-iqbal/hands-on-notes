## Structure

The notes progress from **complexity analysis → fundamental data structures → core algorithms → algorithmic paradigms → problem solving**.

The first section establishes how to analyze algorithm performance through time and space complexity. The next sections cover fundamental data structures, including arrays, strings, linked lists, stacks, queues, hash tables, trees, heaps, and graphs.

Sorting and searching then introduce core algorithmic techniques for organizing and locating data. Recursion, greedy algorithms, and dynamic programming build on these foundations to introduce increasingly powerful approaches for solving complex problems.

The final section focuses on practical problem solving, combining analysis, reusable techniques, correctness, edge-case handling, and optimization into a systematic approach.

Each topic is separated into focused notes for easier learning, implementation, revision, reference, and problem solving.

## Focus

- Complexity analysis

- Algorithmic problem solving

## Goal

> Build a practical algorithms knowledge base that makes it easy to understand complexity, master fundamental data structures and algorithms, recognize problem-solving patterns, choose suitable techniques, and solve algorithmic problems efficiently.
