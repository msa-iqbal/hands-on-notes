# Problem Solving

Practical, structured notes for understanding **problem-solving fundamentals, algorithmic thinking, common techniques, optimization methods, and strategies** used to solve programming and algorithmic problems.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Problem-Solving Fundamentals|Problem-solving mindset, requirements, inputs, outputs, constraints, and solution design|
|02|Problem Analysis|Problem decomposition, constraint analysis, examples, assumptions, and identifying solution patterns|
|03|Brute Force|Exhaustive search, straightforward solutions, baseline implementations, and complexity analysis|
|04|Two Pointers|Pointer movement, sorted data, pair and range problems, and efficient search patterns|
|05|Sliding Window|Fixed and variable windows, window expansion and contraction, and subarray or substring problems|
|06|Prefix Sum|Prefix construction, range queries, cumulative calculations, and efficient subarray operations|
|07|Binary Search|Search-space reduction, boundary handling, monotonic conditions, and efficient searching|
|08|Backtracking|State-space exploration, decision trees, undo operations, pruning, and constraint-based search|
|09|Divide & Conquer|Problem decomposition, recursive division, combining results, and complexity analysis|
|10|Bit Manipulation|Bitwise operations, masks, shifts, toggling, checking bits, and bit-based techniques|
|11|Invariants|Maintaining conditions, loop invariants, correctness reasoning, and problem-solving patterns|
|12|Edge Cases|Boundary conditions, empty inputs, extreme values, duplicates, invalid states, and special cases|
|13|Optimization|Complexity reduction, bottleneck identification, trade-offs, and improving solutions|
|14|Problem-Solving Strategies|Pattern recognition, technique selection, solution validation, optimization, and systematic problem solving|

## Structure

The notes progress from **problem-solving fundamentals → problem analysis → brute force → common problem-solving techniques → correctness and edge cases → optimization → problem-solving strategies**.

The first sections establish a systematic approach to understanding problems, analyzing requirements and constraints, and developing straightforward brute-force solutions. The next sections introduce reusable techniques such as two pointers, sliding window, prefix sum, and binary search.

Backtracking, divide and conquer, and bit manipulation then cover additional techniques for exploring solution spaces, decomposing problems, and manipulating data efficiently. Invariants provide a foundation for reasoning about correctness, while edge-case analysis helps ensure solutions behave correctly under unusual inputs.

The final sections focus on improving existing solutions and developing a systematic strategy for recognizing patterns, selecting techniques, validating solutions, analyzing complexity, and optimizing implementations.

Each topic is separated into focused notes for easier learning, revision, technique selection, and practical problem solving.

## Focus

- Problem analysis and decomposition
- Brute-force and optimization

## Goal

> Build a practical problem-solving knowledge base that makes it easy to analyze programming problems, recognize reusable patterns, select suitable techniques, develop correct solutions, handle edge cases, and optimize implementations efficiently.
