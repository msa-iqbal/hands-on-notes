# Complexity

Practical, structured notes for understanding **algorithmic complexity, asymptotic notation, performance analysis, and efficiency evaluation**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Time Complexity|Runtime, operation counts, input-size growth, and execution-time analysis|
|02|Space Complexity|Memory usage, auxiliary space, input space, and recursion space|
|03|Big O|Asymptotic upper bounds, growth rates, and dominant terms|
|04|Big Omega|Asymptotic lower bounds and minimum growth rates|
|05|Big Theta|Tight asymptotic bounds and precise growth-rate characterization|
|06|Best, Average & Worst Case|Performance under different input conditions|
|07|Complexity Analysis|Practical analysis of loops, nested loops, conditionals, recursion, and common complexity classes|

## Structure

The notes progress from **time complexity → space complexity → Big O → Big Omega → Big Theta → best, average, and worst-case analysis → complexity analysis**.

The first sections establish how algorithms consume time and memory. The asymptotic-notation sections then introduce the main ways to describe algorithm growth and performance.

Best, average, and worst-case analysis explains how performance can vary with different inputs. The final section brings these concepts together through practical complexity analysis of common algorithm structures.

Each topic is separated into focused notes for easier learning, reference, comparison, and practical application.

## Focus

- Time and space complexity
- Big O, Big Omega, and Big Theta
- Best, average, and worst cases
- Complexity analysis
- Algorithm efficiency

## Goal

> Build a practical complexity knowledge base that makes it easy to analyze algorithm performance, understand asymptotic growth, compare solutions, and evaluate time and space efficiency.
