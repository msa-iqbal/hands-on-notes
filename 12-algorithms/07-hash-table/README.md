# Hash Table

Practical, structured notes for understanding **hash tables, hashing techniques, collision handling, hash-based data structures, and problem-solving strategies** used in software development and algorithms.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Hash Table Fundamentals|Hash tables, key-value storage, indexing, lookup, insertion, deletion, and complexity|
|02|Hash Functions|Hashing principles, hash values, distribution, determinism, and hash-function properties|
|03|Collision Handling|Collision causes, collision-resolution strategies, and performance considerations|
|04|Chaining|Separate chaining, buckets, linked structures, and collision management|
|05|Open Addressing|Linear probing, quadratic probing, double hashing, and probe sequences|
|06|Hash Map|Key-value mappings, lookup operations, updates, deletion, and practical use cases|
|07|Hash Set|Unique-value storage, membership testing, insertion, deletion, and practical use cases|
|08|Hash Table Problems|Common hash-based problems, pattern recognition, edge cases, optimization, and problem-solving|

## Structure

The notes progress from **hash-table fundamentals → hash functions → collision handling → chaining → open addressing → hash maps → hash sets → hash-table problems**.

The first sections establish how hash tables store and retrieve data using keys and hash functions. Collision handling then explains why collisions occur and how chaining and open addressing resolve them.

Hash maps and hash sets introduce common hash-based data structures and their practical operations. The final section applies these concepts to common algorithmic problems, focusing on pattern recognition, efficient lookup, edge cases, complexity, and optimization.

Each topic is separated into focused notes for easier learning, implementation, revision, and problem solving.

## Focus

- Hash-table fundamentals and hash functions
- Collision handling
- Chaining and open addressing
- Hash maps and hash sets
- Hash-table problem solving

## Goal

> Build a practical hash-table knowledge base that makes it easy to understand hashing, implement and analyze hash-based structures, handle collisions, and solve lookup and frequency-based problems efficiently.
