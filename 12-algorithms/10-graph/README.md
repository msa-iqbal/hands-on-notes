# Graph

Practical, structured notes for understanding **graph fundamentals, representations, traversal, shortest paths, minimum spanning trees, connectivity, and graph problem-solving strategies** used in algorithms.

## Structure

The notes progress from **graph fundamentals → representation → BFS → DFS → topological sort → shortest paths → Dijkstra → Bellman-Ford → Floyd-Warshall → minimum spanning trees → Kruskal → Prim's → Union-Find → graph problems**.

The first sections establish graph terminology and common representations before introducing the two fundamental traversal techniques, BFS and DFS. Topological sorting then covers dependency ordering in directed acyclic graphs.

Shortest-path sections introduce the main approaches for different graph conditions, including Dijkstra, Bellman-Ford, and Floyd-Warshall. Minimum spanning tree techniques then cover Kruskal and Prim's algorithms, while Union-Find provides an efficient structure for connectivity and cycle detection.

The final section applies these concepts to practical graph problems, focusing on algorithm selection, pattern recognition, edge cases, complexity, and optimization.

Each topic is separated into focused notes for easier learning, implementation, revision, and problem solving.
