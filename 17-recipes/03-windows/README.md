# Windows

Practical, step-by-step **Windows recipes** for managing local users, Remote Desktop, services, firewall rules, network shares, mapped drives, environment variables, and scheduled tasks.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Create Local User|Create and manage local user accounts, configure passwords, assign groups, and manage account settings|
|02|Configure Remote Desktop|Enable and configure Remote Desktop, manage access permissions, configure network settings, and verify remote connections|
|03|Configure Windows Service|Create, configure, start, stop, restart, enable, disable, and troubleshoot Windows services|
|04|Configure Firewall Rule|Create and manage inbound and outbound firewall rules, configure ports and protocols, and verify firewall behavior|
|05|Setup Network Share|Create Windows network shares, configure share permissions and NTFS permissions, manage access, and verify shared folders|
|06|Map Network Drive|Map shared folders as network drives, configure persistent connections, manage credentials, and troubleshoot connectivity|
|07|Manage Environment Variables|Create, modify, remove, and inspect user and system environment variables and apply configuration changes|
|08|Create Scheduled Task|Create and configure scheduled tasks, define triggers and actions, manage execution settings, and troubleshoot task failures|

## Structure

The recipes progress from **local user management → Remote Desktop → Windows services → firewall rules → network sharing → mapped drives → environment variables → scheduled tasks**.

The first recipes establish basic Windows administration through local user management and Remote Desktop configuration. These provide the foundation for managing accounts and accessing Windows systems remotely.

Windows services and firewall rules then cover system processes and host-level network access. The service recipe focuses on controlling background services, while firewall recipes provide practical procedures for managing network traffic.

Network-share and mapped-drive recipes cover Windows file sharing and access to shared resources across a network. They address both creating shared resources and connecting to them from a Windows system.

The final recipes cover environment configuration and task automation. Environment variables provide a practical way to manage system and application configuration, while Scheduled Tasks allow recurring or event-driven automation.

Each recipe follows an **action-oriented workflow** with commands, configuration, expected results, verification steps, troubleshooting guidance, and important safety considerations.
