Practical, step-by-step **how-to guides** for performing common software development, system administration, DevOps, cloud, database, backend, frontend, and deployment tasks.

## Structure

The recipes progress from **version-control operations → operating-system administration → containerization → databases → backend and frontend setup → DevOps automation → cloud operations → application deployment**.

The first sections focus on practical Git operations and system administration. Git recipes cover recovery, history management, repository operations, and common version-control procedures, while Linux and Windows recipes cover everyday operating-system configuration and administration.

Docker recipes then provide repeatable procedures for containerizing applications, managing persistent data, connecting containers, building images, and maintaining development environments. Database recipes cover backup, restore, and migration workflows across common database systems.

Backend and frontend recipes focus on setting up applications and integrating common development capabilities such as authentication, validation, file uploads, API communication, and deployment.

The DevOps and cloud sections cover CI/CD, infrastructure, reverse proxies, SSL, configuration management, monitoring, cloud services, and application deployment. The final deployment section provides end-to-end procedures for deploying and maintaining applications in production environments.

Each recipe is designed as an **action-oriented procedure** with clear steps, commands, configuration, verification, and relevant considerations.
