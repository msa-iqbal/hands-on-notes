# YAML

Practical **YAML (YAML Ain't Markup Language)** notes covering syntax, data types, mappings, sequences, nesting, configuration, and common errors when working with structured data.

## Contents

| #   | Topic         | What You'll Find                                                                                                                   |
| --- | ------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 01  | Basics        | YAML fundamentals, syntax, indentation, structure, comments, document markers, and common YAML usage                               |
| 02  | Data Types    | Strings, numbers, booleans, null values, dates, explicit types, and YAML scalar values                                             |
| 03  | Objects       | YAML mappings, key-value pairs, nested mappings, object-like structures, and practical configuration examples                      |
| 04  | Arrays        | YAML sequences, lists, nested sequences, arrays of objects, flow style, and practical usage                                        |
| 05  | Nesting       | Nested mappings, nested sequences, mixed structures, indentation, and organizing complex YAML data                                 |
| 06  | Common Errors | Indentation errors, invalid syntax, incorrect data types, duplicate keys, quoting issues, malformed structures, and parsing errors |

## Structure

YAML topics are organized from fundamental syntax and data types to mappings, sequences, nested structures, and common errors.

Each numbered file focuses on a specific YAML concept so individual features and rules can be learned and referenced independently.

The numbering provides a consistent learning sequence while keeping YAML syntax and practical configuration structures easy to locate.
