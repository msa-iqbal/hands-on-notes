# JSON

Practical **JSON (JavaScript Object Notation)** notes covering syntax, data types, objects, arrays, nesting, validation, and common errors when working with structured data.

## Structure

JSON topics are organized from fundamental syntax and data types to objects, arrays, nested structures, and common errors.

Each numbered file focuses on a specific JSON concept so individual features and rules can be learned and referenced independently.

The numbering provides a consistent learning sequence while keeping JSON syntax and practical data structures easy to locate.
