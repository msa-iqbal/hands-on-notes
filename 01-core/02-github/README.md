## Structure

GitHub topics are organized around the main features and workflows used when hosting, managing, collaborating on, and automating software projects.

Each numbered file focuses on a specific GitHub feature or workflow so individual concepts can be studied and referenced independently.

The numbering provides a consistent learning sequence while keeping the GitHub documentation easy to navigate and maintain.
