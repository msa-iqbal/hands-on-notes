## Structure

Networking topics are organized into numbered directories, progressing from fundamental concepts to advanced technologies, practical configuration, troubleshooting, and career development.

Each main directory contains a `readme.md` file that introduces its topic and provides an overview of the related notes.

Individual Markdown files focus on specific concepts, protocols, technologies, commands, or practical exercises. This structure makes topics easier to study independently and reference when needed.

The numbering provides a consistent learning sequence while keeping related networking concepts grouped together.

## Learning Approach

1. **Learn the fundamentals** — Understand network components, communication models, addressing, and protocols.
2. **Understand network operations** — Study switching, routing, VLANs, wireless networking, and packet forwarding.
3. **Configure network services** — Practice NAT, firewalls, VPNs, DHCP, DNS, QoS, and ISP-related services.
4. **Work with MikroTik RouterOS** — Apply networking concepts through router configuration, administration, and automation.
5. **Practice in labs** — Build virtual network environments, complete exercises, and implement practical projects.
6. **Develop troubleshooting skills** — Diagnose connectivity, routing, security, and performance problems systematically.
7. **Prepare for professional growth** — Review certification roadmaps, technical references, and interview questions.

## Goal

> Maintain a structured, practical networking knowledge base that makes networking concepts easier to learn, configure, troubleshoot, and apply in real-world environments—from basic computer networks to advanced routing, MikroTik RouterOS, and ISP infrastructure.
