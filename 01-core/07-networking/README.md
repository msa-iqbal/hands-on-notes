# Networking

Practical **computer networking** notes covering network fundamentals, OSI and TCP/IP models, transport protocols, IP addressing, DNS, DHCP, ports, sockets, proxies, and VPNs.

|#|Topic|What You'll Find|

## Structure

Networking topics are organized from fundamental communication concepts to network models, transport protocols, addressing, network services, and common infrastructure components.

Each numbered file focuses on a specific networking concept so individual topics can be learned and referenced independently.

The numbering provides a consistent learning sequence while keeping networking concepts, protocols, and practical troubleshooting knowledge easy to locate.
