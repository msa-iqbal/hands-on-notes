# 🗁 Network Models

Network models provide a structured way to understand how devices communicate across a network. They divide network communication into logical layers, with each layer responsible for specific networking functions.

Network models help engineers understand, design, troubleshoot, and secure communication systems. They also provide a common framework for developing networking protocols and ensuring interoperability between different devices and vendors.

The two major networking models are:

* **OSI Model:** A seven-layer conceptual reference model developed by the International Organization for Standardization (ISO).
* **TCP/IP Model:** A practical networking model based on the protocol suite used by the Internet.

Understanding these models is essential for learning IP addressing, routing, switching, transport protocols, application protocols, and network troubleshooting.

### 🖆 Learning Objectives

After completing this section, you should be able to:

* Explain why network models are used.
* Understand the seven layers of the OSI model.
* Understand the layers of the TCP/IP model.
* Compare the OSI and TCP/IP models.
* Explain how data moves through networking layers.
* Understand encapsulation and decapsulation.
* Identify Protocol Data Units (PDUs) at different layers.
* Relate networking protocols and devices to their corresponding layers.
