# ISP Networking

Internet Service Provider (ISP) Networking covers the technologies, infrastructure, protocols, and operational practices used to deliver internet connectivity to residential customers, businesses, and other organizations.

An ISP operates network infrastructure that connects customer networks to the global internet through access networks, aggregation networks, core routers, upstream providers, Internet Exchange Points (IXPs), and other service-provider facilities.

This section explores ISP architecture, fiber-optic infrastructure, broadband technologies, subscriber authentication, IP address management, routing, bandwidth planning, and customer network operations.

# 🗁 Learning Objectives

After completing this section, you should be able to:

* Understand ISP architecture and service-provider infrastructure.
* Explain core, aggregation, access, and last-mile networks.
* Understand fiber-optic communication.
* Explain GPON and EPON technologies.
* Configure and troubleshoot PPPoE services.
* Understand subscriber authentication using RADIUS.
* Configure hotspot and captive portal services.
* Understand Carrier-Grade NAT.
* Plan public and private IP address allocation.
* Understand BGP and upstream peering.
* Explain Internet Exchange Points and IP transit.
* Calculate bandwidth requirements and plan network capacity.
* Manage subscriber connectivity and customer networks.
* Build and troubleshoot a practical ISP network.

# 🗁 Recommended Learning Approach

Follow the documentation in sequence:

* Start with ISP fundamentals and network architecture.
* Understand last-mile connectivity and fiber-optic infrastructure.
* Study PON technologies and subscriber access methods.
* Learn PPPoE, hotspot, and RADIUS integration.
* Understand CGNAT and IP address planning.
* Study BGP, upstream peering, IXP, and transit.
* Learn bandwidth planning and customer network management.
* Complete the practical ISP labs.

By the end of this section, you should understand how an ISP delivers internet connectivity, manages subscriber access, operates its infrastructure, and connects to the global internet.
