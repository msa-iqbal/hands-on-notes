# Labs and Practice

The `19-labs-and-practice` directory contains practical networking exercises designed to develop hands-on skills through real network configurations, testing, troubleshooting, and implementation.

The purpose of these labs is to turn theoretical networking knowledge into practical engineering experience.

You will work with:

* Virtual networking environments.
* MikroTik CHR.
* VirtualBox.
* GNS3.
* EVE-NG.
* IP addressing and subnetting.
* Routing and switching.
* VLANs.
* Firewall configuration.
* VPN connectivity.
* ISP network scenarios.
* Complete networking projects.

# 🗁 Learning Objectives

After completing this section, you should be able to:

* Build virtual networking environments.
* Configure routers, switches, and network interfaces.
* Design IP addressing schemes.
* Perform subnetting calculations.
* Configure static and dynamic routing.
* Implement VLAN segmentation.
* Configure firewall and NAT policies.
* Establish VPN connections.
* Troubleshoot network connectivity.
* Design and implement practical ISP scenarios.
* Complete end-to-end networking projects.

# 🗁 Lab Documentation Standard

Each practical lab should contain:

* **Objective:** What you will learn.
* **Topology:** Network diagram and device connections.
* **Requirements:** Hardware, software, and configurations.
* **IP Addressing:** Network and interface addressing plan.
* **Configuration:** Step-by-step commands and settings.
* **Verification:** Commands and tests to confirm functionality.
* **Troubleshooting:** Common problems and solutions.
* **Expected Results:** What a successful implementation looks like.
* **Practice Tasks:** Additional exercises to strengthen understanding.

# 🗁 Practical Learning Approach

For every lab:

* Understand the topology before configuring devices.
* Identify the role of every network device.
* Plan IP addresses before assigning them.
* Configure one component at a time.
* Verify each configuration step.
* Test communication between devices.
* Inspect routing tables and firewall policies.
* Capture packets when necessary.
* Document problems and their solutions.
* Rebuild the lab independently after completing it.

# 🗁 Final Goal

The goal of this section is to develop the ability to design, configure, verify, and troubleshoot real-world networks.

By completing these exercises, you will gain practical experience with small office networks, enterprise-style topologies, VPN connections, routing infrastructure, and ISP network scenarios.
