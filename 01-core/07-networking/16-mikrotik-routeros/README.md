# MikroTik RouterOS

MikroTik RouterOS is a powerful network operating system used to build, manage, and maintain networks ranging from small home installations to enterprise networks and Internet Service Provider (ISP) infrastructure.

This section provides a structured, practical guide to MikroTik RouterOS, with a primary focus on RouterOS v7. It covers device administration, interfaces, bridging, IP addressing, DHCP, NAT, firewall, routing, VLANs, wireless networking, VPNs, ISP services, load balancing, monitoring, automation, and practical deployment projects.

The goal is to develop practical MikroTik networking skills through clear explanations, RouterOS CLI examples, configuration workflows, troubleshooting procedures, and hands-on labs.

# 🗁 Learning Objectives

* Understand MikroTik hardware and RouterOS architecture.
* Navigate RouterOS using WinBox, WebFig, CLI, and SSH.
* Configure and manage physical and logical interfaces.
* Build Ethernet bridges and configure VLANs.
* Configure IPv4, DHCP, DNS, and related network services.
* Establish internet connectivity using routing and NAT.
* Implement firewall rules and router security.
* Configure static routing, OSPF, BGP, and policy-based routing.
* Deploy wireless networks and manage wireless security.
* Implement bandwidth management using queues and QoS.
* Configure VPNs and network tunnels.
* Deploy PPPoE, Hotspot, RADIUS, and other ISP services.
* Configure WAN failover and PCC load balancing.
* Monitor network performance and troubleshoot connectivity.
* Automate RouterOS tasks using scripts, schedulers, and APIs.
* Build complete network solutions through practical projects.

# 🗁 Practical Learning Approach

Each topic should combine conceptual understanding with practical RouterOS configuration.

The recommended workflow is:

* Understand the networking concept.
* Study the relevant RouterOS menus and commands.
* Review configuration examples.
* Apply the configuration in a lab environment.
* Verify the result using operational commands.
* Troubleshoot common configuration problems.
* Document the completed lab and important observations.

Use MikroTik CHR with a supported virtualization platform or physical MikroTik hardware to practice configurations.
