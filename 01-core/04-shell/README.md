## Structure

Shell topics are organized from fundamental shell concepts to language-specific features and practical scripting techniques.

Bash and Zsh are covered separately where their behavior, configuration, or features differ, while common shell concepts remain in the appropriate general sections.

Each numbered file focuses on a specific shell concept so individual topics can be learned, referenced, and reused independently.
