# Regex

Practical **regular expression (Regex)** notes covering pattern fundamentals, character classes, quantifiers, anchors, groups, lookarounds, and practical pattern examples.

## Contents

|#|Topic|What You'll Find|
|---|---|---|
|01|Basics|Regex fundamentals, patterns, literals, metacharacters, escaping, matching, and common syntax|
|02|Character Classes|Character sets, ranges, negated classes, predefined classes, Unicode classes, and character matching|
|03|Quantifiers|Greedy and lazy quantifiers, repetition, optional patterns, exact counts, ranges, and practical usage|
|04|Anchors|Start and end anchors, word boundaries, line boundaries, multiline behavior, and position matching|
|05|Groups|Capturing groups, non-capturing groups, named groups, backreferences, alternation, and grouping patterns|
|06|Lookahead and Lookbehind|Positive and negative lookahead, positive and negative lookbehind, zero-width assertions, and practical use cases|
|07|Examples|Practical Regex patterns for validation, searching, extraction, replacement, parsing, and common development tasks|

## Structure

Regex topics are organized from fundamental pattern syntax to advanced matching techniques and practical examples.

Each numbered file focuses on a specific Regex concept so individual features can be learned and referenced independently.

The numbering provides a consistent learning sequence while keeping Regex syntax and commonly used patterns easy to locate.
