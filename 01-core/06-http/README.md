# HTTP

Practical **HTTP and web communication** notes covering requests, responses, methods, headers, status codes, cookies, sessions, caching, and HTTPS.

## Contents

|#|Topic|What You'll Find|
|---|---|---|
|01|Basics|HTTP fundamentals, client-server communication, request-response model, HTTP versions, and essential concepts|
|02|Request|HTTP request structure, request line, headers, body, parameters, payloads, and request lifecycle|
|03|Response|HTTP response structure, status line, headers, body, response data, and response lifecycle|
|04|Methods|HTTP methods including GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS, and their common use cases|
|05|Headers|Request and response headers, standard headers, content negotiation, caching headers, authentication headers, and custom headers|
|06|Status Codes|HTTP status code classes, 1xx, 2xx, 3xx, 4xx, and 5xx responses, common status codes, and practical usage|
|07|Cookies|Cookie fundamentals, setting and reading cookies, attributes, security options, expiration, and browser behavior|
|08|Sessions|Session fundamentals, session management, session identifiers, authentication sessions, expiration, and session security|
|09|Caching|HTTP caching, cache-control directives, validators, ETags, conditional requests, browser caching, and proxy caching|
|10|HTTPS|HTTPS fundamentals, TLS, certificates, encryption, authentication, certificate validation, and secure HTTP communication|

## Structure

HTTP topics are organized from fundamental request-response concepts to the mechanisms used for state management, caching, and secure communication.

Each numbered file focuses on a specific HTTP concept so individual topics can be learned and referenced independently.

The numbering provides a consistent learning sequence while keeping HTTP behavior, terminology, and practical usage easy to locate.
