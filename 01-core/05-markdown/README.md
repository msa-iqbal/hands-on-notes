## Structure

Markdown topics are organized from basic syntax and document structure to commonly used formatting features and advanced GitHub-specific capabilities.

Each numbered file focuses on a specific Markdown concept so individual features can be learned and referenced independently.

The numbering provides a consistent learning sequence while keeping Markdown syntax and documentation techniques easy to locate.
