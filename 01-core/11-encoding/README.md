# Encoding

Practical **data encoding and character encoding** notes covering ASCII, Unicode, UTF-8, Base64, URL encoding, and common encoding concepts used in software development and web technologies.

## Contents

| #   | Topic        | What You'll Find                                                                                             |

| 02  | ASCII        | ASCII character set, character codes, control characters, printable characters, and ASCII limitations        |
| 03  | Unicode      | Unicode standard, code points, characters, planes, Unicode characters, and international text representation |
| 04  | UTF-8        | UTF-8 encoding, byte representation, variable-length encoding, Unicode compatibility, and practical usage    |

## Structure

Encoding topics are organized from fundamental concepts and ASCII to Unicode, UTF-8, Base64, and URL encoding.

Each numbered file focuses on a specific encoding concept so individual formats, standards, and techniques can be learned and referenced independently.

The numbering provides a consistent learning sequence while keeping encoding concepts easy to locate and understand.
