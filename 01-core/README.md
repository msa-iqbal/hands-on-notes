## Structure

Core topics are organized by subject so fundamental development concepts can be found without searching through unrelated areas.

Each topic has its own directory with a `README.md` and numbered notes covering the subject from fundamentals to more advanced concepts.

The numbering provides a consistent learning and navigation order while keeping the repository easy to maintain.

## Focus

- Version control and collaboration
- Command-line development
- Shell scripting
- Technical documentation
- Web communication
- Computer networking
- Regular expressions
- Structured data formats
- Character and data encoding
- Everyday developer fundamentals

## Goal

> Maintain a practical and organized foundation of core technical knowledge that can be quickly learned, reviewed, referenced, and reused throughout software development.
