## Structure

Git topics are organized in a practical sequence, starting with fundamental concepts and progressing toward advanced version-control workflows.

Each numbered file focuses on a specific Git concept so individual topics can be studied or referenced without navigating through a large single document.

The numbering provides a consistent learning order while keeping related Git concepts easy to locate.
