# Terminal

Practical **terminal and command-line** notes covering commands, navigation, file management, input/output, pipes, redirection, processes, and productivity shortcuts.

## Contents

|#|Topic|What You'll Find|
|---|---|---|

|02|Commands|Common terminal commands, command syntax, options, arguments, command discovery, and practical usage|
|03|Navigation|Working with paths, current directories, absolute and relative paths, changing directories, and directory navigation|
|04|Files and Directories|Creating, copying, moving, renaming, deleting, listing, searching, and managing files and directories|
|05|Input and Output|Standard input, standard output, standard error, command output, streams, and file descriptors|

## Structure

Terminal topics are organized from basic command-line concepts to practical file management, command composition, process management, and productivity techniques.

Each numbered file focuses on a specific terminal concept so commands and workflows can be learned or referenced independently.

The numbering provides a consistent learning sequence while keeping frequently used terminal knowledge easy to locate.
