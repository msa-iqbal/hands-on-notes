# Next.js

Practical, structured notes for learning and building applications with **Next.js**.

## Contents

| #   | Topic              | What You'll Learn                                                                                            |
| --- | ------------------ | ------------------------------------------------------------------------------------------------------------ |
| 01  | Basics             | Next.js introduction, project setup, project structure, configuration, and development workflow              |
| 02  | Routing            | App Router, pages, layouts, dynamic routes, route groups, parallel routes, navigation, and route handlers    |
| 03  | Rendering          | Rendering fundamentals, static and dynamic rendering, server/client rendering, and streaming                 |
| 04  | Server Components  | Server and Client Components, `'use client'`, component boundaries, and server-client patterns               |
| 05  | Data Fetching      | Data fetching, caching, revalidation, loading and error states, and Server Actions                           |
| 06  | API                | Route Handlers, requests, responses, headers, cookies, redirects, and API patterns                           |
| 07  | Middleware & Proxy | Middleware, Proxy, rewrites, redirects, and request processing                                               |
| 08  | Assets & Styling   | Images, fonts, metadata, CSS, and static assets                                                              |
| 09  | Authentication     | Authentication, authorization, sessions, cookies, and authentication patterns                                |
| 10  | Performance        | Performance fundamentals, code splitting, image and font optimization, caching, and bundle optimization      |
| 11  | Deployment         | Builds, environment variables, static export, Node.js, Docker, platform deployment, and production checklist |

## Structure

The notes progress from **Next.js fundamentals → routing and rendering → Server Components → data fetching and APIs → request processing → assets and authentication → performance → deployment**.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Focus

- Next.js fundamentals and project structure
- App Router and navigation
- Static, dynamic, server, and client rendering
- Server and Client Components
- Data fetching, caching, and revalidation
- Route Handlers and API development
- Middleware and Proxy
- Images, fonts, metadata, and styling
- Authentication and authorization
- Performance optimization
- Production builds and deployment
- Docker and platform deployment

## Goal

> Learn Next.js systematically, understand its full application architecture, build production-ready applications, and keep practical knowledge easy to find.
