# Forms

Practical, structured notes for building, validating, and managing **frontend forms**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Form Basics|Form structure, inputs, labels, buttons, submission, and form data|
|02|Controlled Forms|Controlled inputs, state synchronization, change handling, and submission|
|03|Uncontrolled Forms|Uncontrolled inputs, refs, native form behavior, and form data|
|04|Validation|Client-side validation, required fields, constraints, and validation flow|
|05|Schema Validation|Validation schemas, type-safe validation, reusable rules, and schema libraries|
|06|Error Handling|Validation errors, server errors, error messages, and error states|
|07|File Uploads|File inputs, previews, validation, multipart forms, and upload handling|
|08|Form Patterns|Reusable form patterns, field components, dynamic forms, and scalable form architecture|

## Structure

The notes progress from **form fundamentals → controlled and uncontrolled forms → validation → schema validation → error handling → file uploads → reusable form patterns**.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Focus

- Form fundamentals
- Controlled and uncontrolled inputs
- Form state management
- Client-side validation
- Schema-based validation
- Error handling and feedback
- File uploads
- Dynamic and reusable forms
- Accessible form design
- Scalable form patterns

## Goal

> Learn how to build reliable, accessible, and maintainable forms with clear validation, error handling, and reusable patterns.
