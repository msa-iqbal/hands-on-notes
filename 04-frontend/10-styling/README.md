# Styling

Practical, structured notes for designing and managing **frontend styling systems**.

## Contents

| #   | Topic            | What You'll Learn                                                                             |
| --- | ---------------- | --------------------------------------------------------------------------------------------- |
| 01  | CSS Architecture | CSS organization, naming conventions, scalability, maintainability, and architecture patterns |
| 02  | CSS Modules      | Scoped styles, component-level CSS, composition, naming, and reusable styles                  |
| 03  | CSS-in-JS        | CSS-in-JS concepts, dynamic styles, component styling, theming, and runtime considerations    |
| 04  | Tailwind CSS     | Utility-first styling, responsive design, variants, customization, and component styling      |
| 05  | Design Tokens    | Colors, spacing, typography, sizing, themes, and shared design values                         |
| 06  | Theming          | Theme architecture, light/dark modes, CSS variables, theme switching, and scalable theming    |

## Structure

The notes progress from **CSS architecture → CSS Modules → CSS-in-JS → Tailwind CSS → design tokens → theming**.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Focus

- CSS architecture and organization
- Component-scoped styling
- CSS Modules
- CSS-in-JS
- Tailwind CSS
- Design tokens
- CSS variables
- Light and dark themes
- Scalable styling systems
- Maintainable frontend styling

## Goal

> Learn modern frontend styling approaches, choose appropriate styling strategies, and build consistent, scalable, and maintainable UI systems.
