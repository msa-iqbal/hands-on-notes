# React

Practical, structured notes for learning and building applications with **React**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Basics|React introduction, project setup, JSX, components, props, and composition|
|02|Components|Functional components, props, composition, children, reusable components, and patterns|
|03|State|State basics, `useState`, state updates, derived state, lifting state, and state architecture|
|04|Hooks|Built-in hooks, custom hooks, hook patterns, and reusable logic|
|05|Context|Context API, providers, consuming context, and context patterns|
|06|Events & Forms|Events, handlers, controlled and uncontrolled components, and form handling|
|07|Rendering|Rendering, conditional rendering, lists, keys, reconciliation, render/commit, and Strict Mode|
|08|Performance|Memoization, `useMemo`, `useCallback`, code splitting, lazy loading, and rendering optimization|
|09|Data Fetching|Data fetching, loading and error states, caching, and server state|
|10|Advanced|Refs, portals, error boundaries, Suspense, concurrent rendering, and React architecture|

## Structure

The notes progress from **React fundamentals → components and state → hooks and context → events and forms → rendering → performance → data fetching → advanced React concepts**.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Focus

- React fundamentals and JSX
- Component design and composition
- Props and state management
- React Hooks and custom hooks
- Context and shared state
- Events and forms
- Rendering and reconciliation
- Performance optimization
- Data fetching and server state
- Advanced React features and architecture
- Reusable and maintainable React patterns

## Goal

> Learn React systematically, understand how it works, build maintainable applications, and keep practical knowledge easy to find.
