# Performance

Practical, structured notes for improving **frontend application performance** and user experience.

## Contents

| #   | Topic                 | What You'll Learn                                                                        |
| --- | --------------------- | ---------------------------------------------------------------------------------------- |
| 01  | Performance Basics    | Performance fundamentals, metrics, bottlenecks, profiling, and optimization principles   |
| 02  | Bundle Size           | Bundle analysis, dependency size, tree shaking, minification, and optimization           |
| 03  | Code Splitting        | Route-based splitting, component splitting, dynamic imports, and chunk optimization      |
| 04  | Lazy Loading          | Lazy loading components, routes, images, resources, and deferred content                 |
| 05  | Rendering Performance | Rendering behavior, re-renders, reconciliation, memoization, and rendering optimization  |
| 06  | Image Optimization    | Image formats, compression, responsive images, sizing, and loading strategies            |
| 07  | Font Optimization     | Font loading, formats, subsetting, preloading, and rendering performance                 |
| 08  | Caching               | Browser caching, HTTP caching, application caching, invalidation, and revalidation       |
| 09  | Web Vitals            | Core Web Vitals, LCP, INP, CLS, measurement, and optimization                            |
| 10  | Performance Debugging | DevTools, profiling, performance traces, bottleneck analysis, and optimization workflows |

## Structure

The notes progress from **performance fundamentals → bundle optimization → code splitting and lazy loading → rendering → assets → caching → Web Vitals → performance debugging**.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Focus

- Frontend performance fundamentals
- Bundle and dependency optimization
- Code splitting and lazy loading
- Rendering performance
- Image and font optimization
- Browser and application caching
- Core Web Vitals
- Performance measurement
- Profiling and debugging
- Practical optimization strategies

## Goal

> Understand frontend performance systematically, identify bottlenecks, and build fast, responsive, and efficient applications.
