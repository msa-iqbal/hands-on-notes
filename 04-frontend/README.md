# Frontend

Practical, structured notes for learning and building **modern frontend applications**.

## Structure

The notes progress from **frontend frameworks and styling → components, state, forms, and routing → data fetching and testing → architecture and performance**.

Framework-specific knowledge is kept separate from general frontend concepts so each area can be learned, referenced, and expanded independently.

## Focus

- React and Next.js
- Modern frontend development
- Component design and architecture
- State and form management
- Routing and navigation
- API and data fetching
- Testing and quality
- CSS and styling systems
- Frontend architecture
- Performance optimization
- Accessibility and maintainability
- Production-ready frontend practices

## Goal

> Learn frontend development systematically, understand how its major parts work together, and build maintainable, scalable, and performant applications.
