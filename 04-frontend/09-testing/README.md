# Testing

Practical, structured notes for testing **frontend applications and components**.

## Contents

| #   | Topic               | What You'll Learn                                                                                |
| --- | ------------------- | ------------------------------------------------------------------------------------------------ |
| 01  | Testing Strategy    | Testing principles, test pyramid, test boundaries, and testing strategy                          |
| 02  | Unit Testing        | Testing functions, utilities, isolated logic, assertions, and test organization                  |
| 03  | Component Testing   | Component behavior, rendering, user interactions, props, state, and accessibility                |
| 04  | Integration Testing | Testing multiple components, modules, APIs, and application workflows together                   |
| 05  | E2E Testing         | Browser-based testing, user journeys, navigation, forms, and complete workflows                  |
| 06  | Mocking             | Mock functions, modules, APIs, network requests, timers, and external dependencies               |
| 07  | Test Coverage       | Coverage metrics, branches, statements, functions, thresholds, and coverage analysis             |
| 08  | Testing Patterns    | Test organization, reusable utilities, test data, fixtures, isolation, and maintainable patterns |

## Structure

The notes progress from **testing fundamentals → unit and component testing → integration and E2E testing → mocking → coverage → scalable testing patterns**.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Focus

- Frontend testing strategy
- Unit and component testing
- Integration testing
- End-to-end testing
- User interaction testing
- Mocking and test doubles
- API and network testing
- Test coverage
- Test organization and maintainability
- Reliable testing patterns

## Goal

> Build reliable frontend applications through meaningful tests that verify behavior, user interactions, integrations, and critical workflows.
