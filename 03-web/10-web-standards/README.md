# Web Standards

Practical, structured notes for understanding and applying **web standards**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Web Standards|Standards, specifications, organizations, and the modern web platform|
|02|HTML Standards|HTML specifications, semantics, elements, attributes, and conformance|
|03|CSS Standards|CSS specifications, features, syntax, and standards-based styling|
|04|DOM Standards|DOM specifications, interfaces, events, and document APIs|
|05|Web API Standards|Web API specifications, interfaces, browser APIs, and platform features|
|06|Browser Compatibility|Compatibility, interoperability, browser differences, and support|
|07|Progressive Enhancement|Building resilient experiences with progressive enhancement|
|08|Feature Detection|Detecting browser capabilities and handling unsupported features|

## Structure

The notes progress from **web standards fundamentals → HTML, CSS, DOM, and Web APIs → browser compatibility → progressive enhancement → feature detection**.

Each topic is separated into focused notes for easier learning and reference.

## Focus

- Web standards and specifications
- HTML and CSS standards
- DOM and Web API standards
- Browser compatibility
- Interoperability
- Progressive enhancement
- Feature detection
- Standards-based web development

## Goal

> Understand web standards, build interoperable applications, and create web experiences that work reliably across browsers and environments.
