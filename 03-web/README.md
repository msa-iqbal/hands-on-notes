# Web

Practical, structured notes for learning and building with **modern web technologies**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|HTML|HTML structure, elements, attributes, semantics, forms, tables, media, accessibility|
|02|CSS|CSS fundamentals, selectors, layout, Flexbox, Grid, responsive design, animations, modern CSS|
|03|JavaScript|Browser JavaScript, script loading, modules, `defer`, `async`, and browser-specific behavior|
|04|TypeScript|Browser TypeScript, compilation, modules, browser builds, and source maps|
|05|Browser|DevTools, storage, rendering, browser security, and browser features|
|06|DOM|DOM structure, element manipulation, events, forms, observers, and performance|
|07|Web API|Fetch, URL, storage, workers, communication, media, and browser APIs|
|08|Accessibility|WCAG, semantic HTML, keyboard navigation, focus, screen readers, ARIA, and accessible forms|
|09|Performance|Rendering, Core Web Vitals, JavaScript, CSS, assets, networking, caching, and lazy loading|
|10|Web Standards|HTML, CSS, DOM, Web APIs, browser compatibility, progressive enhancement, and feature detection|

## Structure

The notes progress from **web fundamentals → HTML and CSS → browser JavaScript and TypeScript → browser internals and DOM → Web APIs → accessibility → performance → web standards**.

Each area is separated into focused notes so topics can be learned, referenced, and expanded independently.

## Focus

- HTML and semantic markup
- CSS and modern layout
- Browser JavaScript and TypeScript
- Browser internals and DevTools
- DOM manipulation and events
- Web APIs
- Accessibility
- Web performance
- Browser compatibility and standards
- Practical, standards-based web development

## Goal

> Learn the web systematically, understand how browsers and web technologies work together, and keep practical knowledge easy to find.
