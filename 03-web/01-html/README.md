# HTML

Practical, structured notes for learning and using **HTML**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Basics|Introduction, document structure, `DOCTYPE`, head/body, attributes, comments|
|02|Elements|Headings, paragraphs, links, lists, `div`, `span`, text, and common elements|
|03|Attributes|Global attributes, `id`, `class`, data attributes, boolean attributes, custom attributes|
|04|Semantic HTML|`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`|
|05|Forms|Forms, inputs, labels, selects, textareas, buttons, validation, form data|
|06|Tables|Tables, rows, headings, sections, and accessible tables|
|07|Media|Images, audio, video, `picture`, responsive images, embedded content|
|08|Accessibility|Accessible HTML, landmarks, heading hierarchy, labels, alt text, ARIA basics|

## Structure

The notes progress from **HTML fundamentals → elements and attributes → semantic HTML → forms and tables → media → accessibility**.

Each topic is separated into focused notes for easy learning and reference.

## Focus

- HTML fundamentals
- Document structure and elements
- Attributes and semantic HTML
- Forms and validation
- Tables and accessible markup
- Images, audio, and video
- Responsive and embedded content
- Web accessibility
- Practical HTML patterns

## Goal

> Learn HTML systematically, write semantic and accessible markup, and keep practical knowledge easy to find.
