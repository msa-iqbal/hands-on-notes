# Web API

Practical, structured notes for working with **browser Web APIs**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Fetch|Requests, responses, headers, cancellation, and error handling|
|02|URL|`URL`, `URLSearchParams`, and URL pattern matching|
|03|Storage|Local storage, session storage, and IndexedDB|
|04|Workers|Web Workers, Shared Workers, and Service Workers|
|05|Communication|WebSocket, Server-Sent Events, and Broadcast Channel|
|06|Media|Media devices, camera, microphone, and screen capture|
|07|Other APIs|Clipboard, Geolocation, Notifications, Intersection Observer, Resize Observer|

## Structure

The notes progress from **network requests and URL handling → browser storage → background workers → real-time communication → media APIs → other browser capabilities**.

Each API is separated into focused notes for easier learning and reference.

## Focus

- Fetch API and HTTP requests
- URL and URL parameter handling
- Browser storage
- Web, Shared, and Service Workers
- WebSocket and Server-Sent Events
- Media devices and screen capture
- Clipboard and Geolocation
- Notifications
- Observer APIs

## Goal

> Understand and use browser Web APIs effectively to build capable, interactive, and reliable web applications.
