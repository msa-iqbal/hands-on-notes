# CSS

Practical, structured notes for learning and using **CSS**.

## Contents

| #   | Topic                | What You'll Learn                                                                        |
| --- | -------------------- | ---------------------------------------------------------------------------------------- |
| 01  | Basics               | CSS introduction, syntax, inclusion, cascade, inheritance, specificity                   |
| 02  | Selectors            | Element, class, ID, attribute, pseudo-class, pseudo-element selectors, combinators       |
| 03  | Box Model            | Width, height, margin, padding, borders, `box-sizing`, overflow                          |
| 04  | Layout               | Display, normal flow, floats, positioning, `z-index`, stacking contexts                  |
| 05  | Flexbox              | Flex containers, items, alignment, and common layout patterns                            |
| 06  | Grid                 | Grid containers, items, tracks, template columns/rows, areas, common patterns            |
| 07  | Responsive           | Responsive design, media queries, breakpoints, mobile-first, container queries           |
| 08  | Typography           | Fonts, font sizes, line height, text properties, web fonts                               |
| 09  | Colors & Backgrounds | Colors, backgrounds, gradients, and opacity                                              |
| 10  | Animations           | Transitions, transforms, keyframes, and animation patterns                               |
| 11  | Variables            | Custom properties, fallbacks, and theming                                                |
| 12  | Modern CSS           | Logical properties, CSS functions, `clamp()`, `calc()`, `min()`, `max()`, modern layouts |

## Structure

The notes progress from **CSS fundamentals → selectors and box model → layout systems → responsive design → styling → animations → variables → modern CSS**.

Each topic is separated into focused notes for easy learning and reference.

## Focus

- CSS fundamentals
- Selectors and specificity
- Box model and layout
- Flexbox and Grid
- Responsive and adaptive design
- Typography and visual styling
- Colors and backgrounds
- Transitions and animations
- CSS custom properties and theming
- Modern CSS functions and layout features
- Practical and reusable CSS patterns

## Goal

> Learn CSS systematically, build responsive and maintainable layouts, and keep practical knowledge easy to find.
