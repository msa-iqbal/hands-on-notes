# Browser

Practical, structured notes for understanding and working with **web browsers**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|DevTools|Elements, Console, Network, Sources, Application, Performance, Security|
|02|Storage|Cookies, local storage, session storage, IndexedDB, storage quotas|
|03|Rendering|Rendering pipeline, DOM, CSSOM, render tree, layout, paint, compositing|
|04|Browser Security|Same-origin policy, CORS, CSP, clickjacking, secure contexts|
|05|Browser Features|Tabs, windows, history, location, clipboard, notifications|

## Structure

The notes progress from **browser developer tools → client-side storage → rendering → browser security → browser features**.

Each topic is separated into focused notes for easier learning and reference.

## Focus

- Browser DevTools
- Client-side storage
- Browser rendering pipeline
- DOM and CSSOM
- Layout, paint, and compositing
- Same-origin policy and CORS
- Content Security Policy
- Browser security features
- Browser tabs, history, and location
- Clipboard and notifications

## Goal

> Understand how browsers work, diagnose web applications effectively, and use browser capabilities safely and efficiently.
