# Performance

Practical, structured notes for improving **web performance** and user experience.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Web Performance Basics|Performance fundamentals, metrics, bottlenecks, and optimization principles|
|02|Critical Rendering Path|HTML, CSS, JavaScript, rendering, and browser loading behavior|
|03|Core Web Vitals|Core Web Vitals, measurement, diagnostics, and optimization|
|04|LCP|Largest Contentful Paint, causes of slow LCP, and optimization techniques|
|05|INP|Interaction to Next Paint, responsiveness, and interaction optimization|
|06|CLS|Cumulative Layout Shift, layout stability, and prevention techniques|
|07|JavaScript Performance|Execution cost, main-thread work, memory, and runtime optimization|
|08|CSS Performance|CSS loading, selector efficiency, rendering cost, and optimization|
|09|Image Optimization|Image formats, sizing, compression, responsive images, and loading|
|10|Font Optimization|Font loading, formats, subsetting, caching, and rendering|
|11|Network Performance|Requests, latency, bandwidth, HTTP, compression, and connection optimization|
|12|Caching|Browser caching, HTTP caching, cache headers, and cache strategies|
|13|Lazy Loading|Lazy loading images, resources, components, and other content|

## Structure

The notes progress from **performance fundamentals → browser rendering → Core Web Vitals → JavaScript and CSS → assets → network and caching → lazy loading**.

Each topic is separated into focused notes for easier learning and reference.

## Focus

- Web performance fundamentals
- Critical rendering path
- Core Web Vitals
- JavaScript and CSS performance
- Image and font optimization
- Network optimization
- Browser and HTTP caching
- Lazy loading
- Performance measurement and debugging

## Goal

> Understand web performance systematically and build fast, responsive, stable, and efficient web applications.
