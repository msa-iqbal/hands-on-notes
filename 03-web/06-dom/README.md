# DOM

Practical, structured notes for understanding and working with the **Document Object Model (DOM)**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|DOM Basics|DOM concepts, structure, nodes, and the document tree|
|02|Document|The `document` object and document-level operations|
|03|Selecting Elements|Selecting and querying DOM elements|
|04|Creating Elements|Creating, inserting, and removing DOM elements|
|05|Modifying Elements|Changing content, properties, and element structure|
|06|Attributes|Reading, setting, removing, and managing attributes|
|07|Classes|Managing classes with `classList` and related APIs|
|08|Styles|Reading and modifying inline and computed styles|
|09|Events|Event types, listeners, propagation, and event handling|
|10|Event Delegation|Delegation patterns, bubbling, and dynamic elements|
|11|Forms|Working with form elements, values, submission, and validation|
|12|Observers|Mutation, Intersection, Resize, and related observer APIs|
|13|DOM Performance|Efficient DOM operations, reflows, repaints, and optimization|

## Structure

The notes progress from **DOM fundamentals → document and element manipulation → attributes, classes, and styles → events and forms → observers → performance**.

Each topic is separated into focused notes for easier learning and reference.

## Focus

- DOM structure and APIs
- Element selection and manipulation
- Attributes, classes, and styles
- Event handling and propagation
- Event delegation
- Forms and validation
- DOM observer APIs
- Reflow, repaint, and rendering impact
- Efficient DOM manipulation

## Goal

> Understand the DOM deeply, manipulate web pages effectively, and write efficient, maintainable browser-side code.
