# Accessibility

Practical, structured notes for building **accessible and inclusive web experiences**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Web Accessibility|Accessibility fundamentals, principles, and inclusive web development|
|02|WCAG Basics|WCAG principles, guidelines, conformance levels, and common requirements|
|03|Semantic HTML|Semantic elements and accessible document structure|
|04|Keyboard Navigation|Keyboard interaction, focus order, and keyboard accessibility|
|05|Focus Management|Focus behavior, focus states, focus trapping, and programmatic focus|
|06|Screen Readers|Screen reader concepts, navigation, announcements, and testing|
|07|ARIA|ARIA roles, states, properties, and appropriate usage|
|08|Color & Contrast|Color accessibility, contrast requirements, and non-color indicators|
|09|Accessible Forms|Labels, instructions, validation, errors, and form accessibility|

## Structure

The notes progress from **accessibility fundamentals → WCAG and semantic HTML → keyboard and focus management → assistive technologies → ARIA → visual accessibility → accessible forms**.

Each topic is separated into focused notes for easier learning and reference.

## Focus

- Web accessibility fundamentals
- WCAG principles and requirements
- Semantic and accessible HTML
- Keyboard navigation
- Focus management
- Screen reader support
- ARIA
- Color and contrast
- Accessible forms
- Accessibility testing

## Goal

> Build web applications that are usable, understandable, and accessible to people with different abilities and assistive technologies.
