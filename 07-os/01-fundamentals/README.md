# OS Fundamentals

Practical, structured notes for understanding **operating system concepts, system components, execution, hardware interaction, and system architecture**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Operating System Basics|Operating system purpose, responsibilities, components, resources, and core concepts|
|02|Kernel|Kernel responsibilities, kernel space, system resource management, and kernel architecture|
|03|User Space|User space, applications, libraries, runtime environments, and user-space processes|
|04|System Calls|System call concepts, user-kernel transitions, common system calls, and system call interfaces|
|05|Process vs Thread|Processes, threads, execution contexts, memory isolation, concurrency, and scheduling|
|06|Interrupts|Hardware and software interrupts, interrupt handling, interrupt controllers, and execution flow|
|07|Drivers|Device drivers, hardware abstraction, driver architecture, kernel interaction, and device management|
|08|System Architecture|Operating system architecture, monolithic kernels, microkernels, hybrid kernels, and system components|

## Structure

The notes progress from **operating system fundamentals → kernel and user space → system calls → processes and threads → interrupts and drivers → overall system architecture**.

The early topics establish how an operating system manages hardware and software resources. Later topics explain how applications interact with the kernel, how execution is organized, how hardware events are handled, and how operating system components are structured.

Each topic is separated into focused notes for easier learning, reference, and expansion.
