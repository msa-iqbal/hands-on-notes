# Networking

Practical, structured notes for understanding and managing **network stacks, interfaces, IP addressing, routing, DNS, sockets, firewalls, and network troubleshooting** across operating systems.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Network Stack|Network layers, protocols, encapsulation, TCP/IP, OSI model, and network communication flow|
|02|Network Interfaces|Network adapters, interface configuration, Ethernet, Wi-Fi, virtual interfaces, and interface management|
|03|IP|IPv4, IPv6, addresses, subnetting, CIDR, private and public addresses, and IP configuration|
|04|Routing|Routing tables, gateways, routes, static routing, dynamic routing concepts, and packet forwarding|
|05|DNS|Domain Name System, resolution, records, resolvers, caching, and DNS troubleshooting|
|06|Sockets|Sockets, ports, TCP and UDP, client-server communication, socket states, and network connections|
|07|Firewall|Firewall concepts, rules, ports, filtering, inbound and outbound traffic, and host-based firewall management|
|08|Network Debugging|Connectivity testing, packet analysis, DNS diagnostics, routing problems, port testing, and network troubleshooting|

## Structure

The notes progress from **network stack fundamentals → network interfaces → IP addressing → routing → DNS → sockets → firewalls → network debugging**.

The early topics establish how operating systems communicate over networks, from network interfaces and protocol layers to IP addressing and packet routing. DNS and sockets then explain how applications resolve names and establish network connections.

The final sections focus on controlling network traffic with firewalls and diagnosing connectivity, routing, DNS, port, and protocol problems.

Each topic is separated into focused notes for easier learning, reference, troubleshooting, and expansion.
