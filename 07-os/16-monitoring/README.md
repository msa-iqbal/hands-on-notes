# Monitoring

Practical, structured notes for monitoring **CPU, memory, storage, network, processes, system logs, and overall system performance**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|CPU|CPU utilization, load, cores, threads, frequency, temperature, and CPU performance metrics|
|02|Memory|RAM usage, available memory, swap, virtual memory, memory pressure, and memory monitoring|
|03|Storage|Disk usage, capacity, I/O, throughput, latency, disk health, and storage monitoring|
|04|Network|Network traffic, bandwidth, latency, packet loss, connections, interfaces, and network monitoring|
|05|Processes|Process CPU and memory usage, process states, resource consumption, and process monitoring|
|06|System Logs|System logs, event logs, journal entries, log levels, timestamps, filtering, and log analysis|
|07|Performance Monitoring|System performance metrics, bottleneck identification, baselines, resource correlation, and performance analysis|

## Structure

The notes progress from **CPU and memory → storage and network → processes and system logs → overall performance monitoring**.

The first sections focus on the primary system resources and how to measure their utilization, capacity, and behavior. Process monitoring connects resource usage to individual workloads, while system logs provide the events and diagnostic information needed to understand system behavior.

The final section brings these metrics together for performance analysis, helping identify resource bottlenecks, establish baselines, correlate system behavior, and investigate performance problems.

Each topic is separated into focused notes for easier learning, reference, troubleshooting, and expansion.
