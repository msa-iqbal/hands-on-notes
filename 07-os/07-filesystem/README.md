# Filesystem

Practical, structured notes for understanding and managing **filesystems, files, directories, storage, permissions, and filesystem performance** across operating systems.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Files & Directories|Files, directories, directory structures, metadata, and filesystem organization|
|02|Paths|Absolute paths, relative paths, path resolution, path components, and path conventions|
|03|File Types|Regular files, directories, symbolic links, device files, sockets, and other filesystem objects|
|04|Permissions|File ownership, read/write/execute permissions, access control, and permission models|
|05|Links|Hard links, symbolic links, link behavior, use cases, and differences between link types|
|06|Mounting|Mount points, mounting and unmounting filesystems, mount options, and persistent mounts|
|07|Filesystem Types|Filesystem concepts, common filesystem types, characteristics, and use cases|
|08|Storage|Storage devices, partitions, volumes, capacity, disk usage, and storage management|
|09|Filesystem Performance|Filesystem performance, I/O behavior, caching, throughput, latency, and performance analysis|

## Structure

The notes progress from **files and directories → paths and file types → permissions and links → mounting and filesystem types → storage → filesystem performance**.

The early topics establish how filesystems organize data and represent filesystem objects. Permissions and links explain access control and relationships between filesystem entries, while mounting connects filesystems to the operating system's directory structure.

The later sections cover filesystem types, storage organization, and performance characteristics such as I/O, caching, throughput, and latency.

Each topic is separated into focused notes for easier learning, reference, troubleshooting, and expansion.
