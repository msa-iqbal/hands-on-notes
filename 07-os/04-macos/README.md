# macOS

Practical, structured notes for learning, configuring, managing, developing on, and troubleshooting **macOS systems**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Basics|macOS architecture, system settings, terminal, and core operating system concepts|
|02|Filesystem|macOS filesystem, APFS, directories, volumes, and storage organization|
|03|Terminal|Shell fundamentals, Zsh, Homebrew, command-line tools, and terminal-based workflows|
|04|Processes|Processes, Activity Monitor, process inspection, and process management|
|05|Services|`launchd`, daemons, service configuration, and service management|
|06|Networking|Network settings, network tools, DNS, and SSH|
|07|Development|Xcode, command-line tools, Homebrew, and macOS development environment setup|

## Structure

The notes progress from **macOS fundamentals → filesystem and terminal → processes and services → networking → development environment**.

The early sections establish macOS architecture, storage, directories, and command-line usage. The process and service sections explain how applications and background services run and are managed.

The networking section covers common system networking and remote-access tools, while the development section focuses on preparing macOS for software development using Xcode, command-line tools, and Homebrew.

Each topic is separated into focused notes for easier learning, reference, troubleshooting, and expansion.
