# iOS

Practical, structured notes for understanding, developing, managing, debugging, and troubleshooting **iOS systems and applications**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Basics|iOS architecture, system frameworks, security model, and core platform concepts|
|02|Filesystem|iOS filesystem, application sandbox, app storage, and file management|
|03|Development|Xcode, Swift, SwiftUI, project structure, and iOS development workflows|
|04|App Lifecycle|Application lifecycle, background tasks, state management, and state restoration|
|05|Permissions|Application permissions, privacy controls, capabilities, and platform access|
|06|Debugging|Console logs, Xcode debugging, crash logs, diagnostics, and performance analysis|

## Structure

The notes progress from **iOS fundamentals → filesystem and sandboxing → development → application lifecycle → permissions and privacy → debugging and performance**.

The early sections establish iOS architecture, system frameworks, security, filesystem isolation, and application storage. The development section covers the primary tools and technologies used to build iOS applications.

The lifecycle and permissions sections explain how applications execute, handle background work, preserve state, and access protected system resources. The final section focuses on diagnosing application problems, analyzing crash logs, and investigating performance.

Each topic is separated into focused notes for easier learning, reference, troubleshooting, and expansion.
