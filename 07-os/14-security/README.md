# Security

Practical, structured notes for understanding and applying **operating system security, access control, sandboxing, isolation, encryption, secure boot, and system hardening**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Security Models|Security principles, threat models, trust boundaries, security domains, and operating system security models|
|02|Access Control|Authentication, authorization, permissions, access-control models, policies, and protected resources|
|03|Sandboxing|Sandboxing concepts, restricted execution environments, application restrictions, and sandbox security boundaries|
|04|Isolation|Process isolation, user isolation, filesystem isolation, virtual machines, containers, and security boundaries|
|05|Encryption|Encryption fundamentals, symmetric and asymmetric cryptography, key management, data at rest, and data in transit|
|06|Secure Boot|Secure Boot concepts, trusted boot chains, firmware verification, bootloader verification, and platform integrity|
|07|Security Hardening|System hardening, attack-surface reduction, secure configuration, patching, logging, monitoring, and security practices|

## Structure

The notes progress from **security models → access control → sandboxing and isolation → encryption → secure boot → security hardening**.

The early topics establish the security principles and access-control mechanisms used to protect operating system resources. Sandboxing and isolation then explain how systems restrict applications, processes, users, and workloads from affecting protected resources.

The later sections cover encryption and trusted boot mechanisms before bringing these concepts together through practical system-hardening techniques that reduce attack surfaces and strengthen overall system security.

Each topic is separated into focused notes for easier learning, reference, troubleshooting, and expansion.
