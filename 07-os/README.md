## Structure

The notes begin with **operating system fundamentals**, followed by platform-specific knowledge for **Linux, Windows, macOS, Android, and iOS**.

The platform-independent sections then cover the major operating system subsystems: **filesystems, processes, services, permissions, storage, networking, boot, security, virtualization, and monitoring**.

This separation keeps operating-system-specific commands and implementation details inside their respective platform directories while keeping common concepts in reusable cross-platform sections.

Each topic is separated into focused notes for easier learning, reference, troubleshooting, and expansion.
