# Storage

Practical, structured notes for understanding and managing **storage devices, disks, partitions, volumes, filesystems, mounting, and disk usage** across operating systems.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Storage Basics|Storage concepts, storage devices, capacity, units, interfaces, and storage architecture|
|02|Disks|Physical disks, HDDs, SSDs, disk devices, disk identification, and disk management|
|03|Partitions|Partition tables, partitions, partition types, MBR, GPT, and partition management|
|04|Volumes|Volumes, logical volumes, volume management, storage pools, and logical storage organization|
|05|Mounting|Mount points, mounting and unmounting filesystems, mount options, and persistent mounts|
|06|Filesystems|Filesystem concepts, filesystem structures, common filesystem types, formatting, and filesystem management|
|07|Disk Monitoring|Disk usage, capacity monitoring, I/O monitoring, health checks, performance metrics, and storage diagnostics|

## Structure

The notes progress from **storage fundamentals → disks and partitions → volumes → mounting → filesystems → disk monitoring**.

The early topics establish how storage devices are organized and how physical disks are divided into partitions and logical volumes. Mounting explains how filesystems become accessible through the operating system's directory structure.

The final sections focus on filesystem management and monitoring storage capacity, disk I/O, health, and performance.

Each topic is separated into focused notes for easier learning, reference, troubleshooting, and expansion.
