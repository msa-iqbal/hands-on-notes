# Android

Practical, structured notes for understanding, configuring, managing, developing, debugging, and troubleshooting **Android systems and applications**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|

|02|Filesystem|Android filesystem, storage, application storage, and filesystem permissions|
|03|ADB|ADB fundamentals, device management, shell access, file transfer, and debugging|
|04|Apps|Application components, activities, services, broadcast receivers, and content providers|

|06|Processes|Android process model, application lifecycle, process management, and background execution|

|—|Toolkits|Android tools, utilities, ADB commands, and practical development tool collections|

## Structure

The notes progress from **Android fundamentals → filesystem and storage → ADB → application components → permissions and security → processes and lifecycle → debugging and performance**.

The early sections explain Android's architecture, AOSP, runtime environment, storage model, and core system components. ADB provides the practical interface for interacting with Android devices from a computer.

The application and permission sections cover how Android applications are structured, executed, isolated, and granted access to system resources. The final sections focus on process behavior, application lifecycle, debugging, crash analysis, and performance.

`TOOLKITS-ANDROID.md` provides a practical collection of useful Android tools, utilities, and ADB-related commands.

Each topic is separated into focused notes for easier learning, reference, troubleshooting, and expansion.
