# Permissions

Practical, structured notes for understanding and managing **access control, users, groups, privileges, and permissions** across operating systems.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Access Control|Access control concepts, authorization, access policies, permission models, and access decisions|
|02|Users|User identities, accounts, authentication context, user management, and account ownership|
|03|Groups|Groups, group membership, role-based access, group management, and shared resource access|
|04|File Permissions|File and directory permissions, ownership, read/write/execute access, and permission models|
|05|ACL|Access Control Lists, ACL entries, inheritance, default ACLs, and fine-grained access control|
|06|Privileges|Privileges, elevated access, administrative permissions, privilege escalation, and privileged operations|
|07|Least Privilege|Least-privilege principles, permission minimization, role design, access reviews, and reducing unnecessary access|

## Structure

The notes progress from **access control fundamentals → users and groups → file permissions → ACLs → privileges → least-privilege access**.

The early topics establish how operating systems identify users and groups and make authorization decisions. File permissions and ACLs provide practical mechanisms for controlling access to files and other protected resources.

The later topics focus on privileged operations and the principle of least privilege, helping reduce unnecessary access and limit the impact of compromised accounts or processes.

Each topic is separated into focused notes for easier learning, reference, troubleshooting, and expansion.
