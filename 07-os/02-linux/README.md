## Structure

The notes progress from **Linux fundamentals → filesystem and user management → permissions and processes → services and storage → networking and boot → package management → system monitoring**.

The `00-quick-notes/` section contains short, quickly referenced information, while the numbered sections provide structured learning material. `TOOLKITS-LINUX.md` serves as a practical collection of useful Linux tools and utilities.

The later sections focus increasingly on system administration, including services, storage, networking, boot processes, packages, and system resource monitoring.

Each topic is separated into focused notes for easier learning, reference, troubleshooting, and expansion.
