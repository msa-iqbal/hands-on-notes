# System Information, Updates & Drivers

## System Information

#### Check Ubuntu Version

Check Ubuntu Version

```bash
lsb_release -a
```

#### Hardware Information

Install **Fastfetch**:

```bash
sudo apt install fastfetch
```

Run:

```bash
fastfetch
```

#### Hardware Information

```bash
fwupdmgr get-devices
```

```bash
fwupdmgr get-updates
```
