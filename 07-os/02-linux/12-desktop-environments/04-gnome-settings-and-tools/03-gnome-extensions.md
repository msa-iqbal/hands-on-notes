# 🖆 Extension list

[Gnome extension manager](https://extensions.gnome.org/)

#### [User Themes](https://extensions.gnome.org/extension/19/user-themes/)

Load shell themes from user directory.

# 🖆 Install GNOME Extension Manager

Open Terminal (`Ctrl` + `Alt` + `T`) and run:

```bash
sudo apt update
sudo apt install gnome-shell-extension-manager
```

Or, Gnome [extension manager](https://flathub.org/en/apps/com.mattjakeman.ExtensionManager) install by [flatpak](https://flathub.org/en) package manager.

After installation, open **Activities** and search for **Extension Manager**. Otherwise, run this command:

```bash
extension-manager
```
