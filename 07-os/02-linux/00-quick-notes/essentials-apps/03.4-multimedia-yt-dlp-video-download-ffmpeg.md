# 1. Introduction

## 1.1 What is yt-dlp?

**yt-dlp** is a command-line audio/video downloader supporting thousands of websites.

It supports:

- Video downloads
- Audio downloads
- Playlists
- Channels
- Subtitles
- Thumbnails
- Metadata
- Format selection
- Download archives
- Output templates
- Browser cookies
- Post-processing

### Basic Syntax

```bash
yt-dlp [OPTIONS] URL
```

---

## 1.2 What is FFmpeg?

**FFmpeg** is a multimedia framework used for:

- Video conversion

- Audio conversion

- Stream merging

- Encoding

- Decoding

- Transcoding

- Metadata processing

- Subtitle processing

- Thumbnail embedding

FFmpeg is particularly important because many platforms provide video and audio as separate streams.

```text
Video Stream
     +
Audio Stream
     |
     v
  FFmpeg
     |
     v
Final Media
```

---

## 1.3 How yt-dlp + FFmpeg Work Together

```text
             yt-dlp
                |
       ┌────────┼────────┐
       ↓        ↓        ↓
     Video    Audio   Subtitles
       |        |        |
       └────────┼────────┘
                ↓
             FFmpeg
                |
       ┌────────┼────────┐
       ↓        ↓        ↓
     Merge   Convert   Process
                |
                ↓
           Final Media
```

In simple terms:

```text
yt-dlp  →  Download
FFmpeg  →  Merge / Convert / Process
FFprobe →  Inspect
```

---

## 1.4 Prerequisites

This guide assumes:

- Ubuntu Linux

- Internet connection

- Terminal access

- `sudo` privileges

Check your Ubuntu version:

```bash
lsb_release -a
```

or:

```bash
cat /etc/os-release
```

## 1.5 Installation & Verification

### Install FFmpeg

```bash
sudo apt update
sudo apt install ffmpeg
```

Optional additional codec support:

```bash
sudo apt install ffmpeg libavcodec-extra
```

Verify:

```bash
ffmpeg -version
```

```bash
ffprobe -version
```

```bash
which ffmpeg
which ffprobe
```

---

### Install yt-dlp

Install `curl`:

```bash
sudo apt install curl
```

Download the standalone binary:

```bash
sudo curl -L \
  https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp \
  -o /usr/local/bin/yt-dlp
```

Make it executable:

```bash
sudo chmod a+rx /usr/local/bin/yt-dlp
```

Verify:

```bash
yt-dlp --version
```

```bash
which yt-dlp
```

Expected:

```text
/usr/local/bin/yt-dlp
```

# 2. Videos

## 2.1 Basic Download

The simplest video download:

```bash
yt-dlp "YOUTUBE_URL"
```

The file is normally saved in the current directory.

Check:

```bash
ls
```

---

## 2.2 Best Quality

```bash
yt-dlp -f "bv*+ba/b" "YOUTUBE_URL"
```

### Format meaning

```text
bv* = best video
ba  = best audio
/b  = fallback to best combined format
```

---

## 2.3 List Available Formats

Before selecting a specific resolution:

```bash
yt-dlp -F "YOUTUBE_URL"
```

Equivalent:

```bash
yt-dlp --list-formats "YOUTUBE_URL"
```

Example:

```text
ID     EXT     RESOLUTION
--------------------------
18     mp4     360p
22     mp4     720p
137    mp4     1080p
271    webm    1440p
313    webm    2160p
140    m4a     audio
251    webm    audio
```

Format IDs vary between videos, so don't blindly reuse IDs.

---

Compatibility-focused MP4:

```bash
  "YOUTUBE_URL"
```

---

## 2.6 1080p MP4

### Single Video (Recommended)

```bash
yt-dlp \
  -f "bv*[height=1080][ext=mp4]+ba[ext=m4a]/b[height=1080][ext=mp4]" \
  --merge-output-format mp4 \
  --embed-thumbnail \
  --no-playlist \
  "YOUTUBE_URL"
```

### What it does

```text
Video     → 1080p MP4
Audio     → M4A
Container → MP4
Thumbnail → Embedded
Playlist  → Disabled
```

---

## 2.7 720p MP4

### Single Video (Recommended)

```bash
yt-dlp \
  -f "bv*[height=720][ext=mp4]+ba[ext=m4a]/b[height=720][ext=mp4]" \
  --merge-output-format mp4 \
  --embed-thumbnail \
  --no-playlist \
  "YOUTUBE_URL"
```

### Playlist (Recommended)

```bash
yt-dlp \
  -f "bv*[height=720][ext=mp4]+ba[ext=m4a]/b[height=720][ext=mp4]" \
  --merge-output-format mp4 \
  --write-thumbnail \
  --convert-thumbnails jpg \
  --embed-thumbnail \
  -o "%(playlist)s/%(playlist_index)02d - %(title)s.%(ext)s" \
  "PLAYLIST_URL" && \
find . -type f -name '*.jpg' -delete
```

### Note

Thumbnail embedding may not work reliably with every MP4 combination/container.

Download an entire playlist:

Specific items:

## 2.9 Subtitles

List subtitles:

```bash
yt-dlp --list-subs "YOUTUBE_URL"
```

Download English subtitles:

```bash
yt-dlp \
  --write-subs \
  --sub-langs en \
  "YOUTUBE_URL"
```

Download automatic subtitles:

```bash
yt-dlp \
  --write-auto-subs \
  --sub-langs en \
  "YOUTUBE_URL"
```

Convert subtitles to SRT:

```bash
yt-dlp \
  --write-subs \
  --sub-langs en \
  --convert-subs srt \
  "YOUTUBE_URL"
```

Embed subtitles:

```bash
yt-dlp \
  -f "bv*+ba/b" \
  --merge-output-format mp4 \
  --write-subs \
  --sub-langs en \
  --embed-subs \
  "YOUTUBE_URL"
```

---

## 2.10 Thumbnails & Metadata

```bash
yt-dlp \
```

Download and convert to JPG:

```bash
yt-dlp \
```

Embed metadata:

```bash
yt-dlp \
```

Embed metadata + thumbnail:

```bash
yt-dlp \
  --embed-metadata \
  --embed-thumbnail \
  "YOUTUBE_URL"
```

## 2.11 Output Organization

Create a dedicated YouTube directory:

```bash
mkdir -p ~/Downloads/YouTube
```

Download there:

```bash
yt-dlp \
  -P ~/Downloads/YouTube \
  "YOUTUBE_URL"
```

Use video title as filename:

```bash
yt-dlp \
  -o "%(title)s.%(ext)s" \
  "YOUTUBE_URL"
```

Useful output fields:

```text
%(title)s
%(id)s
%(uploader)s
%(upload_date)s
%(playlist)s
%(playlist_index)s
%(ext)s
```

### Organize by channel

```bash
yt-dlp \
  -P "~/Downloads/YouTube/%(uploader)s" \
  -o "%(title)s.%(ext)s" \
  "YOUTUBE_URL"
```

Result:

```text
YouTube/
└── Channel Name/
    ├── Video One.mp4
    ├── Video Two.mp4
    └── Video Three.mp4
```

### Organize playlists

```bash
yt-dlp \
  -P "~/Downloads/YouTube/%(uploader)s/%(playlist)s" \
  -o "%(playlist_index)s - %(title)s.%(ext)s" \
  "PLAYLIST_URL"
```

Result:

```text
YouTube/
└── Channel/
    └── Playlist/
        ├── 01 - Video One.mp4
        ├── 02 - Video Two.mp4
        └── 03 - Video Three.mp4
```

# 3. Audio

## 3.1 Audio Only

Best available audio:

```bash
yt-dlp -f "ba" "YOUTUBE_URL"
```

Equivalent:

```bash
yt-dlp -f "bestaudio" "YOUTUBE_URL"
```

---

## 3.2 MP3

Basic MP3 extraction:

```bash
yt-dlp \
  -x \
  --audio-format mp3 \
  "YOUTUBE_URL"
```

Here:

```text
-x
```

means:

> Extract audio.

---

## 3.3 MP3 320K (Recommended)

```bash
yt-dlp \
  -f "ba/b" \
  --extract-audio \
  --audio-format mp3 \
  --audio-quality 320K \
  --no-playlist \
  -o "%(title)s.%(ext)s" \
  "YOUTUBE_URL"
```

Output:

```text
Song Title.mp3
```

### Important

`320K` specifies the target MP3 bitrate. It does **not** create additional quality beyond the original source.

---

## 3.4 MP3 + Thumbnail

```bash
yt-dlp \
  -f "ba/b" \
  --extract-audio \
  --audio-format mp3 \
  --audio-quality 320K \
  --write-thumbnail \
  --convert-thumbnails jpg \
  --embed-thumbnail \
  --no-playlist \
  -o "%(title)s.%(ext)s" \
  "YOUTUBE_URL"
```

### Thumbnail workflow

```text
YouTube
   ↓
Download audio
   ↓
Convert → MP3
   ↓
Download thumbnail
   ↓
Convert → JPG
   ↓
Embed JPG into MP3
```

---

## 3.5 Temporary Thumbnail Cleanup (Recommended)

> NOTE: Deletes JPG files in the current directory. For safety, use a dedicated download directory.

For a single video:

```bash
yt-dlp \
  -f "ba/b" \
  --extract-audio \
  --audio-format mp3 \
  --audio-quality 320K \
  --write-thumbnail \
  --convert-thumbnails jpg \
  --embed-thumbnail \
  --no-playlist \
  -o "%(title)s.%(ext)s" \
  "YOUTUBE_URL" && \
rm -f -- *.jpg
```

### Why `&&`?

```bash
command1 && command2
```

means:

> Execute `command2` only when `command1` succeeds.

### JPG cleanup

```bash
rm -f -- *.jpg
```

# 4. Troubleshooting

## 4.1 `yt-dlp: command not found`

Check:

```bash
ls -l /usr/local/bin/yt-dlp
```

Check PATH:

```bash
echo $PATH
```

Temporarily add `/usr/local/bin`:

```bash
export PATH="/usr/local/bin:$PATH"
```

Then:

```bash
yt-dlp --version
```

---

## 4.2 `ffmpeg: command not found`

Install FFmpeg:

```bash
sudo apt update
sudo apt install ffmpeg
```

Verify:

```bash
ffmpeg -version
```

---

## 4.3 FFmpeg Is Not Detected

Check:

```bash
which ffmpeg
```

```bash
which ffprobe
```

If necessary:

```bash
yt-dlp \
  --ffmpeg-location /usr/bin \
  "YOUTUBE_URL"
```

---

## 4.4 Download Only Gives Low Resolution

First inspect available formats:

```bash
yt-dlp -F "YOUTUBE_URL"
```

Then try:

```bash
yt-dlp \
  -f "bv*+ba/b" \
  --merge-output-format mp4 \
  "YOUTUBE_URL"
```

High-quality downloads frequently require separate video and audio streams, so FFmpeg must be available.

---

## 4.5 MP3 Conversion Fails

Check FFmpeg:

```bash
ffmpeg -version
```

Then retry:

```bash
yt-dlp \
  -x \
  --audio-format mp3 \
  "YOUTUBE_URL"
```

---

## 4.6 YouTube / Extractor Errors

First update yt-dlp:

```bash
sudo yt-dlp -U
```

Check version:

```bash
yt-dlp --version
```

If the stable version has a current extractor problem, try the nightly build:

```bash
sudo yt-dlp --update-to nightly
```

---

## 4.7 Verbose Debugging

When a command fails:

```bash
yt-dlp --verbose "YOUTUBE_URL"
```

For format-related problems:

```bash
yt-dlp \
  --verbose \
  -f "bv*+ba/b" \
  "YOUTUBE_URL"
```

Verbose output can reveal:

- yt-dlp version
- Runtime information
- Extractor
- Selected formats
- FFmpeg
- Network behavior
- Post-processing errors

---

## 4.8 Media Inspection with FFprobe

Check FFprobe:

```bash
ffprobe -version
```

Inspect a video:

```bash
ffprobe "video.mp4"
```

Concise output:

```bash
ffprobe -hide_banner "video.mp4"
```

## 5.2 Recommended Workflow

For everyday usage, think of the workflow as:

```text
                 ┌───────────────┐
                 │    Ubuntu     │
                 └───────┬───────┘
                         │
             ┌───────────┴───────────┐
             ↓                       ↓
        ┌─────────┐             ┌─────────┐
        │ yt-dlp  │             │ FFmpeg  │
        └────┬────┘             └────┬────┘
             │                       │
          Download              Merge / Convert
             │                       │
             └───────────┬───────────┘
                         ↓
                  ┌──────────────┐
                  │ Final Media  │
                  │ MP4 / MP3    │
                  └──────────────┘
```

The most important commands to remember are:

```bash
yt-dlp "URL"
```

```bash
yt-dlp -F "URL"
```

```bash
yt-dlp -f "bv*+ba/b" "URL"
```

```bash
yt-dlp -x --audio-format mp3 "URL"
```

```bash
sudo yt-dlp -U
```

When something goes wrong:

```bash
yt-dlp -F "URL"
```

then:

```bash
yt-dlp --verbose "URL"
```

This gives you a simple progression:

```text
Download
   ↓
Choose Format
   ↓
Download Video / Audio
   ↓
FFmpeg Processing
   ↓
Organize Output
   ↓
Troubleshoot if Necessary
```

For a Linux workstation, **yt-dlp + FFmpeg + FFprobe + a small configuration file** provides a flexible, scriptable multimedia workflow.
