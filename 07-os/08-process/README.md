# Process

Practical, structured notes for understanding, managing, monitoring, communicating between, and debugging **operating system processes**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Process Basics|Processes, process identifiers, address spaces, resources, and process execution|
|02|Process Lifecycle|Process creation, execution, termination, parent-child relationships, and lifecycle management|
|03|Process States|Running, ready, blocked, waiting, stopped, and terminated states and state transitions|
|04|Process Priority|Process priorities, scheduling policies, priority adjustment, and CPU scheduling behavior|
|05|Signals|Signals, signal types, signal handling, termination, interruption, and process control|
|06|Process Communication|Inter-process communication (IPC), pipes, sockets, shared memory, message queues, and synchronization|
|07|Process Monitoring|Process inspection, CPU and memory usage, resource consumption, monitoring tools, and performance analysis|
|08|Process Debugging|Process debugging, tracing, stack inspection, crash analysis, system calls, and diagnostic techniques|

## Structure

The notes progress from **process fundamentals → process lifecycle and states → priority and scheduling → signals → inter-process communication → monitoring → debugging**.

The early topics explain what processes are, how they are created and terminated, and how operating systems represent and schedule them. Signals and IPC cover the mechanisms processes use to receive events and communicate with each other.

The final sections focus on observing process behavior, identifying resource usage, diagnosing failures, tracing execution, and debugging runtime problems.

Each topic is separated into focused notes for easier learning, reference, troubleshooting, and expansion.
