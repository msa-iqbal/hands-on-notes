## 🧭 Where Should I Look?

```text
Learn a concept       → 01–15
Reuse a small example → 16-snippets
Follow a procedure    → 17-recipes
Fix a problem         → 18-troubleshooting
Quick lookup          → 19-reference
Find resources        → 20-resources
```

### Simple rule

> **Organize by purpose first, technology second.**

For example:

```text
Learn PostgreSQL
    → 06-database/postgresql/

Reusable SQL
    → 16-snippets/sql/

Database procedure
    → 17-recipes/database/

Database problem
    → 18-troubleshooting/database/

Quick command/reference
    → 19-reference/
```

## 📝 Note Philosophy

Notes should be:

- Practical
- Clear
- Searchable
- Reusable
- Easy to maintain

Avoid unnecessary duplication.

> **One topic → one primary home.**

The same technology may appear in different sections when the **purpose is different**.

## 🚀 Philosophy

This is not a copy of official documentation.

It is a personal **hands-on knowledge base** for things worth learning, using, fixing, and remembering.

```text
Learn → Build → Debug → Fix → Document → Reuse
```
