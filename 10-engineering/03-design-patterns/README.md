# Design Patterns

Practical, structured notes for understanding and applying **software design patterns** to solve recurring design problems, improve code structure, and build maintainable and flexible software.

## Structure

The notes progress from **design-pattern fundamentals → creational patterns → structural patterns → behavioral patterns → individual pattern implementations**.

The overview establishes what design patterns are, the problems they address, their common structure, and considerations for using them appropriately. Creational, structural, and behavioral sections then introduce the three major pattern categories.

The remaining sections provide focused notes for commonly used patterns, covering object creation, object composition, interface adaptation, behavior extension, communication, algorithm selection, and workflow customization.

Each pattern is separated into a focused note for easier learning, comparison, practical implementation, and expansion.
