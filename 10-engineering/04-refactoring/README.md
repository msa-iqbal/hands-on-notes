# Refactoring

Practical, structured notes for understanding and applying **code refactoring techniques** to improve readability, maintainability, structure, and design without changing the intended behavior of software.

## Contents

| #   | Topic                 | What You'll Learn                                                                                              |
| --- | --------------------- | -------------------------------------------------------------------------------------------------------------- |
| 01  | Refactoring Basics    | Refactoring concepts, goals, principles, workflow, benefits, risks, and when to refactor                       |
| 02  | Code Smells           | Common code smells, identifying design problems, maintainability issues, and refactoring opportunities         |
| 03  | Extract Method        | Extracting focused methods, reducing complexity, improving readability, and separating responsibilities        |
| 04  | Extract Class         | Splitting large classes, separating responsibilities, improving cohesion, and reducing class complexity        |
| 05  | Rename                | Renaming variables, methods, classes, and other identifiers to improve clarity and express intent              |
| 06  | Simplify Conditionals | Simplifying conditional logic, reducing nesting, improving readability, and clarifying decision paths          |
| 07  | Remove Duplication    | Identifying duplicated code, consolidating repeated logic, and improving maintainability                       |
| 08  | Replace Complex Logic | Simplifying complex logic, replacing difficult structures, improving design, and reducing cognitive complexity |
| 09  | Safe Refactoring      | Testing, incremental changes, version control, verification, rollback, and minimizing refactoring risk         |

## Structure

The notes progress from **refactoring fundamentals → code smells → focused refactoring techniques → safe refactoring practices**.

The first section establishes what refactoring is, why it is performed, and how to approach changes while preserving software behavior. Code smells then provides a way to identify areas where refactoring may improve code quality and design.

The following sections cover practical techniques for extracting methods and classes, improving names, simplifying conditionals, removing duplication, and replacing complex logic with clearer structures.

The final section focuses on performing refactoring safely through tests, small incremental changes, version control, verification, and rollback strategies.

Each topic is separated into focused notes for easier learning, reference, practical use, and expansion.
