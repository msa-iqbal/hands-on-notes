# Engineering

Practical, structured notes for learning and applying **software engineering principles, design practices, development workflows, testing, debugging, code review, documentation, and engineering best practices**.

|#|Topic|What You'll Learn|
|---|---|---|

|02|SOLID|SOLID principles, object-oriented design, responsibilities, extensibility, substitutability, interfaces, dependencies, and practical applications|
|03|Design Patterns|Design-pattern fundamentals, creational, structural, and behavioral patterns, and common pattern implementations|
|04|Refactoring|Refactoring fundamentals, code smells, extraction, renaming, logic simplification, duplication removal, and safe refactoring|

|07|Code Review|Review workflows, checklists, code analysis, feedback, pull-request reviews, collaboration, and review best practices|
|08|Documentation|Documentation fundamentals, code and API documentation, architecture documentation, README files, changelogs, runbooks, and documentation practices|
|09|Best Practices|Software engineering principles, code quality, maintainability, reusability, scalability, reliability, performance, security, dependencies, versioning, and compatibility|

## Structure

The notes progress from **code quality and design → refactoring and debugging → testing and review → documentation → broader engineering best practices**.

The first sections establish practical foundations for writing and designing maintainable software. Clean Code and SOLID focus on code quality and object-oriented design, while Design Patterns introduces reusable solutions to recurring design problems.

Refactoring and Debugging focus on improving and diagnosing existing software. Testing then covers verification at different levels and development practices such as TDD and BDD.

Code Review and Documentation address the collaborative and knowledge-sharing aspects of software engineering. Code review focuses on evaluating changes and improving implementation quality, while documentation covers communicating code, APIs, architectures, releases, and operational procedures.

The final section brings these concepts together through broader engineering practices covering quality, maintainability, scalability, reliability, performance, security, dependency management, versioning, and backward compatibility.

Each topic is separated into focused notes for easier learning, reference, practical use, and expansion.
