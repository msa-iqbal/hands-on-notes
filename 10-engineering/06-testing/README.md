# Testing

Practical, structured notes for understanding and applying **software testing practices** to verify correctness, reliability, maintainability, and behavior across different levels of software systems.

## Structure

The notes progress from **testing fundamentals → test pyramid → testing levels → test doubles and test infrastructure → coverage → TDD and BDD → testing best practices**.

The first sections establish testing concepts and the test pyramid, followed by unit, integration, system, and end-to-end testing. These levels explain how software can be verified from individual components through complete application workflows.

Test doubles, mocking, fixtures, and test data then focus on controlling dependencies and creating predictable test environments. Test coverage introduces ways to measure which parts of the code are exercised while recognizing the limitations of coverage metrics.

TDD and BDD cover development approaches that use automated tests and behavior specifications as part of the development process. The final section brings these concepts together through practical testing practices for maintainable, reliable, and automated test suites.

Each topic is separated into focused notes for easier learning, reference, practical use, and expansion.
