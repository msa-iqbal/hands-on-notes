# Debugging

Practical, structured notes for understanding and applying **debugging techniques** to identify, analyze, isolate, and resolve software problems across development and production environments.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Debugging Fundamentals|Debugging concepts, bugs, failures, symptoms, root causes, and systematic problem solving|
|02|Debugging Workflow|Problem reproduction, information gathering, hypothesis formation, isolation, verification, and resolution|
|03|Breakpoints|Breakpoints, conditional breakpoints, watch expressions, stepping, and interactive debugging|
|04|Stack Traces|Reading stack traces, identifying failure locations, tracing call paths, and analyzing exceptions|
|05|Logs|Logging for debugging, log levels, structured logs, correlation, filtering, and log analysis|
|06|Memory Debugging|Memory leaks, invalid memory access, allocation problems, heap analysis, and memory profiling|
|07|Performance Debugging|Performance bottlenecks, profiling, CPU and memory analysis, latency, throughput, and optimization|
|08|Production Debugging|Debugging live systems, observability, safe diagnostics, incident investigation, and minimizing production impact|
|09|Debugging Strategies|Systematic debugging methods, divide and conquer, binary search, tracing, experimentation, and root-cause analysis|

## Structure

The notes progress from **debugging fundamentals → debugging workflow → interactive debugging → stack traces and logs → memory and performance debugging → production debugging → debugging strategies**.

The first sections establish the fundamentals of debugging and provide a systematic workflow for reproducing problems, gathering evidence, forming hypotheses, isolating failures, and verifying fixes.

Breakpoints and stack traces focus on interactive and exception-based debugging, while logs provide a practical method for investigating application behavior and failures. Memory and performance debugging then address resource-related problems, leaks, bottlenecks, latency, and profiling.

Production debugging focuses on diagnosing problems in live environments while minimizing risk and service impact. The final section brings these techniques together through systematic debugging strategies and root-cause analysis.

Each topic is separated into focused notes for easier learning, reference, practical use, and expansion.
