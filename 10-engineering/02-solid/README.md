# SOLID

Practical, structured notes for understanding and applying the **SOLID principles** to design maintainable, flexible, testable, and extensible software.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|SOLID Overview|SOLID principles, object-oriented design, maintainability, flexibility, and software design fundamentals|
|02|Single Responsibility|Single Responsibility Principle (SRP), class responsibilities, separation of concerns, and focused designs|
|03|Open/Closed|Open/Closed Principle (OCP), extensibility, abstraction, and minimizing changes to existing code|
|04|Liskov Substitution|Liskov Substitution Principle (LSP), substitutability, inheritance contracts, and behavioral compatibility|
|05|Interface Segregation|Interface Segregation Principle (ISP), focused interfaces, client-specific contracts, and avoiding unnecessary dependencies|
|06|Dependency Inversion|Dependency Inversion Principle (DIP), abstractions, dependency injection, and loosely coupled designs|
|07|Practical Examples|SOLID examples, common violations, refactoring techniques, and applying SOLID principles in real code|

## Structure

The notes progress from **SOLID fundamentals → Single Responsibility → Open/Closed → Liskov Substitution → Interface Segregation → Dependency Inversion → practical examples**.

The overview establishes the purpose of SOLID and its relationship to object-oriented design. Each principle then focuses on a specific aspect of software structure, responsibility, extensibility, substitutability, interface design, or dependency management.

The practical examples section brings the principles together through common violations, refactoring approaches, and real-world application of SOLID concepts.

Each topic is separated into focused notes for easier learning, reference, practical use, and expansion.
