# Auth

Practical, structured notes for implementing **authentication and authorization** in backend applications.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Fundamentals|Authentication, authorization, sessions, and access control|
|02|Passwords|Password hashing, password policies, and password reset|
|03|JWT|JWT fundamentals, access tokens, refresh tokens, and token security|
|04|OAuth|OAuth fundamentals, OAuth 2.0, authorization code flow, and OpenID Connect|
|05|RBAC|Role-based access control, permissions, and policy patterns|
|06|Security|Session security, cookie security, CSRF, CORS, and brute-force protection|

## Structure

The notes progress from **authentication and authorization fundamentals → password security → JWT → OAuth and OpenID Connect → RBAC → authentication security practices**.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Focus

- Authentication and authorization
- Session-based authentication
- Password hashing and security
- JWT access and refresh tokens
- OAuth 2.0 and OpenID Connect
- Role-based access control
- Permissions and authorization policies
- Session and cookie security
- CSRF and CORS
- Brute-force protection
- Secure authentication patterns

## Goal

> Understand authentication and authorization systematically, implement secure access-control systems, and keep practical security knowledge easy to find.
