## Structure

The notes progress from **backend runtimes and frameworks → API development → authentication and validation → databases and caching → messaging and testing → observability and performance → background jobs and file processing → backend architecture → production operations**.

Node.js provides the runtime foundation, while Express and NestJS cover common server-side application frameworks. API, authentication, validation, database, caching, and messaging topics cover the major building blocks used to develop backend services.

Testing, observability, and performance address the quality and operational characteristics of backend applications, while architecture and production topics cover how systems are structured, deployed, monitored, and maintained.

Each topic is separated into focused notes so the section remains easy to navigate, reference, and expand.
