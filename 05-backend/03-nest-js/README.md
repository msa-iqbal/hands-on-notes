# NestJS

Practical, structured notes for building **scalable server-side applications with NestJS**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Basics|NestJS introduction, CLI, project structure, and configuration|
|02|Modules|Modules, feature modules, global modules, and dynamic modules|
|03|Controllers|Controllers, routes, parameters, and request-response handling|
|04|Providers|Providers, services, dependency injection, and custom providers|
|05|Pipes|Pipes, validation pipes, and transformation pipes|
|06|Guards|Guards, authentication guards, and authorization guards|
|07|Interceptors|Interceptors, logging, response transformation, and performance|
|08|Exception Filters|Exception filters, HTTP exceptions, and custom exceptions|
|09|Middleware|Middleware, global middleware, and route middleware|
|10|Configuration|Configuration, environment variables, validation, and configuration patterns|
|11|Testing|Unit, integration, and E2E testing, plus the testing module|
|12|WebSockets|Gateways, events, and WebSocket adapters|
|13|GraphQL|GraphQL module, code-first, schema-first, resolvers, and GraphQL patterns|
|14|Microservices|Microservices, transporters, message patterns, RPC, and microservice patterns|

## Structure

The notes progress from **NestJS fundamentals → modules and controllers → providers and dependency injection → request lifecycle → configuration and testing → WebSockets and GraphQL → microservices**.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Focus

- NestJS fundamentals and CLI
- Modular application architecture
- Controllers and routing
- Providers and dependency injection
- Pipes, guards, and interceptors
- Middleware and exception handling
- Configuration and environment management
- Unit, integration, and E2E testing
- WebSockets
- GraphQL
- Microservices and RPC
- Scalable backend architecture

## Goal

> Learn NestJS systematically, understand its modular architecture and request lifecycle, build scalable backend applications, and keep practical knowledge easy to find.
