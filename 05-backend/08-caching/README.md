# Caching

Practical, structured notes for improving **application performance with caching**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Caching Basics|Caching concepts, cache layers, cacheable data, and caching fundamentals|
|02|Cache Strategies|Cache-aside, read-through, write-through, write-back, and other caching strategies|
|03|Redis|Redis fundamentals, data types, commands, persistence, and Redis-based caching|
|04|TTL|Time-to-live, expiration, cache lifetime, and expiration strategies|
|05|Cache Invalidation|Invalidation strategies, stale data, cache consistency, and invalidation patterns|
|06|Distributed Caching|Shared caches, distributed cache architecture, consistency, and scalability|

## Structure

The notes progress from **caching fundamentals → cache strategies → Redis → expiration and TTL → cache invalidation → distributed caching**.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Focus

- Caching fundamentals
- Cache layers and strategies
- Cache-aside and write strategies
- Redis caching
- TTL and expiration
- Cache invalidation
- Cache consistency
- Distributed caching
- Scalable caching architecture
- Performance optimization

## Goal

> Learn caching systematically, improve application performance and scalability, and keep practical caching knowledge easy to find.
