# API

Practical, structured notes for designing, building, and working with **modern APIs**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|REST|REST fundamentals, resources, HTTP methods, status codes, headers, query parameters, pagination, filtering, sorting, and versioning|
|02|GraphQL|Schemas, types, queries, mutations, subscriptions, resolvers, and fragments|
|03|WebSocket|WebSocket fundamentals, connections, events, reconnection, and real-time communication patterns|
|04|API Design|Resource design, error formats, versioning, idempotency, rate limiting, and API documentation|

## Structure

The notes progress from **REST fundamentals → GraphQL → real-time communication with WebSocket → general API design principles and patterns**.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Focus

- REST API design
- HTTP methods and status codes
- Resources and query parameters
- Pagination, filtering, and sorting
- API versioning
- GraphQL schemas and operations
- WebSocket and real-time communication
- Resource and error design
- Idempotency and rate limiting
- API documentation
- Reliable and maintainable API patterns

## Goal

> Learn API technologies systematically, design consistent and reliable interfaces, and keep practical API knowledge easy to find.
