# Observability

Practical, structured notes for monitoring, diagnosing, and understanding **backend systems in production**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Logging|Application logs, log levels, log output, context, and logging practices|
|02|Structured Logging|Structured log formats, JSON logs, fields, correlation IDs, and log aggregation|
|03|Metrics|Metrics fundamentals, counters, gauges, histograms, application metrics, and system metrics|
|04|Tracing|Distributed tracing, spans, traces, context propagation, and request flow analysis|
|05|Health Checks|Liveness, readiness, dependency checks, health endpoints, and service health|
|06|Alerting|Alert rules, thresholds, conditions, notifications, and alert management|
|07|OpenTelemetry|OpenTelemetry concepts, instrumentation, traces, metrics, logs, collectors, and exporters|

## Structure

The notes progress from **logging → structured logging → metrics → distributed tracing → health checks → alerting → OpenTelemetry**.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Focus

- Application and system logging
- Structured and machine-readable logs
- Metrics and monitoring
- Distributed tracing
- Request and dependency tracing
- Liveness and readiness checks
- Alerting and incident detection
- OpenTelemetry
- Production diagnostics
- Observability architecture

## Goal

> Learn observability systematically, understand what is happening inside production systems, and diagnose problems quickly and reliably.
