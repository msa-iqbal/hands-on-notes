# Messaging

Practical, structured notes for building **reliable asynchronous and event-driven communication systems**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Message Queues|Queue concepts, producers, consumers, brokers, acknowledgements, and delivery models|
|02|Pub/Sub|Publish-subscribe concepts, publishers, subscribers, topics, and event distribution|
|03|RabbitMQ|RabbitMQ fundamentals, exchanges, queues, bindings, consumers, acknowledgements, and routing|
|04|Kafka|Kafka fundamentals, topics, partitions, producers, consumers, consumer groups, and offsets|
|05|Events|Event-driven architecture, event producers, consumers, event schemas, and event handling|
|06|Retries|Retry strategies, backoff, retry limits, transient failures, and idempotent processing|
|07|Dead-Letter Queues|Dead-letter queues, failed messages, poison messages, recovery, and reprocessing|
|08|Message Patterns|Request-reply, competing consumers, fan-out, routing, event notification, and messaging patterns|

## Structure

The notes progress from **message queues and pub/sub → RabbitMQ and Kafka → event-driven systems → retries and failure handling → messaging patterns**.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Focus

- Message queues and brokers
- Producer and consumer patterns
- Pub/sub messaging
- RabbitMQ
- Apache Kafka
- Event-driven architecture
- Message delivery and acknowledgements
- Retries and backoff strategies
- Dead-letter queues
- Idempotent message processing
- Reliable messaging patterns
- Scalable asynchronous communication

## Goal

> Learn messaging systematically, build reliable event-driven systems, and keep practical asynchronous communication knowledge easy to find.
