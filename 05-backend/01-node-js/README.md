# Node.js

Practical, structured notes for learning and using **Node.js** for backend and server-side development.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Basics|Node.js introduction, runtime, modules, CommonJS, ES Modules, and `package.json`|
|02|Runtime|Event loop, call stack, task queue, microtask queue, process, and runtime patterns|
|03|Built-in Modules|File system, paths, URLs, HTTP, crypto, events, streams, buffers, and child processes|
|04|Async|Callbacks, promises, `async/await`, error handling, and concurrency|
|05|Streams|Readable, writable, duplex, transform streams, and stream pipelines|
|06|Process & Environment|Process management, environment variables, signals, exit codes, and graceful shutdown|
|07|Performance|Performance fundamentals, memory, profiling, worker threads, and performance debugging|

## Structure

The notes progress from **Node.js fundamentals → runtime internals → built-in modules → asynchronous programming → streams → process and environment management → performance**.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Focus

- Node.js fundamentals and runtime
- CommonJS and ES Modules
- Node.js runtime and event loop
- Built-in modules and APIs
- Asynchronous programming
- Streams and data processing
- Processes and environment variables
- Signals and graceful shutdown
- Memory and performance
- Profiling and performance debugging
- Worker threads

## Goal

> Learn Node.js systematically, understand its runtime and APIs, build reliable backend applications, and keep practical knowledge easy to find.
