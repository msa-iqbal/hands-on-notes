# Testing

Practical, structured notes for testing **backend applications, APIs, and services**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Testing Strategy|Testing principles, test boundaries, test pyramid, and testing strategy|
|02|Unit Testing|Testing isolated functions, modules, business logic, assertions, and test organization|
|03|Integration Testing|Testing multiple modules, services, databases, and application integrations|
|04|API Testing|Testing HTTP APIs, requests, responses, authentication, validation, and error handling|
|05|E2E Testing|End-to-end workflows, application behavior, user scenarios, and system integration|
|06|Mocking|Mock functions, modules, APIs, databases, network requests, and external dependencies|
|07|Test Doubles|Stubs, mocks, spies, fakes, and other test-double patterns|
|08|Contract Testing|API contracts, consumer-provider testing, compatibility, and contract verification|
|09|Test Coverage|Coverage metrics, statements, branches, functions, thresholds, and coverage analysis|

## Structure

The notes progress from **testing strategy → unit and integration testing → API and E2E testing → mocking and test doubles → contract testing → test coverage**.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Focus

- Backend testing strategy
- Unit and integration testing
- API testing
- End-to-end testing
- Mocking and test doubles
- Database and external-service testing
- Contract testing
- Test organization and maintainability
- Test coverage
- Reliable backend testing patterns

## Goal

> Build reliable backend applications through meaningful tests that verify business logic, integrations, APIs, contracts, and critical workflows.
