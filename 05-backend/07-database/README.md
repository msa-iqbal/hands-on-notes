# Database

Practical, structured notes for integrating and working with **databases in backend applications**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Database Integration|Connecting backend applications to databases and managing database clients|
|02|Connection Pooling|Connection pools, pool configuration, connection limits, and resource management|
|03|Transactions|Transactions, commit, rollback, isolation, and transactional patterns|
|04|Migrations|Schema migrations, migration workflows, versioning, and rollback strategies|
|05|ORM|ORM concepts, models, relationships, queries, and ORM patterns|
|06|Query Builders|Query builders, query composition, parameterization, and complex queries|
|07|Repositories|Repository patterns, data access abstraction, and repository design|
|08|Database Patterns|Data-access patterns, transaction patterns, service integration, and scalable database architecture|

## Structure

The notes progress from **database integration → connection management → transactions and migrations → ORM and query builders → repositories → scalable database patterns**.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Focus

- Database integration
- Database connections and pooling
- Transactions and isolation
- Schema migrations
- ORM usage and patterns
- Query builders
- Repository pattern
- Data-access abstraction
- Database architecture
- Reliable database integration

## Goal

> Learn database integration systematically, build reliable data-access layers, and keep practical backend database knowledge easy to find.
