# Validation

Practical, structured notes for validating **application input, requests, and responses**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Input Validation|Validating user input, data types, constraints, and validation rules|
|02|Schema Validation|Schema-based validation, reusable schemas, and structured data validation|
|03|Request Validation|Validating request bodies, parameters, query strings, and headers|
|04|Response Validation|Validating API responses, output structures, and response contracts|
|05|Error Messages|Validation errors, error formats, field errors, and user-friendly messages|
|06|Zod|Zod schemas, parsing, validation, transformations, and type inference|
|07|Joi|Joi schemas, validation rules, custom validation, and error handling|
|08|Class Validator|Decorator-based validation, DTOs, validation rules, and NestJS integration|
|09|Validation Patterns|Reusable validation patterns, validation architecture, and best practices|

## Structure

The notes progress from **validation fundamentals → schema and request/response validation → error handling → validation libraries → reusable validation patterns**.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Focus

- Input and data validation
- Schema-based validation
- Request and response validation
- Validation errors and messages
- Zod
- Joi
- Class Validator
- DTO validation
- Reusable validation patterns
- Maintainable validation architecture

## Goal

> Learn validation systematically, validate data consistently across application boundaries, and keep practical validation knowledge easy to find.
