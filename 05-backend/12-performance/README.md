# Performance

Practical, structured notes for improving **backend application performance, scalability, and resource efficiency**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Performance Basics|Performance fundamentals, bottlenecks, profiling, benchmarks, and optimization principles|
|02|Latency|Request latency, response time, latency sources, measurement, and optimization|
|03|Throughput|Throughput, requests per second, capacity, bottlenecks, and scalability|
|04|Concurrency|Concurrent requests, parallelism, synchronization, contention, and resource limits|
|05|Memory|Memory usage, allocation, garbage collection, memory leaks, and optimization|
|06|Database Performance|Query performance, indexes, connection pooling, query plans, and database optimization|
|07|Caching|Cache strategies, cache hit rates, invalidation, TTL, and performance optimization|
|08|Load Testing|Load testing, stress testing, capacity testing, test scenarios, and performance analysis|
|09|Performance Debugging|Profiling, bottleneck analysis, performance traces, diagnostics, and optimization workflows|

## Structure

The notes progress from **performance fundamentals → latency and throughput → concurrency and memory → database and caching → load testing → performance debugging**.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Focus

- Backend performance fundamentals
- Latency and response time
- Throughput and system capacity
- Concurrency and resource contention
- Memory usage and optimization
- Database performance
- Caching and cache efficiency
- Load and stress testing
- Profiling and bottleneck analysis
- Performance debugging
- Scalable backend systems

## Goal

> Understand backend performance systematically, identify bottlenecks, and build fast, efficient, and scalable applications.
