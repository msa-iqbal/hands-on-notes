# Assets

Supporting **images, videos, diagrams, screenshots, and other media files** used by resources and related repository content.

## Contents

|#|Topic|What You'll Find|
|---|---|---|
|01|Images|Screenshots, diagrams, illustrations, covers, and visual references|
|02|Videos|Demonstrations, tutorials, recordings, and other video resources|
|03|Others|PDFs, audio, documents, archives, and other supporting files|

## Structure

Assets are separated from the resource descriptions so supporting media does not clutter the main resource structure.

Images, videos, and other files can be referenced from resource pages whenever visual or downloadable material improves understanding.

## Focus

- Book covers and references
- Course screenshots and materials
- Documentation images
- Tool screenshots
- Tutorials and demonstrations
- Videos and recordings
- Supporting documents and files

## Goal

> Keep resource-related media organized separately while making it easy to reference from the appropriate resource.
