# Resources

Curated **books, courses, documentation, tools, assets, and useful links** for software development and technical learning.

## Contents

|#|Topic|What You'll Find|
|---|---|---|
|01|Books|Recommended books for programming, software engineering, architecture, databases, DevOps, cloud, and related subjects|
|02|Courses|Structured courses and learning programs for technical skills and practical development|
|03|Documentation|Official and trusted documentation for programming languages, frameworks, platforms, and tools|
|04|Tools|Useful development, debugging, testing, DevOps, cloud, database, and security tools|
|04|Assets|Images, videos, screenshots, diagrams, and other supporting resource files|
|05|Links|Useful websites, communities, newsletters, references, and online learning resources|

## Structure

Resources are organized by type so books, courses, documentation, tools, assets, and useful links can be found without searching through unrelated material.

Each resource category is further organized by subject where appropriate. Supporting assets are kept separately so images, videos, and other files do not clutter the main resource structure.

Resources should be kept useful, relevant, and reasonably maintained. Prefer authoritative, active, and technically valuable sources.
