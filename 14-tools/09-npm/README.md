# npm

Practical, structured notes for using **npm** for JavaScript package management, project configuration, dependencies, scripts, workspaces, package publishing, security, and command-line workflows.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|npm Fundamentals|npm concepts, package management, registry, projects, configuration, and essential workflows|
|02|Installation|Installing Node.js and npm, version management, verification, updates, and environment setup|
|03|package.json|Package metadata, scripts, dependencies, configuration fields, project settings, and package structure|
|04|Packages|Installing, updating, removing, inspecting, and managing npm packages|
|05|Dependencies|Production and development dependencies, version ranges, lockfiles, dependency management, and lifecycle|
|06|Scripts|npm scripts, lifecycle scripts, command execution, arguments, chaining, and automation|
|07|npm Workspaces|Workspace configuration, multi-package projects, dependency management, and monorepo workflows|
|08|Publishing Packages|Package configuration, versioning, registries, authentication, publishing, and package maintenance|
|09|npm Security|Dependency risks, audits, package integrity, security policies, trusted packages, and vulnerability management|
|10|npm Commands|Essential npm commands, options, package operations, configuration, and practical command reference|

## Structure

The notes progress from **npm fundamentals → installation → package.json → packages → dependencies → scripts → npm workspaces → publishing packages → npm security → npm commands**.

The first sections establish npm's package-management model and installation workflow, followed by `package.json` for configuring JavaScript and Node.js projects. Packages and dependencies then cover installing, updating, removing, and managing project dependencies.

Scripts introduce npm-based automation for common development tasks. Workspaces extend npm to multi-package projects and monorepos, while package publishing covers versioning, registry configuration, authentication, and distribution.

The security section focuses on managing dependency and package-related risks. The final section provides a practical command reference for everyday npm usage and project maintenance.

Each topic is separated into focused notes for easier learning, project setup, dependency management, development, publishing, security, automation, and practical reference.

> Build a practical npm knowledge base that makes it easy to manage JavaScript packages and projects, configure dependencies and scripts, work with monorepos, publish packages, handle security risks, and use npm effectively from the command line.
