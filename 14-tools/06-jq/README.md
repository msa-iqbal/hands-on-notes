# jq

Practical, structured notes for using **jq** for parsing, querying, filtering, transforming, and formatting JSON data from the command line.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|jq Fundamentals|jq concepts, command structure, filters, JSON input, output, and essential workflows|
|02|Selecting Data|Selecting fields, values, nested data, array elements, and JSON properties|
|03|Filtering|Conditions, comparisons, boolean expressions, `select`, and filtering JSON data|
|04|Transforming Data|Mapping, modifying values, restructuring JSON, and transforming data|
|05|Arrays & Objects|Array operations, object construction, iteration, indexing, and nested structures|
|06|Pipes|Combining filters, chaining operations, composing transformations, and data-flow workflows|
|07|Functions|Built-in functions, custom functions, parameters, reuse, and advanced processing|
|08|Formatting Output|Raw output, compact output, pretty printing, string formatting, and output control|
|09|jq Examples|Practical JSON-processing commands, API workflows, shell integration, and reusable examples|

## Structure

The notes progress from **jq fundamentals → selecting data → filtering → transforming data → arrays and objects → pipes → functions → formatting output → practical examples**.

The first sections establish jq's filter-based processing model and basic data selection. Filtering and transformation then introduce conditions, mapping, restructuring, and modification of JSON data.

Arrays and objects cover the primary JSON data structures and their manipulation. Pipes introduce composable processing workflows, while functions provide reusable and more advanced data-processing techniques.

The formatting section focuses on controlling jq output for scripts, terminals, APIs, and automation. The final section brings these concepts together through practical examples and common command-line JSON-processing workflows.

Each topic is separated into focused notes for easier learning, daily usage, scripting, automation, API work, and practical reference.
