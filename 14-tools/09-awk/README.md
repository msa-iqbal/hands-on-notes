# awk

Practical, structured notes for using **awk** for structured text processing, field and record handling, pattern matching, data transformation, conditions, loops, functions, and command-line data-processing workflows.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|awk Fundamentals|awk concepts, program structure, input processing, patterns, actions, and essential workflows|
|02|Fields & Records|Fields, records, field separators, record separators, built-in fields, and structured input|
|03|Patterns & Actions|Pattern matching, actions, conditions, regular expressions, and selective processing|
|04|Variables|Built-in variables, user-defined variables, assignments, counters, and data management|
|05|Conditions|Conditional expressions, `if` statements, comparisons, logical operators, and branching|
|06|Loops|`for`, `while`, `do-while`, iteration, nested loops, and repeated data processing|
|07|Functions|Built-in functions, user-defined functions, parameters, return values, and reusable logic|
|08|awk Examples|Practical data-processing commands, reports, calculations, pipelines, and reusable examples|

## Structure

The notes progress from **awk fundamentals → fields and records → patterns and actions → variables → conditions → loops → functions → practical examples**.

The first sections establish awk's processing model and how it works with structured input through fields and records. Patterns and actions then introduce selective data processing and transformation.

Variables and conditions provide the foundation for storing values and controlling processing logic. Loops extend awk for repeated and structured data operations, while functions introduce reusable processing logic and more maintainable awk programs.

The final section brings these concepts together through practical examples for log analysis, data extraction, reporting, calculations, pipelines, and everyday command-line data processing.

Each topic is separated into focused notes for easier learning, scripting, automation, data processing, troubleshooting, and practical reference.
