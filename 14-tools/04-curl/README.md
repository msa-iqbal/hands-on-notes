# cURL

Practical, structured notes for using **cURL** for HTTP requests, APIs, headers, request bodies, authentication, cookies, file transfers, proxies, TLS, and command-line networking workflows.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|cURL Fundamentals|cURL concepts, command structure, options, URLs, responses, and essential workflows|
|02|HTTP Requests|HTTP methods, URLs, request options, status codes, response handling, and request workflows|
|03|GET & POST|GET and POST requests, query parameters, form data, JSON requests, and common usage patterns|
|04|Headers|Request and response headers, custom headers, content types, user agents, and header management|
|05|Request Body|JSON, form data, raw data, multipart data, payload formatting, and request-body handling|
|06|Authentication|Basic authentication, bearer tokens, API keys, credentials, and authenticated requests|
|07|Cookies|Cookie handling, storing cookies, sending cookies, sessions, and cookie management|
|08|File Upload & Download|File uploads, downloads, multipart requests, output files, and transfer options|
|09|Proxy & TLS|Proxy configuration, HTTPS, certificates, TLS options, verification, and secure connections|
|10|cURL Examples|Practical cURL commands, API workflows, troubleshooting examples, and reusable command patterns|

## Structure

The notes progress from **cURL fundamentals → HTTP requests → GET and POST → headers → request bodies → authentication → cookies → file transfers → proxy and TLS → practical examples**.

The first sections establish cURL's command structure and HTTP request workflow. GET and POST requests then introduce common API operations, followed by headers and request bodies for controlling request metadata and payloads.

Authentication and cookies cover credential-based and session-based requests. File upload and download focuses on transferring data through the command line, while proxy and TLS introduces network routing and secure HTTPS connections.

The final section brings these concepts together through practical cURL commands and reusable workflows for API interaction, debugging, automation, and everyday command-line networking.

Each topic is separated into focused notes for easier learning, daily usage, API development, troubleshooting, automation, and practical reference.
