# Tools

Practical, structured notes for understanding and using **developer tools, editors, API clients, command-line utilities, data-processing tools, package managers, and build automation tools**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|VS Code|Editor fundamentals, settings, shortcuts, extensions, debugging, source control, tasks, and remote development|
|02|Vim|Vim fundamentals, modes, navigation, editing, buffers, windows, macros, configuration, and commands|
|03|Postman|API requests, collections, environments, variables, authentication, tests, scripts, mocking, and automation|

|05|jq|JSON processing, filtering, transformation, arrays, objects, pipes, functions, and output formatting|

|11|Make|Makefiles, targets, variables, dependencies, pattern rules, automatic variables, functions, and build automation|

## Structure

The notes progress from **development environments → text editors → API tools → command-line utilities → package managers → build automation**.

VS Code and Vim cover development environments and editor workflows. Postman and cURL focus on working with APIs and HTTP requests, while jq provides practical tools for processing and transforming JSON data.

grep, sed, and awk cover essential command-line text-searching and text-processing workflows. npm and pnpm then focus on JavaScript package management, dependencies, scripts, workspaces, and monorepos.

The final section covers Make and build automation through Makefiles, targets, variables, dependencies, rules, and reusable build workflows.

Each tool is separated into focused notes for easier learning, daily usage, reference, troubleshooting, and practical development work.

## Focus

- Editors and development environments
- API clients and HTTP tools
- JSON and text processing
- Command-line search and transformation
- JavaScript package managers
- Workspaces and monorepos
- Build automation

## Goal

> Build a practical developer-tools knowledge base that makes it easy to learn, use, configure, automate, and troubleshoot the tools commonly used in software development.
