# sed

Practical, structured notes for using **sed** for stream editing, text transformation, substitution, deletion, insertion, addressing, regular expressions, and command-line text-processing workflows.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|sed Fundamentals|sed concepts, command structure, streams, scripts, and essential text-processing workflows|
|02|Printing|Printing selected lines, ranges, matching lines, and controlling output|
|03|Substitution|Text replacement, substitution flags, patterns, delimiters, and replacement workflows|
|04|Deletion|Deleting lines, matching patterns, ranges, and unwanted text from streams|
|05|Insertion & Appending|Inserting text before lines, appending text after lines, and modifying streams|

## Structure

The notes progress from **sed fundamentals → printing → substitution → deletion → insertion and appending → addressing → regular expressions → practical examples**.

The first sections establish sed's stream-editing model and basic output control. Printing and substitution then introduce selecting lines and replacing text, followed by deletion for removing unwanted content.

Insertion and appending cover adding content to streams, while addressing provides precise control over which lines or patterns an operation affects. Regular expressions extend sed's capabilities for more complex text matching and transformations.

The final section brings these concepts together through practical sed commands and reusable workflows for file editing, pipelines, automation, and command-line text processing.

Each topic is separated into focused notes for easier learning, daily usage, scripting, automation, troubleshooting, and practical reference.
