# pnpm

Practical, structured notes for using **pnpm** for fast and efficient JavaScript package management, dependency management, lockfiles, workspaces, monorepos, scripts, security, and command-line workflows.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|pnpm Fundamentals|pnpm concepts, package management, store architecture, project structure, and essential workflows|
|02|Installation|Installing pnpm, version management, verification, configuration, and environment setup|
|03|Package Management|Installing, updating, removing, inspecting, and managing packages with pnpm|
|04|Dependencies|Production and development dependencies, version ranges, peer dependencies, and dependency management|
|05|pnpm Lockfile|Lockfile concepts, dependency resolution, reproducible installs, updates, and lockfile management|
|06|pnpm Workspaces|Workspace configuration, package relationships, dependency management, and workspace commands|
|07|Monorepos|Monorepo structure, package organization, shared dependencies, filtering, and multi-package workflows|
|08|pnpm Scripts|Package scripts, lifecycle scripts, command execution, filtering, arguments, and automation|
|09|pnpm Security|Dependency risks, audits, package integrity, trusted packages, and secure dependency management|
|10|pnpm Commands|Essential pnpm commands, options, package operations, workspace commands, and practical reference|

## Structure

The notes progress from **pnpm fundamentals → installation → package management → dependencies → lockfile → workspaces → monorepos → scripts → security → commands**.

The first sections establish pnpm's package-management model and installation workflow, followed by package and dependency management. The lockfile section focuses on deterministic dependency resolution and reproducible project installations.

Workspaces introduce multi-package project management, while monorepos build on workspaces to organize and manage larger collections of related packages. Scripts then cover development automation and command execution across projects and workspaces.

The security section addresses dependency and package-management risks. The final section provides a practical command reference for everyday pnpm usage, workspace operations, monorepo management, and project maintenance.

Each topic is separated into focused notes for easier learning, project setup, dependency management, monorepo development, automation, security, and practical reference.
