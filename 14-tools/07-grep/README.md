# grep

Practical, structured notes for using **grep** for searching text, matching patterns, working with regular expressions, searching directories, and analyzing command-line output.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|grep Fundamentals|grep concepts, command structure, input sources, matching behavior, and essential usage|
|02|Pattern Searching|Search patterns, exact matches, multiple patterns, case sensitivity, and text matching|
|03|Options|Common grep options, output control, matching behavior, and practical command combinations|
|04|Regular Expressions|Basic and extended regular expressions, metacharacters, anchors, character classes, and patterns|
|05|Recursive Search|Searching directories, recursive matching, file filtering, hidden files, and directory traversal|
|06|Context Lines|Before and after context, surrounding matches, line ranges, and contextual search output|
|07|grep Examples|Practical search commands, log analysis, source-code searching, pipelines, and reusable examples|

## Structure

The notes progress from **grep fundamentals → pattern searching → options → regular expressions → recursive search → context lines → practical examples**.

The first sections establish grep's command structure and basic text-matching workflow. Pattern searching and options then introduce precise matching and output control for common command-line searches.

Regular expressions extend grep's matching capabilities for more complex search patterns. Recursive search focuses on searching files and directories, while context lines provide additional information around matching results.

The final section brings these concepts together through practical examples for source-code searching, log analysis, command pipelines, and everyday command-line workflows.

Each topic is separated into focused notes for easier learning, daily usage, text searching, scripting, troubleshooting, and practical reference.

> Build a practical grep knowledge base that makes it easy to search and analyze text, locate patterns in files and directories, use regular expressions effectively, and integrate text searching into command-line workflows and scripts.
