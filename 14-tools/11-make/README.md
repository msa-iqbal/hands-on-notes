## Structure

The notes progress from **Make fundamentals → Makefile → targets → variables → pattern rules → dependencies → automatic variables → functions → conditional rules → practical examples**.

The first sections establish Make's build-automation model and Makefile structure. Targets and variables then introduce how build tasks are defined, configured, and reused.

Pattern rules and dependencies explain how Make determines which files need to be rebuilt and how reusable build rules can be applied. Automatic variables provide convenient references for constructing recipes, while functions introduce reusable text, file, and conditional processing.

Conditional rules extend Makefiles with configuration-dependent behavior. The final section brings these concepts together through practical Makefiles and build-automation workflows.

Each topic is separated into focused notes for easier learning, project automation, build configuration, troubleshooting, and practical reference.
