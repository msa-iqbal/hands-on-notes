# VS Code

Practical, structured notes for using **Visual Studio Code** for editing, configuration, extensions, terminal workflows, debugging, source control, tasks, remote development, and troubleshooting.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|VS Code Fundamentals|Editor interface, core concepts, workspace, files, folders, and essential workflows|
|02|Installation|Installation methods, platform requirements, updates, and initial setup|
|03|Settings|User and workspace settings, configuration files, profiles, and customization|
|04|Keyboard Shortcuts|Essential shortcuts, navigation, editing, commands, and productivity workflows|
|05|Extensions|Extension installation, management, configuration, recommendations, and security considerations|
|06|Integrated Terminal|Terminal profiles, shells, commands, environment variables, and terminal workflows|
|07|Debugging|Debug configurations, breakpoints, stepping, variables, watches, and debugging workflows|
|08|Source Control|Git integration, changes, staging, commits, branches, merging, and source-control workflows|
|09|Tasks|Task configuration, automated commands, build tasks, dependencies, and task workflows|
|10|Remote Development|Remote connections, development environments, containers, SSH, and remote workflows|
|11|Troubleshooting|Common problems, diagnostics, extension issues, performance, configuration, and recovery|

## Structure

The notes progress from **VS Code fundamentals → installation → settings → keyboard shortcuts → extensions → integrated terminal → debugging → source control → tasks → remote development → troubleshooting**.

The first sections establish the editor and its configuration, including installation, settings, shortcuts, and extensions. The integrated terminal then covers command-line workflows directly within the editor.

Debugging and source control focus on core development workflows, while tasks introduce automation for builds, commands, and repetitive operations. Remote development extends VS Code to remote systems and development environments.

The final section focuses on diagnosing and resolving common VS Code problems, including configuration, extensions, performance, and development-environment issues.

Each topic is separated into focused notes for easier learning, daily usage, configuration, reference, troubleshooting, and practical development work.
