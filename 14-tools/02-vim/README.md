# Vim

Practical, structured notes for using **Vim** for editing, navigation, search and replacement, buffers, windows, macros, configuration, and efficient command-line editing workflows.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Vim Fundamentals|Vim concepts, interface, basic workflow, command structure, and essential editor operations|
|02|Modes|Normal, Insert, Visual, Command-line, and other Vim modes and their workflows|
|03|Navigation|Cursor movement, files, lines, words, paragraphs, jumps, and efficient navigation|
|04|Editing|Insertion, deletion, copying, pasting, changing text, and editing commands|
|05|Search & Replace|Searching, pattern matching, substitution, ranges, flags, and text replacement|
|06|Buffers|Buffer concepts, opening files, switching buffers, saving, deleting, and buffer management|
|07|Windows & Tabs|Splitting windows, navigating panes, resizing, tabs, and multi-file workflows|
|08|Registers & Macros|Registers, yanking, pasting, recording macros, executing macros, and automation|
|09|Configuration|vimrc configuration, options, key mappings, plugins, and customization|
|10|Vim Commands|Essential commands, command-line operations, file management, and practical command reference|

## Structure

The notes progress from **Vim fundamentals → modes → navigation → editing → search and replace → buffers → windows and tabs → registers and macros → configuration → Vim commands**.

The first sections establish Vim's editing model and modal workflow, followed by navigation and core text-editing techniques. Search and replacement then introduce efficient ways to locate and modify text.

Buffers, windows, and tabs cover working with multiple files and editing contexts. Registers and macros extend Vim with powerful copy, paste, recording, and automation capabilities.

The configuration section focuses on customizing Vim for efficient daily use. The final section provides a practical command reference for common editing and command-line workflows.

Each topic is separated into focused notes for easier learning, daily usage, reference, customization, and practical text-editing work.

## Focus

> Build a practical Vim knowledge base that makes it easy to understand modal editing, navigate and manipulate text efficiently, manage multiple files, automate repetitive work, customize Vim, and use essential commands confidently.
