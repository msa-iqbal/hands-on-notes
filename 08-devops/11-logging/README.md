# Logging

Practical, structured notes for understanding, collecting, forwarding, aggregating, analyzing, and managing **system and application logs**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Fundamentals|Logging basics, log levels, structured logging, and log formats|
|02|Collection|Log collection, forwarding, aggregation, and log rotation|
|03|Tools|`journald`, Fluent Bit, Fluentd, Logstash, and Elasticsearch|
|04|Analysis|Log search, correlation, error analysis, and log retention|

## Structure

The notes progress from **logging fundamentals → log collection → logging tools → log analysis and retention**.

The fundamentals section establishes how logs are generated and structured, including log levels, structured logging, and common log formats. Collection then covers how logs are gathered, forwarded, aggregated, and rotated across systems and applications.

The tools section introduces commonly used components for collecting, processing, and storing logs. The final section focuses on searching and correlating log data, analyzing errors, and managing retention policies.

Each topic is separated into focused notes for easier learning, reference, troubleshooting, and expansion.
