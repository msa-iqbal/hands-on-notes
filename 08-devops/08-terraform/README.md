# Terraform

Practical, structured notes for learning, configuring, provisioning, managing, and automating **infrastructure with Terraform and Infrastructure as Code (IaC)**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Basics|Terraform fundamentals, installation, providers, resources, and data sources|
|02|Configuration|Variables, locals, outputs, expressions, and Terraform functions|
|03|State|Terraform state, state files, remote state, state locking, and state management|
|04|Modules|Terraform modules, module structure, reusable modules, and module versioning|
|05|Workflow|`init`, `plan`, `apply`, `destroy`, and resource import workflows|

## Structure

The notes progress from **Terraform fundamentals → configuration → state management → modules → Terraform workflow**.

The basics section establishes Terraform and Infrastructure as Code concepts before introducing providers, resources, and data sources. Configuration topics then cover the language features used to create flexible and reusable infrastructure definitions.

The state section explains how Terraform tracks managed infrastructure, including local and remote state, locking, and state management. Modules focus on organizing and reusing infrastructure configurations, while the workflow section covers the core Terraform commands used to initialize, plan, apply, destroy, and import infrastructure.

Each topic is separated into focused notes for easier learning, reference, and expansion.
