## Structure

The notes progress from **DevOps fundamentals → containers and orchestration → web infrastructure → CI/CD and automation → deployment → infrastructure as code → configuration management → monitoring and logging → secrets and security → troubleshooting**.

The early sections establish the concepts and tools used throughout the DevOps lifecycle. Docker and Kubernetes cover containerization and orchestration, while Nginx provides practical web-server and reverse-proxy knowledge.

CI/CD, GitHub Actions, and deployment focus on software delivery and release automation. Terraform and Ansible cover infrastructure provisioning and configuration management, while monitoring, logging, and secrets address operational visibility and secure infrastructure management.

The final sections bring these areas together through DevOps security and systematic troubleshooting of real-world operational problems.

Each topic is separated into focused notes for easier learning, reference, practical use, and expansion.
