# Monitoring

Practical, structured notes for understanding, implementing, visualizing, and operating **system and application monitoring, metrics, logs, traces, alerts, and health checks**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Fundamentals|Monitoring basics, metrics, logs, traces, and alerts|
|02|Prometheus|Prometheus fundamentals, metrics, PromQL, targets, and alerting|
|03|Grafana|Grafana fundamentals, dashboards, data sources, and alerting|
|04|Health Checks|Health checks, readiness, liveness, and startup checks|

## Structure

The notes progress from **monitoring fundamentals → Prometheus → Grafana → health checks**.

The fundamentals section establishes the core observability concepts and explains how metrics, logs, traces, and alerts are used to understand system and application behavior. Prometheus then focuses on metrics collection, querying, target management, and alerting.

Grafana covers visualization and dashboards built from monitoring data, while the final section focuses on application and service health through readiness, liveness, and startup checks.

Each topic is separated into focused notes for easier learning, reference, troubleshooting, and expansion.
