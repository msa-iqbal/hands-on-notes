# DevOps Security

Practical, structured notes for securing **DevOps workflows, containers, CI/CD pipelines, secrets, container images, and the software supply chain**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|DevOps Security|DevOps security principles, secure development workflows, access control, hardening, and security practices|
|02|Container Security|Container isolation, runtime security, image security, permissions, vulnerabilities, and container hardening|
|03|CI/CD Security|Pipeline security, permissions, credentials, workflow protection, secure builds, and deployment security|
|04|Secrets Security|Secret protection, access control, secret exposure prevention, rotation, and secure secret handling|
|05|Image Scanning|Container image vulnerability scanning, dependency analysis, security findings, and remediation|
|06|Supply Chain Security|Software supply-chain risks, dependencies, artifact integrity, provenance, signing, and supply-chain protection|

## Structure

The notes progress from **DevOps security fundamentals → container security → CI/CD security → secrets security → image scanning → software supply-chain security**.

The early sections establish security principles across the DevOps lifecycle and then focus on protecting containerized workloads and CI/CD pipelines. Secrets security addresses the protection and lifecycle management of sensitive credentials used by applications and automation.

The final sections focus on identifying vulnerabilities in container images and protecting the broader software supply chain through dependency management, artifact integrity, provenance, and secure software delivery practices.

Each topic is separated into focused notes for easier learning, reference, troubleshooting, and expansion.
