# Docker

Practical, structured notes for learning, building, running, networking, storing, deploying, securing, and managing **Docker containers and images**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Basics|Docker fundamentals, installation, Docker CLI, and Docker architecture|
|02|Images|Docker images, Dockerfiles, image layers, build context, build cache, and multi-stage builds|
|03|Containers|Containers, container lifecycle, container commands, environment variables, resource management, and health checks|
|04|Volumes|Docker volumes, bind mounts, named volumes, volume backups, and storage management|
|05|Networks|Docker networking, bridge and host networks, container communication, DNS, and service discovery|
|06|Compose|Docker Compose, Compose files, services, networks, volumes, environment configuration, and production Compose|
|07|Registry|Container registries, image push and pull, private registries, and image tagging|
|08|Security|Container security, image security, secrets management, and rootless containers|

## Structure

The notes progress from **Docker fundamentals → images → containers → storage and networking → Docker Compose → registries → security**.

The early sections establish how Docker works and how images and containers are created and managed. Volumes and networks then cover persistent storage and communication between containers.

The Compose section focuses on managing multi-container applications, while registries cover image distribution and storage. The final section addresses container and image security, secrets, and rootless execution.

Each topic is separated into focused notes for easier learning, reference, troubleshooting, and expansion.
