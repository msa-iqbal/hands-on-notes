# Ansible

Practical, structured notes for learning, configuring, automating, provisioning, and managing **servers and infrastructure with Ansible**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Basics|Ansible fundamentals, inventory, configuration, and ad-hoc commands|
|02|Playbooks|Playbooks, tasks, handlers, variables, and conditionals|
|03|Roles|Ansible roles, role structure, organization, and reusable roles|
|04|Advanced|Ansible Vault, templates, loops, and error handling|

## Structure

The notes progress from **Ansible fundamentals → playbooks → roles → advanced features**.

The basics section establishes Ansible concepts, inventory management, configuration, and ad-hoc commands for direct system administration. Playbooks then introduce repeatable automation through tasks, handlers, variables, and conditional execution.

The roles section focuses on organizing automation into reusable and maintainable components. The advanced section covers sensitive data protection, dynamic configuration with templates, repeated operations with loops, and handling automation failures.

Each topic is separated into focused notes for easier learning, reference, and expansion.
