# CI/CD

Practical, structured notes for designing, automating, securing, and managing **Continuous Integration, Continuous Delivery, Continuous Deployment, and software delivery pipelines**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Fundamentals|CI/CD basics, continuous integration, continuous delivery, continuous deployment, and pipeline design|
|02|Pipelines|Pipeline stages, builds, testing, packaging, deployment, and rollback|
|03|Strategies|Blue-green deployments, canary deployments, rolling deployments, and feature flags|
|04|Security|Secrets management, artifact security, dependency scanning, and pipeline security|

## Structure

The notes progress from **CI/CD fundamentals → pipeline stages → deployment strategies → pipeline security**.

The fundamentals section establishes the concepts and practices behind continuous integration and software delivery. The pipeline section then covers how source code moves through build, test, package, deployment, and rollback stages.

The strategies section focuses on controlled deployment techniques for reducing deployment risk and managing application releases. The final section addresses security throughout the CI/CD pipeline, including credentials, artifacts, dependencies, and pipeline execution.

Each topic is separated into focused notes for easier learning, reference, and expansion.
