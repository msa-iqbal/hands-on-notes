## Structure

The notes progress from **GitHub Actions fundamentals → workflows and events → jobs and steps → actions and runners → secrets and environments → artifacts and matrices → reusable workflows → deployment → troubleshooting**.

The early sections establish how GitHub Actions workflows are structured and triggered. Jobs, steps, actions, and runners then explain how workflow tasks are executed and automated.

The configuration and reuse sections cover secrets, environments, artifacts, matrix builds, and reusable workflows. Deployment focuses on applying GitHub Actions to software delivery, while the final section provides practical techniques for diagnosing failed workflows and runner or configuration problems.

Each topic is separated into focused notes for easier learning, reference, troubleshooting, and expansion.
