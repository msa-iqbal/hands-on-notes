## Structure

Languages are organized independently so each programming language has a dedicated space for its syntax, concepts, features, examples, and practical development knowledge.

Each language is kept separate to make learning, reference, and maintenance easier without mixing language-specific concepts.

Language-specific notes should remain in their respective directories, while concepts shared across multiple languages can be referenced from the appropriate common section when necessary.
