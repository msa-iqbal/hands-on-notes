# ECMAScript 2016 (ES7)

ECMAScript 2016, commonly known as ES7, is the seventh edition of the ECMAScript language specification.

It was released in June 2016 as the successor to ECMAScript 2015 (ES6).

Unlike ES6, which introduced many major language features, ES2016 was a relatively small update with two primary additions:

* The `Array.prototype.includes()` method.
* The exponentiation operator (`**`).

These features improved array searching and mathematical expressions without significantly changing JavaScript's overall syntax.

# 🗁 What Is ECMAScript 2016?

ECMAScript 2016 introduced incremental improvements to JavaScript.

Starting with ES2016, ECMAScript moved toward a yearly release schedule, allowing new language features to be standardized in smaller, more predictable updates.

Important terminology:

* **ECMAScript:** The standardized specification for JavaScript.
* **ES7:** The informal name for ECMAScript 2016.
* **ES2016:** The official edition name.
* **TC39:** The committee responsible for evolving ECMAScript.

# 🗁 Major ES2016 Features

ES2016 introduced two main language features.

| Feature | Description |
| --- | --- |
| `Array.prototype.includes()` | Checks whether an array contains a particular value |
| Exponentiation operator (`**`) | Calculates the power of a number |

# 🗁 Array.prototype.includes()

Before ES2016, developers commonly used `indexOf()` to determine whether an array contained a particular value.

Example using `indexOf()`:

```javascript
const fruits = ["Apple", "Banana", "Orange"];

console.log(fruits.indexOf("Banana") !== -1); // true
console.log(fruits.indexOf("Mango") !== -1);  // false
```

ES2016 introduced `includes()`, which provides a more readable way to perform this check.

```javascript
const fruits = ["Apple", "Banana", "Orange"];

console.log(fruits.includes("Banana")); // true
console.log(fruits.includes("Mango"));  // false
```

**Syntax**

```javascript
array.includes(searchElement, fromIndex);
```

Parameters:

* `searchElement`: The value to search for.
* `fromIndex`: Optional index from which the search begins.

Returns:

* `true` if the value is found.
* `false` otherwise.

**Searching from a specific index**

```javascript
const numbers = [10, 20, 30, 40, 50];

console.log(numbers.includes(20, 2)); // false
console.log(numbers.includes(30, 2)); // true
```

The search begins at index `2`.

**Using negative indexes**

A negative `fromIndex` starts the search relative to the end of the array.

```javascript
const numbers = [10, 20, 30, 40, 50];

console.log(numbers.includes(40, -2)); // true
console.log(numbers.includes(20, -2)); // false
```

The value `-2` means the search starts at the second-to-last element.

**Checking for NaN**

One important difference between `includes()` and `indexOf()` is how they handle `NaN`.

```javascript
const values = [10, 20, NaN, 40];

console.log(values.includes(NaN)); // true
console.log(values.indexOf(NaN)); // -1
```

`includes()` uses SameValueZero comparison, which considers `NaN` equal to itself.

**Checking object references**

For objects, `includes()` compares references rather than object contents.

```javascript
const firstUser = {
  id: 1,
  name: "Alice"
};

const secondUser = {
  id: 1,
  name: "Alice"
};

const users = [firstUser];

console.log(users.includes(firstUser));  // true
console.log(users.includes(secondUser)); // false
```

Although both objects contain identical properties, they are different object references.

# 🗁 Exponentiation Operator

ES2016 introduced the exponentiation operator (`**`) as a shorter alternative to `Math.pow()`.

It calculates a number raised to a specified power.

Before ES2016:

```javascript
console.log(Math.pow(2, 3)); // 8
console.log(Math.pow(5, 2)); // 25
```

Using the exponentiation operator:

```javascript
console.log(2 ** 3); // 8
console.log(5 ** 2); // 25
```

**Syntax**

```javascript
base ** exponent;
```

Examples:

```javascript
console.log(2 ** 4);  // 16
console.log(3 ** 3);  // 27
console.log(10 ** 2); // 100
console.log(4 ** 0);  // 1
console.log(2 ** -2); // 0.25
```

**Fractional exponents**

Exponentiation also supports fractional exponents.

```javascript
console.log(9 ** 0.5); // 3
console.log(8 ** (1 / 3)); // 2
```

A fractional exponent can represent a root operation.

**Negative bases**

Parentheses are necessary when using a negative base.

```javascript
console.log((-2) ** 2); // 4
console.log((-2) ** 3); // -8
```

Without parentheses:

```javascript
console.log(-2 ** 2); // SyntaxError
```

The unary negation operator cannot appear immediately before the base of an exponentiation expression.

**Exponentiation assignment operator**

JavaScript also supports the exponentiation assignment operator (`**=`).

```javascript
let number = 2;

number **= 3;

console.log(number); // 8
```

This is equivalent to:

```javascript
number = number ** 3;
```

# 🗁 Practical Examples

**Checking supported permissions**

```javascript
const permissions = [
  "read",
  "write",
  "delete"
];

function hasPermission(permission) {
  return permissions.includes(permission);
}

console.log(hasPermission("read"));   // true
console.log(hasPermission("execute")); // false
```

**Validating allowed file extensions**

```javascript
const allowedExtensions = [
  ".jpg",
  ".png",
  ".webp"
];

function isAllowedFile(filename) {
  const extension = filename.slice(filename.lastIndexOf("."));

  return allowedExtensions.includes(extension.toLowerCase());
}

console.log(isAllowedFile("photo.png")); // true
console.log(isAllowedFile("document.pdf")); // false
```

**Calculating compound values**

```javascript
const principal = 1000;
const rate = 0.05;
const years = 3;

const amount = principal * (1 + rate) ** years;

console.log(amount);
```

**Calculating square and cube values**

```javascript
function square(number) {
  return number ** 2;
}

function cube(number) {
  return number ** 3;
}

console.log(square(5)); // 25
console.log(cube(3));   // 27
```

# 🗁 ES2016 vs ES2015

| ES2015 (ES6) | ES2016 (ES7) |
| --- | --- |
| Introduced `let` and `const` | Introduced `includes()` |
| Introduced arrow functions | Introduced `**` |
| Introduced template literals | Added incremental language improvements |
| Introduced classes | Continued yearly standardization |
| Introduced native modules | Focused on smaller language updates |
| Introduced promises | |

ES2015 was a major language evolution, while ES2016 focused on targeted improvements.

# 🗁 Browser and Runtime Compatibility

Both `Array.prototype.includes()` and the exponentiation operator are supported by modern JavaScript engines.

Older environments may require compatibility solutions.

For `includes()`, a polyfill can provide the missing method.

For exponentiation syntax, a transpiler such as Babel can transform the expression into compatible JavaScript.

Example:

```javascript
const result = 2 ** 3;
```

Can be transformed into:

```javascript
var result = Math.pow(2, 3);
```

Remember that syntax transformation and runtime polyfills solve different compatibility problems.

# 🗁 Best Practices

* Use `includes()` when checking whether an array contains a value.
* Prefer `includes()` over `indexOf() !== -1` when only a Boolean result is needed.
* Remember that `includes()` uses SameValueZero comparison.
* Understand that objects are compared by reference.
* Use `**` for exponentiation instead of `Math.pow()` when it improves readability.
* Use parentheses when working with negative bases.
* Use `**=` when updating a variable with its exponentiated value.
* Consider runtime compatibility when supporting older environments.

# 🗁 Key Takeaways

* ES2016 is the seventh edition of ECMAScript.
* It was released in June 2016.
* `Array.prototype.includes()` checks whether an array contains a value.
* `includes()` supports searching from a specific index.
* `includes()` can find `NaN`, unlike `indexOf()`.
* Objects are compared by reference when using `includes()`.
* The exponentiation operator (`**`) calculates powers.
* The exponentiation assignment operator (`**=`) updates a variable.
* ES2016 introduced smaller, incremental improvements following the major ES2015 release.
