# JavaScript

Practical, structured notes for learning and using **JavaScript**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Basics|Introduction, setup, first program, strict mode|
|02|Syntax|Statements, expressions, operators, variables, `let`, `const`, `var`|
|03|Types|Primitive types, objects, coercion, conversion|
|04|Control Flow|Conditions, loops, `break`, `continue`, `for...of`, `for...in`|
|05|Functions|Declarations, expressions, arrows, parameters, callbacks, recursion|
|06|Scope & Closures|Scope, lexical scope, closures, hoisting|
|07|Objects|Properties, methods, `this`, prototypes, prototype chain|
|08|Classes|Classes, constructors, methods, inheritance, private fields|
|09|Arrays & Collections|Arrays, array methods, `Map`, `Set`, `WeakMap`, `WeakSet`|
|10|Strings & Regex|String manipulation, searching, templates, regular expressions|
|11|Errors & Debugging|Errors, `try/catch`, custom errors, DevTools, debugging|
|12|Async|Callbacks, promises, `async/await`, event loop, timers|
|13|Modules|ES modules, imports, exports, dynamic imports, CommonJS|
|14|DOM|Elements, attributes, styles, events, forms, event delegation|
|15|Browser API|Window, location, history, storage, Fetch, URL, workers|
|16|JSON & Data|JSON parsing, serialization, transformation|
|17|Functional Programming|Pure functions, immutability, composition, currying|
|18|Testing|Unit, integration, mocking, frameworks, coverage|
|19|Tooling|Node.js, npm, packages, scripts, bundlers, transpilers, linting|
|20|Modern JavaScript|ES6–ES2025 and modern language features|
|21|Advanced|Execution model, call stack, memory, GC, metaprogramming, performance|

## Structure

The notes progress from **JavaScript fundamentals → core language → browser APIs → tooling → modern and advanced concepts**.

Each topic is separated into focused notes for easy learning and reference.

## Focus

- JavaScript fundamentals
- Core language concepts
- Functions, objects, and classes
- Scope, closures, and prototypes
- Arrays and collections
- Asynchronous programming
- Modules and browser APIs
- DOM manipulation
- Functional programming
- Testing and tooling
- Modern ECMAScript features
- Runtime, memory, and performance

## Goal

> Learn JavaScript systematically, understand its runtime behavior, and keep practical knowledge easy to find.
