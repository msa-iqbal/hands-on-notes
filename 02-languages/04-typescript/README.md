# TypeScript

Practical, structured notes for learning and using **TypeScript**.

## Contents

| #   | Topic                       | What You'll Learn                                                                               |
| --- | --------------------------- | ----------------------------------------------------------------------------------------------- |
| 01  | Basics                      | Introduction, setup, compilation, `tsc`, and TypeScript vs JavaScript                           |
| 02  | Syntax                      | Statements, expressions, variables, operators, and type annotations                             |
| 03  | Basic Types                 | Primitive types, `any`, `unknown`, `never`, `void`, objects, symbols, and bigint                |
| 04  | Functions                   | Function types, parameters, return types, overloads, callbacks, and `this`                      |
| 05  | Arrays & Tuples             | Arrays, readonly arrays, tuples, optional and rest elements                                     |
| 06  | Objects & Interfaces        | Object types, type aliases, interfaces, extension, merging, and index signatures                |
| 07  | Unions & Narrowing          | Unions, intersections, type guards, predicates, discriminated unions, and exhaustiveness        |
| 08  | Enums & Literals            | Enums, literal types, template literals, and `as const`                                         |
| 09  | Generics                    | Generic functions, interfaces, classes, constraints, `keyof`, and generic patterns              |
| 10  | Classes                     | Classes, access modifiers, constructors, inheritance, abstract classes, and static members      |
| 11  | Utility Types               | `Partial`, `Required`, `Readonly`, `Pick`, `Omit`, `Record`, `Exclude`, `Extract`, and more     |
| 12  | Advanced Types              | Conditional, mapped, indexed-access, recursive, branded, and distributive types                 |
| 13  | Modules                     | Imports, exports, type-only imports/exports, module resolution, and declaration merging         |
| 14  | Generators & Iterators      | Iterators, iterables, generators, and async iterators                                           |
| 15  | Decorators                  | Decorators, classes, methods, properties, and metadata                                          |
| 16  | Error Handling              | Error types, `unknown` in `catch`, custom errors, narrowing, and safe handling                  |
| 17  | Configuration               | `tsconfig`, compiler options, strict mode, targets, modules, aliases, and project references    |
| 18  | Tooling                     | `tsc`, `ts-node`, `tsx`, ESLint, Prettier, npm, and build tools                                 |
| 19  | Testing                     | Unit testing, Jest, Vitest, mocking, type testing, and coverage                                 |
| 20  | JavaScript Interoperability | JavaScript compatibility, JSDoc, declaration files, ambient declarations, and third-party types |
| 21  | Advanced                    | Type inference, structural typing, variance, augmentation, performance, and large projects      |

## Structure

The notes progress from **TypeScript fundamentals → type system → generics → advanced types → tooling → interoperability → advanced concepts**.

Each topic is separated into focused notes for easier learning and reference.

## Focus

- TypeScript fundamentals
- Static typing and type inference
- Functions, objects, interfaces, and classes
- Generics and utility types
- Type narrowing and advanced types
- Modules and configuration
- JavaScript interoperability
- Modern TypeScript tooling
- Testing and type testing
- Large-project patterns and performance

## Goal

> Learn TypeScript systematically, understand its type system, and keep practical knowledge easy to find.
