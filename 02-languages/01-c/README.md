# C

Practical, structured notes for learning and using **C**.

## Contents

| #   | Topic           | What You'll Learn                                                              |
| --- | --------------- | ------------------------------------------------------------------------------ |
| 01  | Basics          | Introduction, installation, compilation, first program, build & run            |
| 02  | Syntax          | Statements, expressions, operators, identifiers, scope, preprocessor           |
| 03  | Types           | Data types, variables, pointers, arrays, strings, structs, unions, enums       |
| 04  | Control Flow    | Conditions, loops, `break`, `continue`, `goto`                                 |
| 05  | Functions       | Functions, parameters, return values, scope, recursion, variadic functions     |
| 06  | Memory          | Memory model, stack/heap, pointers, dynamic allocation, memory leaks           |
| 07  | I/O             | Standard I/O, input/output, formatting, files, binary files, errors            |

| 09  | Modules         | Source/header files, linkage, `static`, `extern`, multi-file projects          |
| 10  | Libraries       | Standard library, strings, character handling, math, time, assertions          |
| 11  | Errors          | Warnings, `errno`, error handling, assertions, debugging                       |
| 12  | Concurrency     | Processes, threads, POSIX threads, mutexes, condition variables, semaphores    |
| 13  | Data Structures | Arrays, linked lists, stacks, queues, hash tables, trees, graphs               |
| 14  | Testing         | Testing basics, unit tests, frameworks, mocking, coverage                      |
| 15  | Advanced        | Pointers, bit operations, alignment, endianness, UB, optimization, portability |

## Structure

The notes progress from **C fundamentals → language features → memory → libraries → concurrency → advanced concepts**.

Each topic is kept separate for focused learning and quick reference.

## Focus

- C language fundamentals
- Pointers and memory management
- Functions and data structures
- File and standard I/O
- Preprocessor and multi-file projects
- Standard library
- Error handling and debugging
- Concurrency and POSIX threads
- Testing and code quality
- Performance and portability
- C standards and language behavior

## Goal

> Learn C systematically, understand how it works at a low level, and keep practical knowledge easy to find.
