# C++

Practical, structured notes for learning and using **C++**.

## Contents

| #   | Topic             | What You'll Learn                                                             |

| 03  | Types             | Fundamental types, variables, constants, conversions, enums, structs, unions  |

| 05  | Functions         | Parameters, return values, overloading, recursion, lambdas, function pointers |
| 06  | OOP               | Classes, objects, constructors, inheritance, polymorphism, virtual functions  |

| 08  | STL               | Containers, strings, iterators, pairs, tuples                                 |

| 12  | I/O               | Streams, console I/O, files, string streams, formatting                       |

## Structure

The notes move from **fundamentals → language features → memory → STL → modern C++ → advanced concepts**.

Each topic is kept separate so it can be studied, referenced, or expanded independently.

## Focus

- Practical examples
- Clear explanations
- Modern C++ practices
- Memory and resource management
- STL and standard library usage
- Build and debugging workflows
- Performance and portability
- C++ standards and evolution

## Goal

> Learn C++ systematically, understand how it works, and keep practical knowledge easy to find.
