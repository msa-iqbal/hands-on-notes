# HTML

Practical, reusable **HTML snippets** for creating document structures, text content, links, images, lists, tables, forms, semantic elements, metadata, and common web-page structures.

|#|Topic|What You'll Learn|

|02|Headings and Text|Headings, paragraphs, emphasis, strong text, quotations, code, and common text elements|

|04|Images|Images, `src`, `alt`, dimensions, responsive images, figures, and common image patterns|

## Structure

The snippets progress from **document structure → text content → links and images → lists and tables → forms → semantic elements → metadata → common tasks**.

The first sections establish the basic structure of an HTML document and provide reusable patterns for headings, text, links, and images. These form the foundation for creating common web-page content.

Lists and tables then cover structured content presentation, while forms introduce practical patterns for collecting and submitting user input.

Semantic elements focus on creating meaningful and well-structured HTML using appropriate elements for page sections and content. Meta tags then cover commonly required metadata and document-level configuration.

The final section collects frequently used HTML solutions for everyday page structures, components, and markup tasks.

Each topic is separated into focused snippets for **quick lookup, adaptation, and reuse**.
