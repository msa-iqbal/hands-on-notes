# Bash

Practical, reusable **Bash scripting snippets** for automating tasks, processing files, managing processes, working with networks, and performing common system administration operations.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Variables|Variable declaration, assignment, expansion, environment variables, command substitution, and common variable operations|
|02|Conditions|`if`, `elif`, `else`, `case`, comparisons, logical operators, and conditional expressions|
|03|Loops|`for`, `while`, `until`, nested loops, loop control, `break`, and `continue`|
|04|Functions|Function definition, parameters, return values, local variables, reusable logic, and function patterns|
|05|Arrays|Indexed arrays, associative arrays, accessing elements, iteration, modification, and array operations|
|06|Files and Directories|Creating, reading, copying, moving, deleting, testing, searching, and managing files and directories|
|07|Text Processing|`grep`, `sed`, `awk`, `cut`, `sort`, `uniq`, `tr`, `head`, `tail`, pipes, redirection, and text manipulation|
|08|Processes|Process inspection, background jobs, signals, process control, job management, and process monitoring|
|09|Networking|Network commands, connectivity checks, DNS, ports, HTTP requests, downloads, and basic network automation|
|10|System Administration|Users, permissions, services, packages, environment configuration, system information, logs, and administrative automation|

## Structure

The snippets progress from **Bash fundamentals → control flow → reusable functions and data structures → file and text processing → process management → networking → system administration**.

The first sections cover the core building blocks of Bash scripting, including variables, conditions, loops, functions, and arrays. These provide the foundation for writing reusable shell scripts and automating repetitive tasks.

File and directory snippets then cover common filesystem operations, while text-processing snippets focus on working efficiently with command output and structured or unstructured text.

Process and networking sections provide practical techniques for managing running programs, checking system connectivity, interacting with network services, and automating network-related tasks.

The final section focuses on system administration tasks such as users, permissions, services, packages, configuration, logs, and system maintenance.

Each topic is separated into focused snippets for **quick lookup, adaptation, and reuse**.
