# PowerShell

Practical, reusable **PowerShell scripting snippets** for automating Windows tasks, managing files and directories, controlling processes and services, working with networks, accessing the registry, and performing system administration operations.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Variables|Variable declaration, assignment, data types, environment variables, automatic variables, and variable operations|
|02|Conditions|`if`, `elseif`, `else`, `switch`, comparisons, logical operators, and conditional expressions|
|03|Loops|`for`, `foreach`, `while`, `do`, nested loops, loop control, `break`, and `continue`|
|04|Functions|Function definition, parameters, return values, scopes, advanced functions, reusable logic, and function patterns|
|05|Arrays and Hashtables|Arrays, hashtables, collections, accessing elements, iteration, modification, and data operations|
|06|Files and Directories|Creating, reading, copying, moving, deleting, searching, testing, and managing files and directories|
|07|Processes and Services|Process inspection, process control, jobs, Windows services, service management, and monitoring|
|08|Networking|Network configuration, connectivity checks, DNS, IP addresses, ports, HTTP requests, and network automation|
|09|Registry|Registry paths, keys, values, reading, modifying, creating, deleting, and registry management|
|10|System Administration|Users, permissions, packages, scheduled tasks, system information, event logs, configuration, and administrative automation|

## Structure

The snippets progress from **PowerShell fundamentals → control flow → functions and data structures → filesystem operations → processes and services → networking → registry → system administration**.

The first sections cover the core building blocks of PowerShell scripting, including variables, conditions, loops, functions, arrays, and hashtables. These provide the foundation for writing reusable scripts and automating Windows tasks.

Files and directories then cover common filesystem operations, while processes and services focus on managing running applications and Windows services.

The networking section provides practical snippets for connectivity, DNS, IP configuration, ports, HTTP requests, and network automation. Registry snippets then cover common operations for inspecting and managing the Windows Registry.

The final section brings these capabilities together for system administration tasks such as user management, permissions, scheduled tasks, event logs, system information, configuration, and automation.

Each topic is separated into focused snippets for **quick lookup, adaptation, and reuse**.
