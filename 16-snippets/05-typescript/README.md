# TypeScript

Practical, reusable **TypeScript snippets** for type definitions, interfaces, unions, generics, functions, utility types, objects, arrays, error handling, and common development tasks.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Types|Primitive types, type annotations, type inference, literal types, tuples, enums, and common type definitions|
|02|Interfaces|Interface declarations, properties, optional properties, readonly properties, extension, and reusable object contracts|
|03|Types and Unions|Type aliases, union types, intersection types, literal unions, narrowing, and combining types|
|04|Generics|Generic functions, types, interfaces, constraints, parameters, defaults, and reusable type-safe patterns|
|05|Functions|Function types, parameters, return types, optional parameters, default values, overloads, and callbacks|
|06|Utility Types|`Partial`, `Required`, `Readonly`, `Pick`, `Omit`, `Record`, `Exclude`, `Extract`, `ReturnType`, and related utilities|
|07|Objects|Object types, property access, destructuring, spreading, narrowing, type assertions, and object transformations|
|08|Arrays|Typed arrays, tuples, iteration, mapping, filtering, reducing, searching, sorting, and array transformations|
|09|Error Handling|Error types, `try/catch`, custom errors, type-safe error handling, narrowing, and safe failure handling|
|10|Common Tasks|Frequently used TypeScript solutions for everyday programming and development tasks|

## Structure

The snippets progress from **type fundamentals → interfaces and type composition → generics → functions and utility types → objects and arrays → error handling → common tasks**.

The first sections focus on TypeScript's type system, including basic types, interfaces, type aliases, unions, intersections, and type narrowing. These provide the foundation for writing type-safe and maintainable code.

Generics then introduce reusable type-safe patterns, followed by function snippets covering typed parameters, return values, callbacks, and function overloads. Utility types provide concise ways to transform and reuse existing types.

Objects and arrays focus on practical data manipulation while preserving type safety. Error-handling snippets then cover safe exception handling, custom errors, and working with values of uncertain types.

The final section collects frequently used TypeScript solutions for everyday development tasks that do not belong to a single specialized topic.

Each topic is separated into focused snippets for **quick lookup, adaptation, and reuse**.
