The notes focus on **Visual Studio Code**, covering its core features and practical development workflow.

The Visual Studio Code section introduces the editor, configuration, extensions, integrated terminal, source control, debugging, workspace settings, and productivity features. VS Code also provides integrated source control and debugging capabilities as part of its development workflow.

Each topic is kept in a focused guide for easier learning, configuration, troubleshooting, productivity improvement, and daily development reference.
