# SQL

Practical, reusable **SQL snippets** for querying, inserting, updating, deleting, joining, aggregating, transforming, and analyzing relational database data.

## Structure

The snippets progress from **basic data retrieval → data modification → table relationships → aggregation → subqueries → CTEs → analytical queries → common tasks**.

The first sections cover the core SQL data-manipulation operations: `SELECT`, `INSERT`, `UPDATE`, and `DELETE`. These provide the foundation for retrieving and modifying relational data.

Joins then introduce techniques for combining data across multiple tables, followed by aggregation for grouping and summarizing query results. Subqueries provide reusable query logic for filtering and deriving data from nested queries.

CTEs improve the organization and readability of complex queries, while window functions provide practical techniques for ranking, partitioning, calculating running values, and performing analytical operations without collapsing result rows.

The final section collects frequently used SQL solutions for everyday querying, reporting, data manipulation, and database work.

Each topic is separated into focused snippets for **quick lookup, adaptation, and reuse**.
