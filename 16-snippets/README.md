# Snippets

Practical, structured code snippets for **common programming, scripting, database, markup, and styling tasks**, covering Bash, PowerShell, JavaScript, TypeScript, SQL, HTML, and CSS.

|02|PowerShell|Variables, conditions, loops, functions, arrays, hashtables, files and directories, processes, services, networking, registry, and system administration|

|04|TypeScript|Types, interfaces, unions, generics, functions, utility types, objects, arrays, error handling, and common development tasks|
|05|SQL|SELECT, INSERT, UPDATE, DELETE, joins, aggregation, subqueries, CTEs, window functions, and common database tasks|

|07|CSS|Selectors, colors, backgrounds, box model, Flexbox, Grid, positioning, responsive design, animations, pseudo-classes, and common styling tasks|

## Structure

The snippets progress from **shell scripting → Windows scripting → JavaScript → TypeScript → SQL → HTML → CSS**.

The first sections focus on command-line and system scripting. Bash covers Unix-like environments, while PowerShell covers Windows-oriented scripting and administration.

The JavaScript and TypeScript sections provide reusable programming patterns for everyday development tasks. SQL focuses on common database queries and data manipulation operations.

The final sections cover HTML and CSS snippets for building and styling web interfaces.

Each technology is separated into focused notes so frequently used solutions can be quickly located, copied, adapted, and reused.
