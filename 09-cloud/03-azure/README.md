# Azure

Practical, structured notes for learning, configuring, deploying, securing, monitoring, and troubleshooting **Microsoft Azure cloud services and infrastructure**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Basics|Azure fundamentals, subscriptions, resource groups, regions, Azure Portal, and Azure CLI|
|02|Compute|Virtual Machines, VM Scale Sets, Load Balancer, and App Service|
|03|Storage|Storage accounts, Blob Storage, File Storage, Disk Storage, and storage tiers|
|04|Database|Azure SQL, Cosmos DB, PostgreSQL, and MySQL|
|05|Networking|Virtual Networks, subnets, route tables, NSGs, load balancing, Application Gateway, DNS, and VPN|
|06|Serverless|Azure Functions, Logic Apps, Event Grid, and event-driven application workflows|
|07|Identity|Microsoft Entra ID, users, groups, roles, and role-based access control|
|08|Monitoring|Azure Monitor, Activity Log, Application Insights, logging, and operational visibility|
|09|Troubleshooting|Diagnosing Virtual Machine, storage, networking, identity, configuration, and access problems|

## Structure

The notes progress from **Azure fundamentals → compute → storage → databases → networking → serverless → identity → monitoring → troubleshooting**.

The basics section establishes Azure's management hierarchy, regional infrastructure, and primary management tools. Compute, storage, and database sections then cover the core services used to run applications and manage data.

Networking focuses on building and securing Azure network infrastructure, while serverless introduces managed and event-driven application services. Identity covers Microsoft Entra ID and Azure RBAC for authentication and access control, followed by monitoring and application observability.

The final section provides practical approaches for diagnosing common Azure infrastructure, service, networking, storage, and identity problems.

Each topic is separated into focused notes for easier learning, reference, and expansion.
