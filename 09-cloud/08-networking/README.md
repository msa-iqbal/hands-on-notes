# Networking

Practical, structured notes for understanding, designing, securing, connecting, and troubleshooting **cloud and distributed network infrastructure**.

## Structure

The notes progress from **cloud networking fundamentals → virtual networks → subnet design → routing → internet connectivity → NAT → firewalls → load balancing → DNS → VPN → private connectivity → network security**.

The early sections establish cloud networking architecture and virtual network design. Subnets, routing, internet connectivity, and NAT then explain how traffic moves between workloads, private networks, and external destinations.

Firewalls and load balancing cover traffic filtering and distribution, while DNS and VPN address service discovery and secure connectivity. Private connectivity focuses on accessing cloud services without exposing traffic unnecessarily to public networks.

The final section brings these concepts together through network security, segmentation, isolation, and defense-in-depth practices.

Each topic is separated into focused notes for easier learning, reference, troubleshooting, and expansion.
