# Cloud Architecture

Practical, structured notes for understanding, designing, scaling, securing, and operating **cloud architectures, distributed systems, resilient workloads, and common cloud architecture patterns**.

## Structure

The notes progress from **architecture fundamentals → scalability → high availability → resilience → event-driven architecture → microservices → serverless architecture → multi-region → multi-cloud → reference architectures**.

The first section establishes the fundamentals of cloud architecture and well-architected design principles. Scalability then focuses on increasing or decreasing application capacity through horizontal and vertical scaling.

High availability and resilience cover redundancy, fault tolerance, failure handling, and designing systems that can continue operating during component or infrastructure failures. Event-driven architecture introduces asynchronous communication and event-based system design.

Microservices focuses on decomposing applications into independently developed and deployed services, while serverless architecture covers managed execution environments and cloud-native application patterns.

Multi-region and multi-cloud sections address geographic distribution, regional resilience, provider diversity, and workload portability. The final section brings these concepts together through practical reference architectures for common application types.

Each topic is separated into focused notes for easier learning, reference, practical use, and expansion.
