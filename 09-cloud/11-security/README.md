## Structure

The notes progress from **cloud security fundamentals → network security → data security → encryption → secrets management → security monitoring → compliance → security best practices**.

The first section establishes the basic security principles used throughout cloud environments. Network security then focuses on protecting cloud networks through segmentation, traffic controls, and isolation.

Data security covers protecting and classifying information stored or processed in cloud environments. Encryption focuses specifically on protecting data **at rest** and **in transit**.

Secrets management covers the secure handling of credentials, API keys, tokens, passwords, and other sensitive configuration values. Security monitoring focuses on collecting security-related logs, detecting suspicious activity, and responding to security alerts.

The compliance section introduces the relationship between cloud infrastructure, security controls, governance, and regulatory requirements. The final section consolidates practical security practices that can be applied across cloud workloads.

## Security Principles

These notes should consistently reinforce several core security principles:

- **Least privilege** — grant only the permissions required to perform a task.
- **Defense in depth** — use multiple independent security controls rather than relying on a single control.
- **Secure by default** — avoid unnecessary exposure and insecure default configurations.
- **Encryption** — protect sensitive data both at rest and in transit.
- **Secrets isolation** — keep credentials and sensitive values outside source code and public configuration.
- **Network segmentation** — separate workloads and trust boundaries where appropriate.
- **Monitoring and auditing** — maintain sufficient logs and visibility to detect and investigate security events.
- **Regular rotation** — rotate credentials, secrets, and cryptographic material according to the applicable security requirements.
- **Data classification** — apply protection controls according to the sensitivity and importance of the data.
- **Continuous improvement** — regularly review security controls, configurations, and operational practices.
