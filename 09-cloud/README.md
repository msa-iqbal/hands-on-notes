## Structure

The notes progress from **cloud fundamentals → cloud providers → core cloud infrastructure → cloud-native services → security and identity → monitoring and cost management → availability and recovery → migration → architecture → troubleshooting**.

The first section establishes the concepts and principles behind cloud computing. AWS, Azure, and GCP then provide provider-specific knowledge, while the following sections cover provider-neutral concepts for compute, storage, databases, networking, serverless, and containers.

Security, identity and access, monitoring, and cost management address the operational requirements of running cloud workloads securely, visibly, and efficiently. High availability and disaster recovery focus on maintaining service continuity and recovering from failures or disruptive events.

Migration covers moving existing workloads, applications, databases, and data into cloud environments. Cloud architecture brings these concepts together through scalable, resilient, event-driven, microservices, serverless, multi-region, and multi-cloud architectures.

The final section provides practical troubleshooting approaches for common cloud infrastructure, service, configuration, access, and operational problems, including provider-specific troubleshooting for AWS, Azure, and GCP.

Each topic is separated into focused notes for easier learning, reference, practical use, and expansion.
