# Migration

Practical, structured notes for understanding, planning, executing, and managing **cloud migrations, workload migrations, data migrations, application migrations, and migration strategies**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Cloud Migration|Cloud migration fundamentals, migration concepts, assessment, planning, and migration readiness|
|02|Migration Strategies|Rehost, replatform, refactor, repurchase, retain, retire, and migration strategy selection|
|03|Server Migration|Server migration, workload movement, infrastructure migration, and server migration processes|
|04|Database Migration|Database migration, schema and data movement, database migration planning, and migration approaches|
|05|Application Migration|Application migration, application dependencies, workload preparation, and application migration processes|
|06|Data Migration|Data migration, data transfer, data validation, synchronization, and migration integrity|
|07|Migration Planning|Migration assessment, dependency analysis, prioritization, sequencing, and migration roadmaps|

## Structure

The notes progress from **cloud migration → migration strategies → server migration → database migration → application migration → data migration → migration planning**.

The first section establishes the fundamentals of cloud migration and covers migration assessment, readiness, planning, and the factors involved in moving workloads to cloud environments.

Migration strategies then introduce common approaches including **rehost, replatform, refactor, repurchase, retain, and retire**. These strategies provide different ways to determine how existing workloads should be handled during migration.

Server, database, application, and data migration sections focus on the specific workload types that may need to be moved, including their dependencies, preparation, transfer, validation, and cutover requirements.

The final section focuses on migration planning through assessment, dependency analysis, workload prioritization, migration sequencing, and roadmap development.

Each topic is separated into focused notes for easier learning, reference, practical use, and expansion.
