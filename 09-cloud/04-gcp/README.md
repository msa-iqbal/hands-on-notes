# GCP

Practical, structured notes for learning, configuring, deploying, securing, monitoring, and troubleshooting **Google Cloud Platform (GCP) services and infrastructure**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Basics|GCP fundamentals, projects, organizations, regions, zones, Cloud Console, and `gcloud` CLI|
|02|Compute|Compute Engine, Managed Instance Groups, Cloud Run, and load balancing|
|03|Storage|Cloud Storage, storage classes, Persistent Disk, and cloud storage management|
|04|Database|Cloud SQL, Firestore, Bigtable, Spanner, and managed database services|
|05|Networking|VPCs, subnets, firewall rules, Cloud NAT, load balancing, Cloud DNS, and VPN|
|06|Serverless|Cloud Functions, Cloud Run, Workflows, and serverless application workflows|
|07|IAM|Users, service accounts, roles, permissions, and identity and access management|
|08|Monitoring|Cloud Monitoring, Cloud Logging, Error Reporting, and operational visibility|
|09|Troubleshooting|Diagnosing compute, storage, networking, IAM, configuration, and access problems|

## Structure

The notes progress from **GCP fundamentals → compute → storage → databases → networking → serverless → IAM → monitoring → troubleshooting**.

The basics section establishes GCP's resource hierarchy, project structure, geographic infrastructure, and primary management tools. Compute, storage, and database sections then cover the core services used to run applications and manage data.

Networking focuses on VPC architecture, traffic control, connectivity, DNS, and load balancing. Serverless covers managed application execution and workflow services, while IAM explains users, service accounts, roles, and permissions.

The final sections focus on operational visibility and practical troubleshooting of common GCP compute, storage, networking, and identity problems.

Each topic is separated into focused notes for easier learning, reference, and expansion.
