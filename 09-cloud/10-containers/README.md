# Containers

Practical, structured notes for understanding, managing, deploying, networking, scaling, and securing **cloud-based container platforms and managed container environments**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Container Platforms|Managed container platforms, container services, execution environments, and cloud container infrastructure|
|02|Container Registries|Managed container registries, image storage, image management, versioning, and distribution|
|03|Managed Kubernetes|Amazon EKS, Azure AKS, Google GKE, managed Kubernetes architecture, and cluster management|
|04|Container Deployment|Container deployment patterns, workload management, scaling, and deployment strategies|
|05|Container Networking|Cloud container networking, service connectivity, network isolation, and container traffic|
|06|Container Security|Container security fundamentals, image security, vulnerability management, and secure container practices|

## Structure

The notes progress from **container platforms → container registries → managed Kubernetes → container deployment → container networking → container security**.

The first sections establish how managed container platforms execute workloads and how container images are stored, versioned, and distributed through registries. Managed Kubernetes then covers cloud-managed Kubernetes services and the infrastructure used to operate container clusters.

Container deployment focuses on practical workload deployment, deployment patterns, and auto scaling. Container networking explains how containerized workloads communicate with other services and networks in cloud environments.

The final section focuses on securing container workloads and images through security controls, vulnerability management, and secure container practices.

Each topic is separated into focused notes for easier learning, reference, practical use, and expansion.
