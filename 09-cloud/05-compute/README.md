# Compute

Practical, structured notes for understanding, configuring, scaling, balancing, and designing **compute resources and architectures for cloud and infrastructure environments**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Virtual Machines|VM fundamentals, images, instance types, resource sizing, and VM lifecycle|
|02|Auto Scaling|Scaling concepts, horizontal and vertical scaling, and scaling policies|
|03|Load Balancing|Load-balancing fundamentals, Layer 4 and Layer 7 balancing, and health checks|
|04|Compute Architecture|Stateless and stateful compute, scalability, and compute architecture patterns|

## Structure

The notes progress from **virtual machines → auto scaling → load balancing → compute architecture**.

The virtual machine section establishes the fundamentals of compute instances, including images, instance types, resource sizing, and lifecycle management. Auto scaling then explains how compute capacity can be adjusted based on workload requirements.

Load balancing focuses on distributing traffic across compute resources using Layer 4 and Layer 7 techniques, with health checks used to maintain reliable traffic routing.

The final section brings these concepts together through stateless, stateful, and scalable compute architectures.

Each topic is separated into focused notes for easier learning, reference, and expansion.
