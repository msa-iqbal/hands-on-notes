# Serverless

Practical, structured notes for understanding, building, securing, and designing **serverless applications, functions, APIs, event-driven systems, and cloud-native workflows**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Fundamentals|Serverless concepts, characteristics, benefits, limitations, and operating models|
|02|Functions|Function fundamentals, lifecycle, execution, and runtime environments|
|03|API Gateways|API Gateway concepts, request handling, routing, integration, and common patterns|
|04|Event-Driven|Events, event sources, event processing, asynchronous communication, and event-driven architectures|
|05|Workflows|Workflow fundamentals, orchestration, task coordination, and serverless workflows|
|06|Serverless Databases|Serverless data services, managed databases, scalability, and application data patterns|
|07|Serverless Security|Function security, API security, authentication, authorization, and secure serverless design|
|08|Serverless Architecture|Serverless architecture patterns, application design, scalability, resilience, and cloud-native applications|

## Structure

The notes progress from **serverless fundamentals → functions → API gateways → event-driven systems → workflows → serverless databases → security → architecture**.

The fundamentals section establishes how serverless computing works and explains its characteristics, benefits, and limitations. Functions then introduce the execution model, lifecycle, and runtime environments used to run application logic without managing traditional servers.

API gateways and event-driven architecture cover application entry points, asynchronous communication, event sources, and event processing. Workflows and serverless databases extend these concepts into coordinated application processes and managed data architectures.

The final sections focus on securing serverless workloads and bringing the individual services together into scalable, resilient, and maintainable serverless application architectures.

Each topic is separated into focused notes for easier learning, reference, and expansion.
