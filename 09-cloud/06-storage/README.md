# Storage

Practical, structured notes for understanding, managing, protecting, backing up, and optimizing **data storage across cloud and infrastructure environments**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Object Storage|Object-storage fundamentals, buckets, objects, versioning, and lifecycle management|
|02|Block Storage|Block-storage concepts, volumes, and snapshots|
|03|File Storage|File-storage fundamentals, shared file systems, and mounting|
|04|Storage Classes|Hot, cool, and archive storage tiers and their use cases|
|05|Data Lifecycle|Lifecycle management, data transitions, and retention policies|
|06|Backup|Storage backup strategies, backup management, and snapshots|
|07|Archival|Long-term data retention, archival strategies, and cold-data management|
|08|Storage Security|Encryption, access control, data protection, and storage security practices|

## Structure

The notes progress from **object storage → block storage → file storage → storage classes → data lifecycle → backup → archival → storage security**.

The first sections establish the major storage models and how data is stored and accessed. Storage classes then introduce different approaches for balancing access frequency, performance, durability, and cost.

Data lifecycle, backup, and archival sections focus on managing data throughout its useful life, including retention, recovery, and long-term storage. The final section addresses protecting stored data through encryption, access control, and data-protection practices.

Each topic is separated into focused notes for easier learning, reference, and expansion.
