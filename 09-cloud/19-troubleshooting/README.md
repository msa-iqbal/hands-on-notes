# Troubleshooting

Practical, structured notes for diagnosing, analyzing, resolving, and preventing **cloud infrastructure, networking, storage, database, serverless, identity, security, monitoring, and cloud-provider problems**.

## Structure

The notes progress from **compute → storage → database → networking → serverless → IAM → security → monitoring → AWS → Azure → GCP**.

The first sections focus on troubleshooting common cloud infrastructure components. Compute covers virtual machine and scaling problems, while storage addresses storage availability, capacity, and permission issues. Database troubleshooting focuses on connectivity, availability, configuration, and operational problems.

Networking covers connectivity, DNS resolution, routing, and traffic-flow problems. Serverless focuses on function execution, invocation, runtime, and configuration issues.

IAM troubleshooting addresses authentication, authorization, permissions, and access problems. Security covers security-related configuration and incidents, while monitoring focuses on problems involving metrics, logs, alerts, dashboards, and observability.

The final sections provide cloud-provider-specific troubleshooting for **AWS, Azure, and GCP**, allowing provider-specific symptoms, diagnostics, commands, and solutions to remain separate from provider-neutral troubleshooting concepts.

Each topic is separated into focused notes for easier diagnosis, reference, practical use, and expansion.
