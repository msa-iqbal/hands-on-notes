# Database

Practical, structured notes for designing, managing, scaling, securing, backing up, recovering, and migrating **databases in cloud and distributed environments**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Relational|Managed relational databases, SQL-based services, and common cloud SQL patterns|
|02|NoSQL|Managed NoSQL databases, data models, and common NoSQL patterns|
|03|Managed Databases|Database-as-a-Service, managed database capabilities, and database selection|
|04|Caching|Cloud caching, distributed caching, cache strategies, and performance optimization|
|05|Replication|Read replicas, database replication, synchronization, and scaling read workloads|
|06|Backup & Recovery|Database backups, recovery procedures, restore strategies, and data protection|
|07|High Availability|Highly available database architectures, redundancy, failover, and resilience|
|08|Database Migration|Migration fundamentals, migration planning, migration strategies, and cutover approaches|

## Structure

The notes progress from **relational and NoSQL databases → managed database services → caching → replication → backup and recovery → high availability → database migration**.

The first sections establish the major database models and managed database approaches used in cloud environments. Caching and replication then focus on improving database performance, distributing read workloads, and increasing scalability.

Backup, recovery, and high availability address data protection and resilient database operations. The final section covers database migration planning and strategies for moving databases between environments or platforms.

Each topic is separated into focused notes for easier learning, reference, and expansion.
