# AWS

Practical, structured notes for learning, configuring, deploying, securing, monitoring, and troubleshooting **Amazon Web Services (AWS)**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Basics|AWS fundamentals, account setup, regions, availability zones, Management Console, AWS CLI, and SDKs|
|02|Compute|EC2, AMIs, Auto Scaling, Elastic Load Balancing, and Lightsail|
|03|Storage|S3, EBS, EFS, storage classes, and cloud storage management|
|04|Database|RDS, Aurora, DynamoDB, ElastiCache, and database migration|
|05|Networking|VPCs, subnets, route tables, gateways, security groups, network ACLs, Route 53, and VPC peering|
|06|Serverless|Lambda, API Gateway, EventBridge, Step Functions, and serverless application workflows|
|07|IAM|IAM users, groups, roles, policies, permissions, and access control|
|08|Monitoring|CloudWatch, CloudTrail, logging, monitoring, auditing, and operational visibility|
|09|Troubleshooting|Diagnosing EC2, S3, networking, IAM, configuration, and access-related problems|

## Structure

The notes progress from **AWS fundamentals → compute → storage → databases → networking → serverless → IAM → monitoring → troubleshooting**.

The basics section establishes AWS account management, regional infrastructure, and the primary tools used to interact with AWS. Compute, storage, and database sections then cover the core services used to run applications and manage data.

Networking focuses on building and securing AWS network infrastructure, while serverless introduces event-driven and managed application services. IAM covers identity and access control, and monitoring provides visibility into AWS resources and activity.

The final section brings these concepts together through practical troubleshooting of common AWS infrastructure, service, networking, and permission problems.

Each topic is separated into focused notes for easier learning, reference, and expansion.
