## Structure

The MIME-type reference is organized by **content category** so commonly needed media and data formats can be located quickly. Each section groups related MIME types and connects them with their typical file formats or web usage.

The application section covers structured data, documents, scripts, and other formats commonly served by web servers and APIs. The final cheatsheet provides a compact lookup for the MIME types encountered most frequently during development.

These pages are intended for **quick lookup**, not detailed content-format tutorials. HTTP concepts belong in `01-core/http/`, file-format information belongs in `19-reference/06-file-extensions/`, and technology-specific configuration should remain in its appropriate category.
