# Emoji Shortcodes List for Markdown

Emoji shortcodes are text-based aliases that render as emojis in Markdown platforms such as GitHub, GitLab, Discord, Slack, and other Markdown-compatible editors.

For example:

```
:smile: :rocket: :computer: :fire:
```

Output: 😄 🚀 💻 🔥

> Explore the documentation, tools, guides, and references behind the topic.

* [Unicode Emoji List](https://unicode.org/emoji/charts/full-emoji-list.html)

**Important:** Shortcode support varies by Markdown platform. GitHub supports many `:shortcode:` aliases, but standard CommonMark Markdown does not define emoji shortcodes.

For portable documentation, use actual Unicode emojis (e.g., `🌐`, `💡`, `⚠️`) when compatibility matters.
