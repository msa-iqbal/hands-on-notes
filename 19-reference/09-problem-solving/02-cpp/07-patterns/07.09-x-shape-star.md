# X Shape Star Pattern

Write a C++ program to print an `X` shape using `*`.

## Pattern

```text
*   *
 * *
  *
 * *
*   *
```

## Program

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;

    cout << "Enter an odd number: ";
    cin >> n;

    if (n % 2 == 0) {
        cout << "Please enter an odd number." << endl;
        return 0;
    }

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            if (j == i || j == n - i - 1) {
                cout << "*";
            } else {
                cout << " ";
            }
        }

        cout << endl;
    }

    return 0;
}
```

## Sample Output

```text
Enter an odd number: 5
*   *
 * *
  *
 * *
*   *
```
