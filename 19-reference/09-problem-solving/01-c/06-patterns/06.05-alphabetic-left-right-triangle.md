# Alphabetic Left-Right Triangle

## Problem

Write a C program to print an alphabetic triangle in which each row starts from a different character and continues backward toward `A`.

### C Program

```c
#include <stdio.h>

int main(void)
{
    int n;

    printf("Enter number of rows: ");
    scanf("%d", &n);

    for (int i = 1; i <= n; i++)
    {
        for (int j = i; j >= 1; j--)
        {
            printf("%c", 'A' + j - 1);
        }

        printf("\n");
    }

    return 0;
}
```

### Sample Output

```text
Enter number of rows: 5
A
BA
CBA
DCBA
EDCBA
```
