## Structure

Problem-solving materials are organized by programming language so problems and their solutions can be practiced using language-specific syntax, features, libraries, and programming techniques.

Each language has its own directory containing problems, solutions, exercises, and related practice materials.

The language-based structure makes it easy to solve the same or similar problems using different programming languages and compare their implementation approaches.
