## Structure

The reference collection is organized for **fast lookup rather than step-by-step learning**. Commands and shortcuts provide immediately reusable information, while ports, HTTP status codes, MIME types, and file extensions provide compact technical tables.

The environment section collects commonly needed configuration information across operating systems, programming runtimes, containers, and CI/CD systems. This provides a quick place to check environment-related conventions without mixing them into individual technology notes.

The glossary provides concise definitions of terminology used throughout the repository. Terms are grouped by technical domain so related concepts can be located quickly.

Reference pages should remain **compact, searchable, and lookup-oriented**. Detailed explanations, procedures, troubleshooting workflows, and reusable code should remain in their appropriate primary categories.
