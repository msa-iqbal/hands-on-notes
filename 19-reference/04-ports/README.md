## Structure

The port references are organized by **service category** so commonly needed network information can be found quickly. Common ports provide a general overview, while the specialized sections group ports by the type of service that uses them.

The collection covers infrastructure services, application services, remote access, file sharing, containers, monitoring, and local development. Each reference should identify the **port, protocol, service, and common usage** where applicable.

These pages are intended for **quick lookup**, not detailed networking tutorials. Networking concepts belong in `01-core/networking/`, service-specific configuration belongs in the relevant technology category, and network problems belong in `18-troubleshooting/11-networking/`.
