## Structure

The shortcut references are organized by **environment or application** so commonly used keyboard combinations can be found quickly. Terminal and shell shortcuts cover command-line workflows, while Vim and VS Code focus on text and code editing.

Git and browser shortcuts provide development and general productivity references. Windows, macOS, and Linux collect operating-system-specific shortcuts and desktop navigation.

These pages are intended for **quick lookup and memorization**, not detailed tutorials. Tool-specific behavior should remain in `14-tools/`, operating-system concepts in `07-os/`, and step-by-step procedures in `17-recipes/`.
