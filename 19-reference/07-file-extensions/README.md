## Structure

The file-extension reference is organized by **file type and common usage** so extensions can be identified quickly. Each section groups related formats and provides a practical lookup between extensions and the types of files they represent.

Source-code and configuration extensions focus on software-development files, while documents, media, archives, databases, and executable files cover commonly encountered files across development and operating-system environments.

These pages are intended for **quick lookup**, not detailed file-format documentation. MIME types belong in `19-reference/05-mime-types/`, operating-system-specific file behavior belongs in `07-os/`, and technology-specific file formats should remain in their appropriate primary categories.
