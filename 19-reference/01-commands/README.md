## Structure

The command references are organized by **tool or command-line environment** rather than by task. Each page focuses on the commands most commonly needed for that tool and keeps examples suitable for quick lookup.

Operating-system and development commands come first, followed by container and orchestration tools. Package managers and general-purpose CLI utilities then cover common development workflows, while Terraform and Ansible provide infrastructure and automation references.

These pages are intended for **quick reference**, not detailed tutorials. Step-by-step procedures should remain in `17-recipes/`, reusable command examples can be placed in `16-snippets/`, and problem-specific command sequences belong in `18-troubleshooting/`.
