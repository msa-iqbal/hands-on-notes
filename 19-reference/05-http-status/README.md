# HTTP Status

Quick-reference **HTTP status codes for understanding request outcomes, redirections, client errors, server errors, and common web application responses**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|1xx Informational|Informational HTTP responses and their meaning during request processing|
|02|2xx Success|Successful HTTP responses such as OK, Created, Accepted, and No Content|
|03|3xx Redirection|Redirect responses, caching-related behavior, and resource-location changes|
|04|4xx Client Errors|Client-side request errors such as Bad Request, Unauthorized, Forbidden, Not Found, and validation-related responses|

|06|Status Code Cheatsheet|Compact lookup table of commonly used HTTP status codes and their typical meanings|

## Structure

The HTTP status reference is organized according to the **five HTTP response classes**: informational, successful, redirection, client-error, and server-error responses. This makes it easy to locate a status code based on its response category.

The cheatsheet provides a compact overview for everyday development and debugging. Individual sections can contain status-code definitions, common usage, practical context, and important distinctions between similar responses.

These pages are intended for **quick lookup**, not complete HTTP tutorials. HTTP fundamentals belong in `01-core/http/`, API-specific behavior belongs in the relevant web or backend category, and HTTP-related problems belong in `18-troubleshooting/`.
