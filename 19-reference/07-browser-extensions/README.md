# Browser Extensions

Practical, structured notes for using and managing **browser extensions** in Google Chrome and Mozilla Firefox, including installation, configuration, productivity, privacy, security, development, and extension management.

## Contents

| #   | Topic           | What You'll Learn                                                                                                                |
| --- | --------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 01  | Google Chrome   | Chrome extensions, installation, management, permissions, configuration, productivity, privacy, security, and useful extensions  |
| 02  | Mozilla Firefox | Firefox add-ons, installation, management, permissions, configuration, privacy, security, developer tools, and useful extensions |

## Structure

The notes progress from **Google Chrome → Mozilla Firefox**, covering the installation, configuration, management, and practical use of browser extensions.

The Google Chrome section focuses on installing and managing extensions, understanding permissions, configuring extension settings, organizing extensions, and using extensions for development, productivity, privacy, and security.

The Mozilla Firefox section covers add-ons, extension management, permissions, configuration, privacy, security, and extension development workflows. Firefox WebExtensions use a `manifest.json` file to define extension metadata and functionality.

Each browser is separated into a focused guide for easier learning, extension management, troubleshooting, customization, and practical reference.
