# Comments

Write a C++ program that demonstrates single-line and multi-line comments.

## C++ Program

```cpp
#include <iostream>
using namespace std;

int main() {
    // This is a single-line comment.

    /*
       This is a multi-line comment.
       It can span multiple lines.
    */

    cout << "Comments in C++" << endl;
    cout << "Single-line and multi-line comments are supported." << endl;

    return 0;
}
```

## Sample Output

```text
Comments in C++
Single-line and multi-line comments are supported.
```
