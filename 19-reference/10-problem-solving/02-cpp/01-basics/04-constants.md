# Constants

Write a C++ program to demonstrate the use of constants using the `const` keyword.

## C++ Program

```cpp
#include <iostream>
using namespace std;

int main() {
    const double PI = 3.141592653589793;
    const int DAYS_IN_WEEK = 7;

    cout << "PI = " << PI << endl;
    cout << "Days in a week = " << DAYS_IN_WEEK << endl;

    return 0;
}
```

## Sample Output

```text
PI = 3.14159
Days in a week = 7
```
