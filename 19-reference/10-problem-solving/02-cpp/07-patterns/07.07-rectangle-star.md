# Rectangle Star Pattern

Write a C++ program to print a rectangular pattern using `*`.

## Pattern

```text
*****
*****
*****
*****
*****
```

## Program

```cpp
#include <iostream>
using namespace std;

int main() {
    int rows, columns;

    cout << "Enter number of rows: ";
    cin >> rows;

    cout << "Enter number of columns: ";
    cin >> columns;

    for (int i = 1; i <= rows; i++) {
        for (int j = 1; j <= columns; j++) {
            cout << "*";
        }

        cout << endl;
    }

    return 0;
}
```

## Sample Output

```text
Enter number of rows: 5
Enter number of columns: 5
*****
*****
*****
*****
*****
```
