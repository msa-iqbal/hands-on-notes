# Rectangle Star Pattern

## Problem

Write a C program to print a rectangle pattern using `*`.

## C Program

```c
#include <stdio.h>

int main(void)
{
    int rows, columns;

    printf("Enter number of rows: ");
    scanf("%d", &rows);

    printf("Enter number of columns: ");
    scanf("%d", &columns);

    for (int i = 1; i <= rows; i++)
    {
        for (int j = 1; j <= columns; j++)
        {
            printf("*");
        }

        printf("\n");
    }

    return 0;
}
```

## Sample Output

```text
Enter number of rows: 4
Enter number of columns: 6
******
******
******
******
```
