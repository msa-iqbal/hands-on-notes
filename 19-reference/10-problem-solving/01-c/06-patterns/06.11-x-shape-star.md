# X-Shape Star Pattern

## Problem

Write a C program to print an `X` shape using `*`.

## C Program

```c
#include <stdio.h>

int main(void)
{
    int n;

    printf("Enter an odd number: ");
    scanf("%d", &n);

    if (n % 2 == 0)
    {
        printf("Please enter an odd number.\n");
        return 0;
    }

    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < n; j++)
        {
            if (j == i || j == n - i - 1)
                printf("*");
            else
                printf(" ");
        }

        printf("\n");
    }

    return 0;
}
```

## Sample Output

```text
Enter an odd number: 7
*     *
 *   *
  * *
   *
  * *
 *   *
*     *
```
