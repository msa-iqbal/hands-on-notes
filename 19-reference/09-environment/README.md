## Structure

The environment reference starts with **general environment concepts**, covering environment variables and PATH before moving into operating-system-specific environments. This provides the foundation for understanding how processes discover commands and receive configuration.

Language runtimes then cover Node.js, Python, and Java environments, followed by Docker and CI/CD environments. This progression connects local development environments with containerized and automated build or deployment environments.

These pages are intended for **quick lookup and configuration reference**, not complete environment-management tutorials. Operating-system concepts belong in `07-os/`, language fundamentals belong in `02-languages/`, Docker concepts belong in `08-devops/`, and deployment procedures belong in `17-recipes/`.
