# Database Security

Practical, structured notes for securing **databases, database access, credentials, data, and application-to-database communication**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Users & Roles|Database users, roles, role hierarchy, authentication, service accounts, and account management|
|02|Permissions|Privileges, grants, roles, object permissions, schema permissions, and access control|
|03|Least Privilege|Least-privilege principles, permission minimization, role design, service accounts, and access reviews|
|04|SQL Injection|SQL injection fundamentals, attack vectors, parameterized queries, prepared statements, input handling, and prevention|
|05|Secrets|Database passwords, credentials, API keys, secret storage, environment variables, rotation, and secret management|
|06|Encryption|Encryption at rest, encryption in transit, TLS, key management, encrypted backups, and sensitive data protection|
|07|Database Security Checklist|Database hardening, access control, authentication, encryption, secrets, auditing, backups, monitoring, and security review|

## Structure

The notes progress from **users and roles → permissions → least privilege → SQL injection prevention → secrets and encryption → database security practices**.

The early topics focus on controlling who can access database resources and what they are allowed to do. Later topics address application-level threats, credential protection, encryption, and broader database hardening.

The security checklist brings these concepts together into a practical review process for evaluating database security.

Each topic is separated into focused notes for easier learning, reference, and expansion.
