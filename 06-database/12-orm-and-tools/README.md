# ORM & Tools

Practical, structured notes for understanding, using, and managing **Object-Relational Mappers (ORMs), database migrations, and database client tools**.

## Structure

The notes progress from **ORM fundamentals → Prisma, TypeORM, Sequelize, and Drizzle → database migrations → database client tools**.

The ORM topics focus on different approaches to application-level database access, including models, relationships, queries, transactions, and type safety. Migration topics cover controlled database schema changes and version management.

Database client topics cover tools used to connect to databases, execute queries, inspect schemas, manage data, and perform administrative tasks.

Each topic is separated into focused notes for easier learning, reference, and expansion.
