# SQL

Practical, structured notes for learning and using **SQL** to query, modify, and manage relational data.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Basics|`SELECT`, `WHERE`, `ORDER BY`, `LIMIT`, `OFFSET`, and `DISTINCT`|
|02|Data Definition|`CREATE`, `ALTER`, `DROP`, `TRUNCATE`, and database object definitions|
|03|Data Manipulation|`INSERT`, `UPDATE`, `DELETE`, `UPSERT`, and modifying table data|
|04|Joins|Inner, left, right, full, cross, and self joins|
|05|Functions|Aggregate, string, date, numeric, and `NULL` functions|
|06|Subqueries|Subqueries, correlated subqueries, `EXISTS`, and nested query patterns|
|07|CTE|Common Table Expressions, recursive CTEs, and reusable query patterns|
|08|Window Functions|Window fundamentals, ranking, partitioning, and window frames|
|09|Advanced|Views, materialized views, stored procedures, functions, and triggers|

## Structure

The notes progress from **SQL fundamentals → data definition and manipulation → joins and functions → subqueries → CTEs → window functions → advanced SQL features**.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Focus

- SQL query fundamentals
- Filtering, sorting, and pagination
- Creating and modifying database objects
- Inserting, updating, deleting, and upserting data
- Joins and relational data
- SQL functions
- Subqueries and correlated queries
- Common Table Expressions
- Recursive queries
- Window functions
- Views and materialized views
- Stored procedures and functions
- Database triggers
- Practical SQL query patterns

## Goal

> Learn SQL systematically, write clear and efficient queries, understand relational data deeply, and keep practical SQL knowledge easy to find.
