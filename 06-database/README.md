# Database

Practical, structured notes for learning, designing, developing, securing, optimizing, and operating **databases and data systems**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Fundamentals|Database concepts, types, architecture, servers, clients, connections, and terminology|
|02|SQL|SQL basics, data definition, data manipulation, joins, functions, subqueries, CTEs, window functions, views, procedures, and triggers|
|03|PostgreSQL|PostgreSQL installation, `psql`, features, indexes, transactions, performance, administration, backup, recovery, and replication|
|04|MongoDB|MongoDB fundamentals, documents, collections, queries, updates, indexes, aggregation, transactions, replication, sharding, and recovery|
|05|Redis|Redis fundamentals, data types, commands, expiration, persistence, Pub/Sub, Streams, transactions, caching, replication, and clustering|
|06|Database Design|Data modeling, normalization, relationships, schema design, constraints, schema evolution, and database patterns|
|07|Indexing|Index structures, B-Tree, hash, composite, covering, partial, full-text indexes, selectivity, maintenance, and performance|
|08|Transactions|Transactions, ACID, commit, rollback, isolation levels, locking, deadlocks, and concurrency control|
|09|Backup & Recovery|Backup types, logical and physical backups, incremental backups, point-in-time recovery, disaster recovery, and backup strategy|
|10|Replication|Replication models, primary-replica architecture, synchronous and asynchronous replication, read replicas, and failover|
|11|Performance|Query performance, execution plans, `EXPLAIN`, connection pooling, lock contention, memory, disk I/O, and performance tuning|
|12|ORM & Tools|ORM concepts, Prisma, TypeORM, Sequelize, Drizzle, migrations, and database client tools|
|13|Security|Users, roles, permissions, least privilege, SQL injection prevention, secrets, encryption, and database security practices|

## Structure

The notes progress from **database fundamentals → SQL → database systems → database design → indexing and transactions → backup, replication, and performance → ORM and tools → database security**.

The early sections establish database concepts and SQL fundamentals before moving into PostgreSQL, MongoDB, and Redis. Design, indexing, transactions, backup, replication, and performance cover the core concepts required to build and operate reliable database systems.

The final sections focus on application-level database access through ORMs and database tools, followed by security practices for protecting database access, credentials, and data.

Each topic is separated into focused notes for easier learning, reference, and expansion.
