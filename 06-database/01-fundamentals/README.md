# Fundamentals

Practical, structured notes for understanding **database fundamentals, database types, architecture, connectivity, and essential terminology**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Database Basics|What databases are, why they are used, how data is stored, and fundamental database concepts|
|02|Database Types|Relational, non-relational, document, key-value, graph, wide-column, and other database models|
|03|Relational vs Non-Relational|Differences between relational and non-relational databases, data models, schemas, relationships, and common use cases|
|04|Database Architecture|Database architecture, application-database communication, database layers, components, and common architectural models|
|05|Database Server|Database server concepts, server processes, database instances, connections, resources, and server responsibilities|
|06|Database Client|Database clients, CLI tools, GUI tools, client-server communication, queries, and database administration interfaces|
|07|Database Connection|Connection concepts, connection strings, authentication, connection lifecycle, pooling, timeouts, and connection management|
|08|Database Terminology|Tables, rows, columns, records, fields, keys, indexes, schemas, constraints, relationships, queries, transactions, and other common terms|

## Structure

The notes progress from **basic database concepts → database types → relational and non-relational models → database architecture → database servers and clients → database connections → common database terminology**.

Understanding these fundamentals provides the foundation for working with specific database technologies such as PostgreSQL, MySQL, SQLite, MongoDB, Redis, and other database systems.

Database architecture and terminology are especially important when moving from basic application-level database usage to database design, administration, performance optimization, and distributed systems.

Each topic is separated into focused notes for easier learning, reference, and expansion.
