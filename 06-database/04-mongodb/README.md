# MongoDB

Practical, structured notes for learning, developing with, optimizing, scaling, and administering **MongoDB**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Basics|MongoDB fundamentals, installation, client tools, configuration, and initial setup|
|02|Documents|Documents, document structure, BSON, embedded documents, and document modeling|
|03|Collections|Collection fundamentals, creating collections, capped collections, and collection options|
|04|Queries|Query fundamentals, filters, operators, projection, sorting, and pagination|
|05|Updates|Insert, update, delete, update operators, and upsert operations|
|06|Indexes|Index fundamentals, single-field, compound, multikey, text indexes, and index performance|
|07|Aggregation|Aggregation fundamentals, pipelines, filtering, projection, grouping, lookup, sorting, and performance|
|08|Transactions|Transactions, sessions, multi-document transactions, and transaction patterns|
|09|Replication|Replication, replica sets, members, arbiters, read preference, failover, and recovery|
|10|Sharding|Sharding fundamentals, shard keys, sharded clusters, chunk management, and performance|
|11|Backup & Recovery|Backup fundamentals, `mongodump`, `mongorestore`, point-in-time recovery, and disaster recovery|

## Structure

The notes progress from **MongoDB fundamentals → documents and collections → queries and updates → indexes and aggregation → transactions → replication and sharding → backup and recovery**.

The early topics focus on MongoDB's document model and everyday database operations, while later topics cover performance, distributed systems, high availability, scaling, and recovery.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Goal

> Learn MongoDB systematically, understand its document model and distributed architecture, build efficient data access patterns, and keep practical MongoDB knowledge easy to find.
