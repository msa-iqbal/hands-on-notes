# PostgreSQL

Practical, structured notes for learning, configuring, administering, optimizing, and using **PostgreSQL**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Installation|PostgreSQL installation, client tools, configuration, and initial setup|
|02|psql|`psql` basics, meta-commands, database navigation, and useful CLI commands|
|03|Features|Schemas, extensions, JSON/JSONB, arrays, full-text search, and PostgreSQL-specific features|
|04|Indexes|B-tree, Hash, GIN, GiST, partial indexes, and index selection|
|05|Transactions|Transactions, isolation levels, locking, concurrency, and deadlocks|
|06|Performance|`EXPLAIN`, `EXPLAIN ANALYZE`, query planning, `VACUUM`, and `ANALYZE`|
|07|Administration|Users, roles, permissions, configuration, logging, and monitoring|
|08|Backup & Recovery|Backups, `pg_dump`, `pg_restore`, point-in-time recovery, and replication|

## Structure

The notes progress from **PostgreSQL installation and CLI usage → PostgreSQL-specific features → indexes and transactions → performance → administration → backup and recovery**.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Focus

- PostgreSQL installation and configuration
- `psql` and PostgreSQL client tools
- Schemas and extension
- JSON and JSONB
- Arrays and full-text search
- PostgreSQL indexes
- Transactions and isolation levels
- Locking and deadlocks
- Query planning and optimization
- `EXPLAIN` and `EXPLAIN ANALYZE`
- `VACUUM` and `ANALYZE`
- Users, roles, and permissions
- Logging and monitoring
- Backup and restore
- Point-in-time recovery
- Replication

## Goal

> Learn PostgreSQL systematically, understand its features and internals, administer databases reliably, optimize queries, and keep practical PostgreSQL knowledge easy to find.
