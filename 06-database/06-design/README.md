# Database Design

Practical, structured notes for designing **reliable, consistent, maintainable, and scalable database schemas**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Data Modeling|Entities, relationships, cardinality, primary keys, and foreign keys|
|02|Normalization|Normalization principles, 1NF, 2NF, 3NF, and denormalization|
|03|Relationships|One-to-one, one-to-many, and many-to-many relationships|
|04|Schema Design|Schema structure, naming conventions, constraints, and schema evolution|
|05|Patterns|Audit fields, soft delete, polymorphic data, and multi-tenant database patterns|

## Structure

The notes progress from **data modeling fundamentals → normalization → relationships → schema design → practical database design patterns**.

The early topics focus on modeling data correctly and defining relationships, while later topics cover schema organization, constraints, evolution, and reusable patterns for real-world applications.

Each topic is separated into focused notes for easier learning, reference, and expansion.
