# Redis

Practical, structured notes for learning, configuring, using, optimizing, and operating **Redis**.

## Structure

The notes progress from **Redis fundamentals → data types and commands → expiration and persistence → Pub/Sub and Streams → transactions and caching → replication → clustering**.

The early topics focus on Redis data structures and everyday operations, while later topics cover persistence, messaging, distributed systems, high availability, scaling, and production-oriented usage.

Each topic is separated into focused notes for easier learning, reference, and expansion.

## Focus

## Goal

> Learn Redis systematically, understand its data structures and distributed capabilities, use it effectively for caching and messaging, and keep practical Redis knowledge easy to find.
