Practical, structured **troubleshooting guides** for diagnosing and resolving common problems across operating systems, Git, Docker, databases, frontend and backend applications, and networking.

## Structure

The troubleshooting guides progress from **operating-system problems → mobile-device problems → Git and Docker → database issues → frontend and backend applications → networking**.

The first five sections cover troubleshooting across Linux, Windows, macOS, Android, and iOS. These guides focus on platform-specific failures involving boot, applications, storage, permissions, connectivity, services, performance, and device capabilities.

Git and Docker then cover common development and infrastructure problems. Git guides address repository state, history, branches, remotes, and authentication, while Docker guides focus on containers, images, networking, volumes, resources, Compose, and registries.

Database troubleshooting covers connectivity, authentication, database services, query performance, locking, connection pools, migrations, backups, restores, and replication. Frontend and backend sections then address application-level failures from development through production.

The final networking section provides cross-platform troubleshooting for connectivity, DNS, DHCP, addressing, ports, routing, firewalls, proxies, and VPNs. These guides can also support diagnosis of problems encountered in the other categories.

Each troubleshooting guide follows a **problem-oriented workflow** covering symptoms, possible causes, diagnosis, solution, verification, prevention, and related issues.
