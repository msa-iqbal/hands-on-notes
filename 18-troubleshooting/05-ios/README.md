## Structure

The guides progress from **application problems → installation and update failures → battery and storage → Wi-Fi and mobile data → Bluetooth and USB → application performance → notifications**.

The first three sections focus on application lifecycle problems. App-crash troubleshooting covers runtime failures and recovery, while installation and update guides address storage, compatibility, App Store, network, restriction, and configuration issues.

Battery and storage troubleshooting then covers common device-resource problems. These guides help identify applications, files, background activity, and system features responsible for excessive battery consumption or insufficient storage.

The connectivity section covers Wi-Fi, mobile data, Bluetooth, and USB connections. These guides provide structured diagnosis for network access, authentication, cellular configuration, accessory pairing, computer connections, and data-transfer problems.

The application-performance guide focuses on slow, unresponsive, or resource-intensive applications and provides a structured approach to identifying the underlying cause. The final guide covers notification problems involving permissions, application settings, Focus modes, background activity, and notification delivery.

Each troubleshooting guide follows a **problem-oriented workflow** covering symptoms, possible causes, diagnosis, solution, verification, prevention, and related issues.
