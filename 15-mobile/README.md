# Mobile

Practical, structured notes for understanding **mobile application development across Android, iOS, React Native, and Flutter**, including development environments, application architecture, platform APIs, networking, storage, testing, performance, security, and publishing.

## Structure

The notes progress from **native mobile development → cross-platform mobile development**.

Android and iOS cover native application development and platform-specific concepts, including application structure, lifecycle, navigation, storage, networking, permissions, background work, notifications, testing, performance, security, and publishing.

React Native and Flutter then cover cross-platform development. React Native focuses on JavaScript-based mobile development and integration with native platform capabilities, while Flutter covers Dart, widgets, layouts, state management, and platform integration.

Each platform or framework is separated into focused notes for easier learning, development, debugging, testing, optimization, security, and practical mobile application work.

## Focus

## Goal

> Build a practical mobile-development knowledge base that makes it easy to learn native and cross-platform development, build and debug applications, integrate platform capabilities, optimize performance, apply security practices, and publish mobile applications.
