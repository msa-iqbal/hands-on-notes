# Fundamentals

Practical, structured notes for understanding **security fundamentals, core principles, security objectives, threats, vulnerabilities, risk management, and foundational security practices**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Security Fundamentals|Security concepts, objectives, terminology, security domains, and foundational concepts|
|02|Security Principles|Core security principles, least privilege, separation of duties, fail-safe design, and trust boundaries|
|03|Confidentiality, Integrity & Availability|CIA triad, confidentiality, integrity, availability, and security trade-offs|
|04|Threats & Vulnerabilities|Threats, vulnerabilities, attack surfaces, threat actors, and common security weaknesses|
|05|Risk Management|Risk identification, risk assessment, risk treatment, mitigation, acceptance, and monitoring|
|06|Threat Modeling|Threat identification, assets, trust boundaries, attack paths, threat analysis, and mitigation|
|07|Security Controls|Preventive, detective, corrective, technical, administrative, and physical security controls|
|08|Defense in Depth|Layered security, multiple controls, failure containment, redundancy, and layered protection|
|09|Security Best Practices|Foundational security practices, secure defaults, least privilege, updates, monitoring, and security awareness|

## Structure

The notes progress from **security fundamentals → security principles → CIA → threats and vulnerabilities → risk management → threat modeling → security controls → defense in depth → security best practices**.

The first sections establish security terminology, objectives, and fundamental principles. The CIA section then introduces the three core security objectives used to evaluate how information and systems should be protected.

Threats and vulnerabilities explain common sources of security risk, while risk management provides a structured approach to identifying, evaluating, treating, and monitoring those risks. Threat modeling then applies these concepts to systems by identifying assets, trust boundaries, attack paths, and appropriate mitigations.

Security controls and defense in depth introduce practical protection mechanisms and layered security strategies. The final section brings these concepts together through foundational security practices that can be applied across systems and applications.

Each topic is separated into focused notes for easier learning, revision, reference, and practical security work.
