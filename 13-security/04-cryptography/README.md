# Cryptography

Practical, structured notes for understanding **cryptography fundamentals, encryption, hashing, message authentication, digital signatures, key management, randomness, key exchange, and secure cryptographic practices**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Cryptography Fundamentals|Cryptographic concepts, security goals, plaintext, ciphertext, keys, algorithms, and common terminology|
|02|Symmetric Encryption|Shared-key encryption, block and stream ciphers, encryption modes, keys, and practical use cases|
|03|Asymmetric Encryption|Public-key cryptography, private and public keys, encryption, signatures, and practical use cases|
|04|Hashing|Hash functions, one-way properties, collision resistance, integrity checks, and common applications|
|05|Message Authentication Codes|MACs, HMAC, message integrity, authentication, shared secrets, and verification|
|06|Digital Signatures|Signing, verification, authenticity, integrity, non-repudiation concepts, and signature workflows|
|07|Key Management|Key generation, storage, distribution, rotation, revocation, lifecycle management, and protection|
|08|Randomness|Secure random generation, entropy, nonces, salts, initialization vectors, and randomness requirements|
|09|Key Exchange|Secure key establishment, Diffie-Hellman concepts, ephemeral keys, and shared-secret generation|
|10|Cryptography Best Practices|Algorithm selection, key protection, secure defaults, library usage, key lifecycle, and common mistakes|

## Structure

The notes progress from **cryptography fundamentals → symmetric encryption → asymmetric encryption → hashing → message authentication codes → digital signatures → key management → randomness → key exchange → cryptography best practices**.

The first sections establish the basic concepts and security goals of cryptography before introducing symmetric and asymmetric encryption. Hashing then covers one-way transformations used for integrity and other security applications.

Message authentication codes and digital signatures build on these primitives to provide message authentication, integrity, and authenticity. Key management and randomness then address the operational foundations required to use cryptographic systems securely.

Key exchange introduces techniques for establishing shared secrets over communication channels. The final section brings these concepts together through practical cryptographic practices, secure algorithm selection, key protection, and correct library usage.

Each topic is separated into focused notes for easier learning, implementation, revision, and practical security work.
