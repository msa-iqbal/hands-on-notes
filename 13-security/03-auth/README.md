# Auth

Practical, structured notes for understanding **authentication, authorization, password security, multi-factor authentication, session management, access control, and secure identity practices**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Authentication Fundamentals|Authentication concepts, identity verification, credentials, authentication factors, and common flows|
|02|Authorization|Access decisions, permissions, resource protection, policy enforcement, and authentication vs authorization|

## Structure

The notes progress from **authentication fundamentals → authorization → password authentication → password hashing → multi-factor authentication → session management → role-based access control → attribute-based access control → permission models → authentication best practices**.

The first sections establish how identities are verified and how authorization determines what authenticated users are allowed to access. Password authentication and password hashing then cover the secure handling and storage of password credentials.

Multi-factor authentication introduces additional authentication factors and stronger identity verification. Session management then focuses on maintaining authenticated state securely across requests.

RBAC, ABAC, and permission models cover different approaches to expressing and enforcing access decisions. The final section brings these concepts together through practical authentication and identity-security practices.

Each topic is separated into focused notes for easier learning, implementation, security review, and practical application.
