# Security

Practical, structured notes for understanding **security fundamentals, web security, authentication, cryptography, secure communication, identity protocols, secrets management, and secure software development**.

## Contents

|#|Topic|What You'll Learn|
|---|---|---|
|01|Fundamentals|Security principles, CIA, threats, vulnerabilities, risk management, threat modeling, and security controls|
|02|Web|Web vulnerabilities, OWASP risks, injection attacks, security headers, and web security practices|
|03|Auth|Authentication, authorization, passwords, MFA, sessions, access control, and authentication practices|
|04|Cryptography|Encryption, hashing, MACs, digital signatures, key management, randomness, and key exchange|
|05|TLS|TLS fundamentals, handshakes, certificates, PKI, versions, cipher suites, and mutual TLS|
|06|OAuth|OAuth concepts, roles, authorization flows, PKCE, tokens, scopes, consent, and OpenID Connect|
|07|JWT|JWT structure, claims, signing, verification, tokens, expiration, storage, and security risks|
|08|Secrets|Secrets management, environment variables, API keys, credentials, storage, rotation, and scanning|
|09|Secure Coding|Secure development practices, validation, encoding, error handling, logging, dependencies, and security testing|

## Structure

The notes progress from **security fundamentals → web security → authentication → cryptography → TLS → OAuth → JWT → secrets management → secure coding**.

The first sections establish core security principles, threats, vulnerabilities, risk management, and common security controls. Web security and authentication then focus on protecting applications, users, sessions, and access to resources.

Cryptography introduces the mathematical foundations used to protect information, followed by TLS for securing network communication. OAuth and JWT then cover widely used mechanisms for delegated authorization, identity, and token-based authentication.

Secrets management focuses on protecting credentials and sensitive configuration data. The final section brings these concepts into software development through secure coding practices, dependency security, security testing, and static analysis.

Each topic is separated into focused notes for easier learning, implementation, revision, and practical security work.

> Build a practical security knowledge base that makes it easy to understand security principles, protect applications and data, implement secure authentication and communication, manage sensitive information, and develop software securely.
